# 提示词翻译

状态：已接受，实施状态见[实施计划](../../plans/2026-09-14-prompt-translation.md)。页面与内容语言规则沿用[设计方案](../../plans/2026-09-14-prompt-translation-design.md)。

## 本机模型配置

「设置 → AI 与模型」MUST 统一管理本机接口、Key、优化模型和翻译模型。两个模型均使用可搜索下拉框，由用户主动获取 `/models` 后选择；获取列表不要求先保存模型。保存但未在列表返回的模型保留并标明，不悄悄改成第一项。请求错误或空列表需可重试。更换接口时旧列表失效，旧密钥仅可用于与保存配置完全相同的规范化基础地址。

原启动器配置 MUST 兼容读取；翻译模型为空表示未配置，不自动调用优化模型或服务器审核密钥。列表发现允许未保存的草稿 Key，只在当前请求中使用，不持久化；公开配置永不返回 Key。具体服务仅在用户主动优化、翻译或测试时接收对应文本。

## 原文与翻译版本

MUST 以源正文摘要、目标语言和规则版本标识译文；源文修改后旧缓存不再作为当前译文。正文翻译只处理自然语言，变量语法、代码、链接和 JSON 键保留；保护或完整性校验失败即失败，不覆盖原文。英文原稿直接作为英文版本。中文版本先供广场展示，本地库只按用户主动请求生成。

## 验收场景

- Given 新设备未保存模型 When 填写接口及 Key 获取模型 Then 可获取和搜索选择，无需输入模型 ID。
- Given 已保存旧配置 When 升级 Then 优化模型与密钥保留，翻译模型仍未配置。
- Given 更换接口或 Key When 请求模型失败 Then 原设置不被覆盖，不把旧目录显示为新接口结果，也不向新接口发送旧密钥。
- Given 本地正文含变量 When 翻译模板并填写参数 Then 变量名称与用户值不变，复制使用当前语言的模板。
- Given 提示词已生成翻译 When 重复请求或下载 Then 复用同一版本，不重复创建条目或增加下载/收藏计数。
- Given 翻译任务失败/限流/输出截断 When 查看内容 Then 原文仍可用，有明确失败和重试入口。
