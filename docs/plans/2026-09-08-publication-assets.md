# P1c 单条提示词公开附件

状态：已实现并本机验收，承接私有附件同步。不包含合集成员附件、云端回收及恶意软件扫描。

## 实施步骤

1. 单条提示词投稿页按需读附件并逐个勾选，默认均不选；显示公开告知。切换源/账号清空选择，读取/上传失败保留页面，禁止提交不完整快照。复用私有上传和哈希校验，只将选中的引用送入投稿；私有同步不产生公开授权。合集仍只提交正文成员。
2. publications 追加 asset_refs JSONB，旧记录缺省空数组。服务端检查 ready、所有者、元数据、数量和大小；带附件稿件一律 pending，纯文本规则/AI 不得自动通过。引用随不可变投稿快照保存，后续本地编辑不改变待审文件。
3. 审核人员只能通过投稿范围的专用接口读取已选文件，不扩大私有媒体权限。管理台列出文件名、类型、大小，显式查看图片/文本或下载文件；不执行 HTML/SVG/Office。审核权限与会话在传输前后检查。
4. 广场正文返回批准附件清单。公开字节代理必须同时满足投稿 approved、square_items online、附件在此稿件清单、媒体 ready、站点匿名访问策略；传输后再次检查。不存在/下架/回收站为 404，不发对象签名 URL，no-store。已下载副本不受远端下架影响。
5. 客户端详情显式加载附件预览；下载时获取所有文件、验证 SHA-256 后与正文原子导入 SQLite，失败不留半份副本，沿用下载防重入。新本地附件 UUID 随导入重映射，不携带云端私有地址。
6. 隔离双账号、审核角色、匿名策略和下架测试；前端投稿选择/失败、管理端附件显示、下载事务及校验测试；运行相关全量测试/构建、文档检查，独立提交。不得在用户现有账号或真实投稿上执行测试审核。

## Given / When / Then

- GIVEN 本机有两份私人文件；WHEN 只选其中一份投稿；THEN 只提交选中引用，未选文件不能通过投稿接口读取。
- GIVEN 他人文件或伪造元数据；WHEN 投稿；THEN 拒绝且不创建投稿。
- GIVEN 自动审核全部允许通过；WHEN 投稿包含附件；THEN 仍待人工，不把文本模型结果当文件安全验证。
- GIVEN 待审稿件；WHEN 作者或普通用户请求审核附件；THEN 无审核权限不能读取；审核人员仅能读取此稿选中的文件。
- GIVEN 稿件待审/驳回或内容已下架；WHEN 通过已知 URL 读附件；THEN 404。批准且 online 才可公开；禁止匿名时无会话 401。
- GIVEN 图片/文本附件；WHEN 显式查看；THEN 校验后预览，其他文档下载不自动执行。
- GIVEN 多文件下载中某个损坏/离线；WHEN 下载到本地；THEN 不留下正文或部分文件，重试可完整导入且不重复。

## 后续边界

合集成员附件、公开文件替换/删除和对象回收另做切片。本片人工审核不等于防病毒保证；已经公开或下载的文件无法从他人设备撤回。
