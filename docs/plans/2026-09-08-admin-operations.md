# 概览、审计和系统状态

| 字段 | 值 |
|---|---|
| 状态 | 实施与本地验证完成；正常提交门禁待通过 |
| 范围 | A11、A12；无任意命令执行、生产恢复或日志删除按钮 |

## 指标设计

- owner/admin GET overview，days=7/30/90。用同一 SQL 快照返回当前用户/启用用户、公开在线内容/待审、已记录下载累计、当前收藏关系和全期 mock 订单；时间窗口仅用于新增账号/投稿/mock 订单，清晰标注口径，不生成增长曲线。
- accounts 增量 created_at：先加可空列，再设置新插入默认 now，不给旧账号伪造注册时间；operations_metadata 保存采集启用时间。返回未知创建时间账号/投稿数量；累计下载不支持按日期拆分，因为历史仅保存计数且受客户端统计开关影响。
- 不采集桌面/MCP 本地使用行为，mock 与真实收费不能混算，订单无金额。

## 审计与失败追踪

- owner GET /v1/admin/audit，actor/action/from/to/offset 固定每页 25；成功 security_audit 与 request_failures 合并。返回必要元数据和白名单脱敏变化摘要，不返回任意配置正文、令牌、密码、验证码、请求体或私有库。
- 有界失败 middleware 仅记录身份/管理/投稿写路径失败，使用 MatchedPath 模板（无路径实参或查询串）、HTTP 方法/状态、请求 UUID、可确认的操作者和时间。失败日志写入异常不篡改原响应，服务器只输出固定说明；不记录提供商原始错误。
- owner 受限导出 JSON（最多 500 条，明确上限），显式确认并审计导出；无删除日志接口。后续 A19 只允许配置失败/投递运行日志留存，不删除安全成功审计。

## 系统状态与恢复

- owner GET system 返回应用版本、服务器 UTC 时间、Postgres/Redis/对象存储实际探测结果、mail 队列数量和密钥“已载入”状态；不返回数据库 URL、凭据、磁盘路径或签名 URL。
- 每个依赖最多 3 秒、整体有限时。对象存储必须检查 HTTP 2xx，禁止跟随重定向；修复原 ping 将 403/500 当成功的问题。未配置与不可用分开，不因为配置对象存在即标健康。
- 编写配套恢复手册：Postgres 逻辑备份、OAuth/AI/SMTP/通知共用加密密钥、对象存储与部署配置需配套保护；停止写入、验证目标、隔离恢复、验证再切换，生产恢复须用户明确授权。删除现行 local-dev 中危险的一键 reset 建议和过时默认初始化描述，链接现行后台说明。
- 隔离恢复演练仅生成独立临时数据库/随机 schema 和合成数据、随机加密密钥，使用 Docker Postgres 16 的 pg_dump/pg_restore；检查关键表行数、账号校验器、公开快照、加密样本可恢复且错密钥拒绝。记录具体命令和结果，不读/输出真实业务备份或密钥。

## 实施与验收

1. 先定义统计口径与 API/权限；隔离测试时间窗口、旧记录为空时间、角色拒绝、摘要脱敏和导出上限。
2. 实现增量迁移与真实查询、失败请求模板化日志、限时健康探测；失败不能变成成功空列表。
3. 新增概览/审计/系统页，日期与角色导航、分页、空/失败/刷新态及导出确认；无虚拟增长数字。
4. 隔离恢复演练和手册，宽窄屏浏览器、后端/前端测试构建、文档检查后正常提交。

## Given/When/Then

- GIVEN 老账号没有创建时间；WHEN 查看近 7 天新增；THEN 不算作今天新增，明确列未知历史数。
- GIVEN OAuth 密钥/口令/验证码存在于输入或配置；WHEN 请求失败、查询审计或导出；THEN 不含这些值，记录模板路径与请求 ID 而非完整 URL/正文。
- GIVEN 对象存储返回 403 或依赖超时；WHEN 查看系统页；THEN 显示不可用，不报告健康。
- GIVEN 合成库备份及配套随机密钥；WHEN 在独立空库恢复；THEN 合成账号/内容与密文一致、正确密钥可解密、错误密钥拒绝，现有业务库不变。
