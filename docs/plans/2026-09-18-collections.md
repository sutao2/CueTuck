# 合集内创作与封面发布修复

状态：实施中。

## 步骤与验收

1. 合集详情增加新建提示词，复用正文与附件编辑器。原生事务一次创建成员，使用 source=collection 标记合集内创作；独立列表排除该来源，移出/删除合集转为 local，已有提示词加入保持来源。验证创建、编辑、移出、删除与备份同步保留。
2. 统一合集封面组件：详情为有最大宽度的正方形九宫格，卡片独立图片区域，列表小缩略图；单图保持比例。验证 1/3/9 图、缺图、窄屏与标题不重叠。
3. 发布预览明确展示将公开的合集封面；封面复用私有媒体上传及稿件审核授权，以独立 cover 字段关联清单，保留顺序和布局。验证审核前不可读、关联拒绝、公开详情与下载恢复；成员私有附件仍默认不选。
4. 运行客户端、原生与后端针对性测试、构建与页面检查；更新规格和索引，提交。

## Given / When / Then

- GIVEN 已有合集；WHEN 在合集中新建提示词；THEN 只出现在该合集，独立提示词列表不增加；保存失败无半成品。
- GIVEN 合集专属成员；WHEN 移出或删除合集；THEN 内容与附件保留并变成独立提示词；界面预先说明。
- GIVEN 九张封面；WHEN 浏览卡片、列表与详情；THEN 图片按行列均匀排列，不挤成条形、不覆盖标题。
- GIVEN 有封面的合集；WHEN 确认发布预览；THEN 上传封面并关联稿件，审核批准后可展示，下载后保留布局与顺序。
- GIVEN 非图片/未知/重复封面引用；WHEN 投稿；THEN 拒绝，未选择成员附件仍不上传。
