## 切片与验收

1. 快捷键与同步状态：显示启动注册失败及修复入口，保存成功清除错误；将自动同步队列准确命名，显示当前账号的队列与最近手动同步结果。Given 冲突/账号切换 When 启动或查看状态 Then 不伪装成功、不显示上一账号状态，原按钮仍可用。
2. 搜索与日常操作：全局搜索增加本机 Skills 和显式社区 Skill 范围，保持草稿离开保护；明确复制/填写、本地保存、收藏范围；空库提供可选示例；Skills 维护入口折叠。Given 用户搜索 Skill 或首次使用 When 选择结果或示例 Then 可完成原有流程，取消不写数据，搜索不安装文件。
3. 本地回收站：提示词/合集可恢复，删除后可撤销；保留成员分离合同，恢复不覆盖现有条目且修复失效分类/合集引用。Given 删除含附件条目 When 重启后恢复 Then 正文与文件完整，原搜索/使用/同步仍有效。
4. 备份说明与恢复预览：明确库内附件和外链边界，恢复前校验并显示内容数量；失败保留原库，恢复前保存当前库。Given 有附件的备份或损坏文件 When 预览/恢复 Then 文件完整或拒绝写入；预览不修改原文件。
5. 同步覆盖历史：在较新远端正文覆盖本机前保留本机版本，提供查看和恢复为独立副本；不改变较新者胜/保留本地与附件传输边界。Given 正文发生冲突 When 同步后恢复旧版本 Then 当前同步条目不被覆盖，旧版本可查看并复制为本地提示词。
