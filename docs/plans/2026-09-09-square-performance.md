# 广场有界加载与滚动性能

## 目标与边界

替代客户端一次获取 21,775 条约 18.2 MB 的列表路径。桌面广场使用新的 `/v1/square/browse`，数据库执行筛选、排序、计数和 LIMIT/OFFSET；保留旧 `/items` 与 MCP `/search` 兼容接口，不改变详情、下载或管理台合同。本地库沿用现有分页。

## 切片

1. 后端：默认 48、最多 48 条；稳定 id 次排序；返回 total/next_offset 和精简摘要、单张封面及当前账号收藏状态；排序索引；不查询正文或成员。验收 SQL 分页、参数校验、分类/模型/搜索、收藏隔离与下架过滤。
2. 传输：浏览器 AbortController、Tauri 可取消的有界请求；筛选立即失效旧请求。新接口失败不退回全量接口；列表与追加加载错误分别处理。
3. 视图：接近底部预取一页，单次追加防重；虚拟网格仅挂载视口附近行，支持图片/无图行、列表视图、侧栏调宽及返回详情保留位置；失败有手动重试，不自动循环重试。保留键盘可操作的加载更多按钮。本地空间不触发远端续页。
4. 验收：首屏响应小于 250 KB（本机现有数据），滚动多页挂载卡片有界；快速搜索/筛选、追加失败重试、末页停止、去重与重返本地。运行相关后端/前端/原生测试、构建，逐个切片提交。

## Given/When/Then

- GIVEN 两万条公开记录 WHEN 打开广场 THEN 只取最多 48 条精简记录，不读取正文/成员快照。
- GIVEN 首批已显示 WHEN 滚动接近底部 THEN 单次请求下一页；快速重复触发不重复请求或条目。
- GIVEN 旧搜索或续页尚未完成 WHEN 切换分类/模型/搜索/空间 THEN 取消旧传输并隔离旧响应，不覆盖新结果。
- GIVEN 后续一页请求失败 WHEN 重试 THEN 保留已有内容、重试同一 offset；不整页离线或无限重试。
- GIVEN 已加载多页 WHEN 上下滚动或调整侧栏宽度 THEN 只挂载可见附近行，条目仍可打开、下载、收藏；详情返回保留位置。
- GIVEN 收藏或内容可见性不同 WHEN 分页查询 THEN 不泄漏其他账号收藏及非 online 内容，完整总数与筛选一致。
