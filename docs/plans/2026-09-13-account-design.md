# 账号页信息层级与资料编辑

- 日期：2026-09-13
- 状态：实现、浏览器验收与本机客户端更新完成
- 范围：桌面设置「账号与广场」，沿用已有身份、资料、投稿和账单接口。

## 设计与切片

1. 顶部账号概览突出已保存显示名、邮箱和登录状态，用文字头像代替空白；未登录展示访客与登录入口，不假造第三方头像或账号绑定信息。
2. 宽屏采用公开资料主卡与投稿/订阅辅助卡，窄屏顺序堆叠。作者信息偏好独立放在下方，沿用设置颜色与焦点样式。
3. 资料表单保留标签、显式保存与未保存退出确认；补充保存中、未保存、已保存就近反馈，只有真实保存成功才更新概览名字。
4. 真实订阅状态与 Mock 标识保持可见；模拟操作和测试码收进默认折叠的测试区域，非模拟环境保留兑换与支付入口，不改变真实权益或接口。
5. 验证资料失败/重试、脏状态、访客与模拟账单；跑前端回归与浅深色/窄屏浏览器检查，构建并更新本机客户端，独立提交。

## Given / When / Then

- GIVEN 已登录且有公开资料；WHEN 查看账号页；THEN 概览显示已保存资料和邮箱，常用入口与编辑区清楚分组。
- GIVEN 修改显示名或简介；WHEN 未保存、保存失败或保存成功；THEN 依次提示未保存、保留输入并可重试、更新概览并提示已保存。
- GIVEN Mock 已开启；WHEN 初次进入账号页；THEN 真实订阅与 Mock 标识可见，测试操作折叠；展开后仍能使用原有模拟与兑换功能。
- GIVEN 访客或窄窗口；WHEN 查看账号页；THEN 登录入口可用、资料编辑禁用，卡片顺序堆叠且无横向溢出。
