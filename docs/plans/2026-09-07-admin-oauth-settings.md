# 管理台第三方登录配置与界面

## 目标与边界

用户要求在管理端配置 Google / GitHub 登录，并改善管理台外观。保留审核、用户只读列表、站点开关；不扩展到注册、改密或其他 OAuth 提供商。

## 实施与验收

- [x] 管理员专属 GET/PUT 配置接口，逐提供商保存，校验回调与启用所需字段。秘密以 AEAD 加密后写入 Postgres，独立后端密钥文件不进 Git；空密钥保留原值。
- [x] OAuth 每次请求读取有效配置，数据库覆盖环境变量；启停立即生效、重启保留；错误不得回显密钥。
- [x] 侧栏式管理台、紧凑登录页、第三方登录表单及状态说明，保留既有功能；登录必须确认管理员角色，提供退出入口。
- [x] API 权限/脱敏/校验/持久化/启停测试，管理端保存/重试/权限测试，浏览器实际操作与窄屏检查。
- [x] 运行测试、构建、文档检查，更新本地服务并提交。

## 配置存储约束

服务器第一次启动在 `PROMPTARK_OAUTH_KEY_FILE` 指定位置（默认工作目录下 `.promptark/oauth.key`）创建随机 32 字节密钥；Unix 文件权限 0600。数据库备份须配套保管密钥文件，多实例共用同一文件内容；已有密文无法解密时失败，不覆盖为新密钥。管理端仅显示是否设置了密钥。用户仍须在提供商控制台创建应用并登记同一回调地址，真实授权验收依赖用户凭据。
