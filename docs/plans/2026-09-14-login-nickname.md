# 登录后补全公开昵称

状态：计划完成，实施中。

1. 主窗口在邮箱/OAuth 登录及恢复会话后读取本人公开资料；缺少昵称时展示集中设置弹窗，已设置则继续原操作，不修改认证与钥匙串存储。
2. 昵称去除首尾空格，不能为空；明确公开可见，保留已有简介。读取/保存失败就近反馈并允许重试；保存期间禁止重复操作，退出登录可回到本地库。
3. 测试已有昵称、空昵称、失败重试、简介保留及卸载后的过期响应；验证登录与发布续接，构建安装客户端，记录实机结果并提交。

- Given 邮箱或 OAuth 登录成功且昵称为空 When 进入工作台 Then 先设置公开昵称，成功后继续原操作。
- Given 恢复已有会话且昵称为空 When 打开应用 Then 同样提示补全；已有昵称不重复设置。
- Given 读取或保存失败 When 重试 Then 保留输入，不冒充保存成功；退出登录后本地功能可用。
- Given 账号有简介 When 只设置昵称 Then 简介不被清空，邮箱不被用作默认公开昵称。
