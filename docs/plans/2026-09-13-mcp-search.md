# MCP 搜索与请求隔离

状态：已验收（2026-09-13）。

## 实施与验证

1. 本地搜索使用进程内 SQLite FTS5 trigram 索引。Unicode 字符间插入空格后索引，使双字中文也有三字符片段；原文小写字面校验消除编码误匹配。单字回退字面扫描，多词按空白分隔且全部命中，标题优先、BM25 与标题/id 稳定排序。保留旧文本数组，新增 structuredContent 分页信息与分类/模型精确筛选。
2. 只读源库，以同一连接的 data_version 检测提交（含 WAL），文件身份变化时重开；索引在内存中重建，不写用户库。构建最多 10 秒、查询最多 2 秒，取消由进度回调检查；参数与分页有界。
3. stdio 控制请求即时处理，本地与广场分别使用单工作线程和最多 32 条等待队列。支持 notifications/cancelled，跳过排队任务、停止本地 SQL、抑制已取消任务的结果。已发出的阻塞 HTTP 仍受原 8 秒总超时约束，不承诺立即断开；不阻塞本地与 ping。
4. 搜索正确性、只读/WAL/文件替换、分页、参数、取消与远端慢请求隔离用临时库和真实 stdio 验证；隔离生成 50,000 条数据比较 release 前后冷启动与重复查询，记录限制。更新接入说明、构建 release、docs-check 后分片提交。

## Given / When / Then

- GIVEN 中文双字词、英文、标点与多词分别位于标题/正文；WHEN 搜索；THEN 全部词须字面命中，不把 %、_、引号当查询语法，标题命中优先。
- GIVEN 多页同名条目及分类/模型；WHEN 筛选翻页；THEN 稳定无重复，next_offset 仅在还有结果时出现，旧文本数组仍可用。
- GIVEN 索引已建立；WHEN 外部提交新增、修改、删除或替换库文件；THEN 下次查询反映新数据，删除/缺失库不返回旧缓存，源库不被写入。
- GIVEN 广场请求卡住；WHEN ping、本地搜索或取消通知到达；THEN 控制与本地请求可独立完成，已取消结果不返回，后续请求继续工作。
- GIVEN 请求超过等待队列上限；WHEN 继续调用工具；THEN 返回繁忙错误，不创建无限线程或无限排队。

## 范围

仅 MCP 服务；不修改桌面搜索或广场服务的 SQL，不增加语义搜索、远程 HTTP MCP、写工具或自动宿主配置。
