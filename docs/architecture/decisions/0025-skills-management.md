# 25. Skills 文件管理与公开来源

- Status: accepted
- Date: 2026-09-13

## Context

用户批准 Skills 首版方案并要求完整实现测试。它管理外部智能体的文件目录，与提示词数据库不同。

## Decision

采用 [Skills 规格](../../specs/skills/spec.md) 的两组导航、原生文件操作、固定来源提交和独立副本安装。注册表、不可变暂存与持久备份独立保存在应用数据目录；写入串行且每个目标具有独立结果。浏览器不提供假本机数据。只预览说明和文件，不执行包内脚本，不把插件缓存当已启用 Skill。

## Consequences

文件安装就绪不能替代目标客户端的加载验收；未测组合明确说明。共享目录可能被多个工具读取，页面须显示影响范围。公开来源无需账号，受网络与 GitHub 速率限制影响。
