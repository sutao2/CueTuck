# 连续操作页面化

## 计划

用户要求非必要不使用弹窗。沿用主壳和完整设置页，只改桌面交互承载方式，不修改独立启动器。

1. 新建/编辑提示词或合集、使用、合集详情、广场详情、发布、登录及其身份流程、新建分类改为右侧工作区页面。保留顶栏、侧栏与返回入口，内容居中限宽、内部滚动，无背景遮罩和悬浮外框。
2. 主列表隐藏但保留 DOM、查询、筛选、视图与滚动；合集进入成员编辑/使用后可返回合集。收藏触发登录后返回来源，发布触发登录后续接发布。
3. 编辑返回、侧栏切换沿用未保存确认；保存失败保留输入，忙碌禁止重复提交或退出。确认删除/放弃等短暂决定可保留对话框。新建分类不再是阻塞弹窗。
4. 页面不陷阱式循环 Tab；进入聚焦首个编辑控件，返回尽量恢复入口。原有原生命令协议、OAuth 和剪贴板逻辑不变。
5. 更新回归测试并用隔离浏览器验证导航与长内容、浅深色和窄屏；构建并重启真实 macOS 包，正常提交，门禁不绕过。

## Given/When/Then

- GIVEN 本地列表带查询与滚动；WHEN 新建/编辑后取消或保存；THEN 编辑在右侧页面，返回保留查询/筛选/视图/滚动。
- GIVEN 编辑存在未保存内容；WHEN 返回或点击侧栏其他空间；THEN 先确认，继续编辑保留内容，放弃才跳转；保存进行中不离开。
- GIVEN 合集有成员；WHEN 编辑或使用成员后返回；THEN 回到该合集，不丢失成员上下文。
- GIVEN 用户在详情或设置发起登录；WHEN 返回或登录成功；THEN 回到来源页或继续原动作，不叠加多层页面。
- GIVEN 浅深色、小窗口与长内容；WHEN 遍历连续操作页；THEN 没有模态遮罩，主要操作可达，只有必要确认使用 dialog。

- Playwright 隔离内存预览：新建/保存/编辑返回、侧栏未保存确认、新建分类、合集创建与成员编辑返回；浅/深色及 800×600 窄窗口的登录、编辑和变量填写布局通过。未向真实站点提交内容或创建账号。
- macOS debug `.app` 构建成功，真实 WebKit 新建、已有提示词编辑及 Escape 返回通过；本机两条提示词未修改。Rust 既有 unused/dead-code 警告仍在。
- `docs-check` 与 diff 空白检查通过；正常 Git 提交仍需通过仓库 WorkLog 的暂存内容评审门禁，不绕过门禁。
