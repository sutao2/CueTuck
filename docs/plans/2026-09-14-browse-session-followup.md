# 分类统计、翻译与重启会话复验

状态：实施中。

1. 分类切换保留已获取的全广场分类统计，只重置所选结果和分页；首次失败仍显示未知，主动刷新可更新统计。验证延迟请求期间数量不闪空、分类请求参数与分页上限、过期响应隔离。
2. 复现翻译错误并部署已验的个人额度修复，备份数据库后仅更新 API，保留线上配置。验证健康、分类元数据、管理员英文译文请求和完成状态。
3. 实机退出并重开已安装客户端，记录会话恢复结果；如发现并发轮换或凭据读取问题，按认证合同修复，不绕过系统钥匙串权限或落盘明文令牌。

- Given 已取得全局分类统计 When 点击其他分类或搜索 Then 分类数字保持，结果区只请求该条件的第一页，续页不用于计算总量。
- Given 首次尚无统计 When 请求失败 Then 数量为未知，不伪造为零。
- Given 用户已登录 When 退出进程并重新启动 Then 无需重新 OAuth，恢复相同账号；失败区分凭据无效与临时不可读。

关联：[认证](../specs/auth/spec.md)、[工作台](../specs/workbench/spec.md)、[翻译](../specs/translation/spec.md)。

分类回归先红后绿：切换分类中与查询失败时统计闪空已复现，修复后 WorkbenchShell 106 项通过。请求仍只发送所选分类第一页，返回 total 独立于分类统计。已安装 beta.12 完整退出再启动，实机自动恢复原账号，无需 OAuth；仅运行一个正式客户端。翻译实机复现为 429 个人次数限制，当前线上仍为旧 API，正在执行已获明确授权的备份部署。
