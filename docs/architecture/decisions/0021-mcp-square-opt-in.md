# 21. MCP 广场显式启用

- Status: accepted
- Date: 2026-09-08
- Supersedes: [ADR 0011](0011-web-and-mcp.md) 的 MCP 永不联网限制；Web 独立交付决定保持不变。

## Context

用户要求其他智能体能够搜索提示词，并授权继续实施不依赖外部凭据的 P2 计划。默认本地隐私边界仍需保留。

## Decision

保留独立 stdio 和三个本地只读工具；广场工具以启动环境变量显式启用，与本地工具命名及数据流分离。联网只读匿名公共 API，不复用桌面登录令牌、不上传私人内容、不自动读取附件。约束与验收场景统一见 [P2 计划](../../plans/2026-09-08-mcp-square.md)。

## Consequences

新增受限 HTTP 客户端与分页公共接口；默认启动行为兼容原有宿主。桌面只提供路径核验和配置生成，不将 MCP 打包进桌面，不替用户修改第三方宿主配置。
