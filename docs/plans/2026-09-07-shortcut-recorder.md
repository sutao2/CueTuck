# 快捷键按键录入

状态：已实现并完成当前环境验收。原设置的三项快捷键使用普通文本框，无法直接录制组合。

## 实施与验收

1. 共用按键录入控件替换三项文本框；焦点进入后录制，Mac 显示符号，底层保存标准组合名。使用物理键码识别 Option/Shift 组合，不把输入法文本或单独修饰键存成快捷键。
2. Tab/Shift+Tab 导航；Esc 取消本次录入且不关闭设置；普通裸字母不录入，允许功能键。失焦和卸载结束录制。
3. 录制时暂停本应用全局快捷键回调，防止唤起、新建和最近粘贴打断录制；系统保留组合仍可能被系统拦截，不承诺能抢占。
4. 沿用显式保存与注册错误反馈；重复组合保存前拒绝，不扩大到注册事务重构。先补回归，再跑组件和全局回调测试、真实浏览器按键、构建与文档检查，更新桌面包并提交。
