# 本机 Skill 发布修复

## 计划

1. 用带版本号目录复现 export_bundle 名称校验失败。
2. 导出时保留合法目录名，否则使用合法的包元数据名称；两者均不合法时使用 `skill-` 加目录名 SHA-256 前 16 位作为稳定包名。保留全部原文件，不放宽共享校验。
3. 详情页安装与发布按钮复用带间距且可换行的操作行。
4. 验证原生导出/导入、前端发布流程、构建与文档门禁，完成后提交。

## 验收场景

- Given `1password-1.0.1` 目录及合法元数据名 When 导出发布包 Then 使用 `1password`，完整文件可校验并导入，原文件不变。
- Given 中文、空格、超长目录及不合法元数据名 When 导出 Then 生成稳定合法包名，显示名称与 SKILL.md 内容不变。
- Given 已有合法目录名 When 导出 Then 保留现有包名。
- Given 本机详情页 When 查看安装和发布操作 Then 两按钮之间留有间距，窄栏可换行。

## 验证记录

- 新增原生用例在修复前复现“Skill 名称或文件数量无效”，修复后通过；覆盖带版本号、中文、空格、保留字和超长名称，导出/导入文件摘要一致。
- Skills 原生回归 26 项通过，3 项原有外网检查保持忽略；共享文件包校验 3 项通过。使用 Command Line Tools，避免当前 Xcode 许可状态阻塞编译；需绑定本机端口及创建临时特殊文件的用例在授权环境重跑通过。
- SkillsPage 前端 27 项通过，新增版本目录详情直接发布、公开确认及提交包名验证。
- Vite 生产构建、docs-check 和 diff 空白检查通过。按钮复用现有 8px gap / flex-wrap 布局；尚未在 Windows 原生窗口视觉验收。
- 本切片实现后已随 [beta.29](2026-10-12-beta29-release.md) 分发。
