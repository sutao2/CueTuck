# 广场分类数量

## 方案

广场树展示公开条目数量，所有分类数量不随搜索、模型和收藏筛选变化；大分类包含直接归属及子分类，全部包含未分类。数量在首批 browse 响应中由数据库一次 GROUP BY 返回，续页不重复统计，不下载全量内容、不逐分类请求。本地计数不变；未加载/失败显示「—」而非假零。

## 步骤与验收

1. 扩展首批分页元数据：category_counts（直接归属分类到数量）、category_total；续页为 null。验证 online 过滤、空库、超过 48 条及筛选不缩小计数。
2. 侧栏合并子级计数，展示 0 和加载占位，切换空间隔离。验证根/子级/全部准确、本地计数不变。
3. 运行后端/前端测试、构建及真实数据请求测量，更新服务并提交。

## Given/When/Then

- GIVEN 大分类直接归属 2 条、子分类 100 条、下架 1 条 WHEN 加载广场 THEN 大分类为 102，子分类为 100，而非当前页条数。
- GIVEN 正在搜索或查看收藏 WHEN 查看分类树 THEN 仍显示全广场公开数量，并通过标题提示口径。
- GIVEN 首次尚未取得统计且请求失败或未返回 WHEN 查看分类树 THEN 显示「—」，不使用本地数量；取得全局统计后按[后续修复](2026-09-14-browse-session-followup.md)在筛选和续页时保持数量。

## 进度

- 已完成：435 项前端测试通过；后端独立 schema 分页/下架/空库/筛选计数测试通过；本地桌面包构建通过，后端与客户端已更新启动。
- 真实数据：全部 21,775，图片生成 20,397，软件开发 430；首屏仍仅 48 条，响应 33,495 字节（比之前增加 275 字节），续页 category_counts=null。不读取全量提示词来计数。
