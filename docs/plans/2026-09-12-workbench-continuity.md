# 工作台连续操作优化

状态：实施计划已定，按两个切片分别实现、验收和提交。

## 范围与切片

仅调整桌面工作台，不改独立启动器、存储协议和既有视觉系统。

1. 多页整理与返回：增加选择本页、清空选择；同一筛选下翻页保留选择，筛选或空间改变清空；保存与整理刷新保留页码，结果变少只回退到最后有效页；手动翻页滚回内容顶部；整理中禁止翻页与清除筛选。验收跨页选择、合集排除、部分失败、保存返回和末页收缩。
2. 预览修改参数：从预览跳到参数后，主按钮及 Enter 直接更新预览；连续跳转保留该模式及输入；首次填写仍逐步前进。验收默认值、漏填提示、输入法组字与复制忙碌保护。

## Given / When / Then

- GIVEN 本地结果超过一页且混有合集 WHEN 选择本页并翻页继续选择 THEN 仅合并本页提示词，跨页选择保留；清空选择和变更筛选均取消选择。
- GIVEN 用户在第二页阅读或编辑 WHEN 保存后返回或整理刷新 THEN 保留页码与滚动；条目减少时页码不超过最后一页。
- GIVEN 批量整理尚未完成 WHEN 尝试翻页或清除筛选 THEN 控件不可操作，成功项移出选择，失败项仍可重试。
- GIVEN 用户正在预览 WHEN 跳转修改任意参数并按更新预览或 Enter THEN 直接返回更新后的预览，不重复逐项填写，也不提前复制。
- GIVEN 首次填写或输入法组字、复制忙碌 WHEN 按 Enter THEN 保留原逐步填写及防重复提交约束。
