# Skills 创建、社区发布与安装闭环

状态：已实施、测试并部署 API / 管理端；本机 macOS 客户端已更新。用户授权补齐客户端截图中的创建、发布与安装。

## 实施切片

1. 原生创建持久 Skill 草稿（标准 SKILL.md），完整包导出/校验导入复用既有安装预检、多目标安装和备份。包传输合同由 API 与原生共享；不执行内容。
2. 新增独立社区 Skill 投稿表及 API：登录投稿、本人记录/撤回、公开分页/分类/详情/完整包、后台审核。发布保存不可变快照，人工审核后上架；与提示词分开，不伪装 GitHub 来源。公开作者只显示昵称，不暴露邮箱/本机路径。请求标识支持重试去重。
3. 客户端广场分社区与 GitHub 来源，创建/发布入口可见；文件夹安装、备份和目录管理只放本机。创建后可安装或发布；发布前展示全部文件与公开确认、许可和分类。后台增加 Skill 审核页，支持查看说明/文件、通过/退回/下架和原因。
4. 验证共享包边界、持久创建、完整安装、权限/审核可见性/去重、客户端流程与后台；部署 API/管理端，构建客户端。每个独立切片提交，记录实际平台验证范围。

## 数据边界

- 首版社区完整包以有界 JSON（base64 文件）存储 PostgreSQL，最多 25 MiB 原始文件、单文件 10 MiB、1000 文件、16 层；仅详情包接口返回内容，列表返回摘要。暂不引入另一套对象上传协议。
- 名称采用可移植小写英文 slug；拒绝绝对路径、路径穿越、重复/大小写碰撞、Windows 保留名和特殊路径。至少一个 UTF-8 SKILL.md，不能上传链接或读取登记范围外文件。
- 创建保存在 CueTuck 本机草稿目录并登记扫描，失败不覆盖已有内容。发布不修改本机文件。已审批快照内容不可变；更新重新投稿，原作者可撤回。
- 审核为人工，后台可下载完整包检查；不将文件审核或安装就绪称为安全保证或运行成功。GitHub 安装逻辑保持。
- 此次补齐客户端与真实后端，官网静态预览不冒充具备本机安装/账号投稿能力。

## Given / When / Then

- Given 离线且名称未占用 When 创建 Then 重启后可扫描到完整 SKILL.md；同名拒绝覆盖，失败保留编辑内容。
- Given 本机含脚本与资料的 Skill When 发布 Then 登录验证、公开确认和许可齐全，保存全包快照及本人 pending 记录，不立即公开。
- Given 本人重复请求或其他账号 When 重试投稿/查看私有包 Then 同一请求不重复建稿，其他账号不可读；匿名不可投稿。
- Given 待审 Skill When 审核通过/退回/下架 Then 公共列表与包权限一致，本人看到状态和原因；审计记录持久化。
- Given 已上架 Skill When 选择并安装 Then 校验所展示快照，预检目标/冲突，完整文件落地且不执行脚本。
- Given 非法路径、大小写碰撞或超限包 When 上传/安装 Then API 与客户端均拒绝，无越界或半安装。
- Given 广场或本机页面 When 浏览操作 Then 广场有创建/发布/查看并安装，本机才显示目录与备份工具；错误可重试，发布草稿不静默丢失。
