# 26. 统一为 ChatGPT 风格的中性桌面视觉

- Status: accepted
- Date: 2026-10-09
- Supersedes: [ADR 0017](0017-screenshot-workbench-frame.md) 的配色、分隔线和控件外观；其余布局与功能约束保留。

## Context

用户要求整体页面参考新版 ChatGPT，Windows 与 Mac 同步优化。当前页面累积了不同边框、圆角、灰阶和字号，深色侧栏与内容层次也沿用旧 Codex 参考。

## Decision

使用浅灰侧栏、白色内容面；深色采用较暗侧栏与深灰内容面。弱化永久分隔和阴影，用留白、排版与柔和选中背景表达层级。动作按钮圆润，输入区域与卡片使用一致的圆角尺度；主操作采用中性反差，警告和危险操作继续保留语义颜色。

保持四区工作台、现有导航/搜索/分类、完整设置页、原生窗口按钮与独立启动器。两平台共享内容样式，仅保留窗口栏、字体与快捷键的平台差异。不照搬 ChatGPT 的聊天功能或宣称像素级复刻；官网和管理台不做结构改版。

## Consequences

浅深主题变量统一供菜单、弹层和启动器继承，避免内容内外的颜色漂移。保留焦点、禁用、危险状态和紧凑密度；通过跨平台浏览器视觉及现有功能回归验证。系统窗口效果仍需对应原生环境验收。
