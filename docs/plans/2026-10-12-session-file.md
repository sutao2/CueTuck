# 本机登录令牌文件

## 用户决定与计划

用户明确要求登录 token 放配置文件，替代登录钥匙串存储。仅保存 refresh token 到应用数据目录 `auth/session.json`，access token 保持内存，密码不落盘。采用原子替换，Unix 目录 0700、文件 0600，Windows 继承用户应用数据目录 ACL。应用备份/导出及同步不包含认证目录。AI API Key 不属于本次登录存储调整。

不自动访问或修改旧钥匙串，也不后台迁移，避免升级启动再触发系统授权；升级后首次需重新登录，旧条目不会在退出后复活。登录/邮箱与 OAuth 统一文件存储；退出删除文件，服务器明确 401 时清除，临时失败保留。

启动恢复只在连接建立失败时自动等待 1 秒、2 秒重试，最多三次；请求已发出后的超时或响应损坏不能盲目重发轮换 token。恢复过程只读取一次文件。更新登录、设置及中英界面说明，完成回归后提交。

## Given / When / Then

- Given 邮箱或 OAuth 登录成功 When 重启恢复 Then 从应用令牌文件续期，不访问钥匙串、不存账号密码。
- Given 旧版本只有钥匙串登录 When 升级启动 Then 为访客，重新登录一次后持久保存；不读取或删除旧凭据。
- Given 网络尚未连接 When 首次连接失败后网络恢复 Then 有界自动重试恢复会话，失败不清除令牌。
- Given 过期令牌返回 401 或用户退出 When 完成 Then 删除文件，无旧钥匙串回退。
- Given 损坏、超限或链接文件 When 读取 Then 明确失败，不泄漏文件内容；写入失败不破坏原文件。
