# 设置改为应用内页面

## 实施切片

用户提供 Codex 设置截图并明确不要弹窗。先修订 ADR 与规格，再实现：

1. 设置占据主窗口，隐藏但不卸载工作台以保留搜索、分类、视图和滚动；不另开原生窗口。保留系统红绿灯与顶部拖动区。
2. 左侧固定导航：返回应用、搜索设置、十类原有设置。右侧居中限宽表单，内容独立滚动，无遮罩、圆角外框或弹窗焦点陷阱。
3. 搜索按分类名和功能关键词过滤导航，不自动跳页或清除表单；零结果可清空。点击结果进入对应页。
   - 用户追加三张截图后进一步采用细边圆角分组、右对齐控件，以及系统/浅色/深色主题预览卡；主题卡复用真实保存接口，不添加截图中的无关功能。
4. 返回应用/Escape 沿用未保存确认、忙碌保护并恢复入口焦点。二次危险确认和登录仍可使用小弹窗；设置本身不再是 dialog。
5. 验证十页浅深色与窄视口、账号直达、草稿保留、搜索、返回原工作台和键盘录入；全量测试、构建、真实桌面包验收后正常提交。

## Given/When/Then

- GIVEN 工作台已有查询、分类或列表滚动；WHEN 进入设置再返回；THEN 设置占满窗口且原工作台状态保留，账号入口直达账号页。
- GIVEN 设置有未保存输入；WHEN 搜索或切页再返回；THEN 草稿保留，离开先确认；取消继续编辑。
- GIVEN 输入「备份」或「代理」；WHEN 查看搜索结果；THEN 显示相关分类，清空恢复十类，不自动提交。
- GIVEN 浅深色及 800×600/1440×900；WHEN 遍历十页；THEN 系统按钮/返回入口可用，页面无横向溢出，右侧长内容滚动。

## 验证

- 桌面端全量 328 项测试通过，包括完整页面语义、关键词搜索、IME/Escape、未保存确认、返回工作台保留查询与入口焦点，以及主题卡保存与失败回滚。
- 浏览器十页 × 浅深色 × 800×600/1440×900 共 40 组布局通过：返回入口可见，无横向溢出；最后字体和开关尺寸调整后再次检查窄屏外观页无溢出。
- 前端构建与 macOS debug app 打包通过；重启真实桌面包并检查常规页、外观页及返回应用，原有两条提示词保留。未改独立启动器窗口。
- 页面确认遮罩与编辑器忙碌状态使用正确的布尔 `inert` 属性：非忙碌时移除属性，不把 `inert="false"` 错当作解除禁用。
- 文档门禁通过。正常提交仍需 WorkLog 对当前暂存内容评审；不绕过门禁。
