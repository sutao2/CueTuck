# 广场与个人作品数据

- 日期：2026-09-13
- 状态：实现、测试、浏览器与本机部署验收完成

## 范围与切片

1. 分页广场返回 download_count（已记录匿名下载次数）和 favorite_count（当前收藏账号关系数）；只对当前页聚合收藏，使用 item_id 索引，不扩展正文载荷或发逐卡请求。内存测试态同口径。
2. 广场网格与列表显示两项数字；热门说明按已记录下载量降序。缺字段显示「—」，不能把旧服务未返回数据写成零。下载失败/未开启统计、离线收藏排队不能虚增显示数值；数据随重新加载刷新。
3. 我的发布接口返回每条作品统计，待审核未上架为零，曾上架后下架保留历史下载/当前收藏；严格只返回本人作品，不泄露收藏者身份。个人作品页展示投稿数、记录下载总次数、当前收藏总次数，提供原始最新顺序、下载最多与收藏最多的排序。汇总位于账号的「我的发布」入口内，不增加设置打开时的全量请求。
4. 先验证后端准确性、账号隔离与分页，再验证前端数值、排序、失败和缺字段；保持下载统计默认关闭与现有隐私合同。
5. 跑相关测试、浏览器网格/列表及浅深色检查、构建并更新本机后端和客户端，立即提交切片。

## Given / When / Then

- GIVEN 两条下载次数不同的条目与多个账号收藏；WHEN 浏览热门；THEN 按记录下载量排序，数值等于服务端记录，重复收藏不重复计数、取消后减少。
- GIVEN 本人作品已上架、下架或未审核；WHEN 查看我的发布；THEN 只汇总本人作品数据，历史下载保留，未上架统计零，不能看到其他账号投稿或收藏者邮箱。
- GIVEN 请求失败或旧服务缺统计字段；WHEN 查看页面；THEN 显示错误或「—」，不展示假零汇总。
- GIVEN 用户浏览、未开启匿名统计下载或仅把收藏加入离线队列；WHEN 操作完成；THEN 不自行增加服务端统计数字。
