# 下载参考图与大图预览

## 计划

1. 修复单条广场内容 reference.images 未进入下载链路：只读取现行参考图白名单 HTTPS 主机，禁止凭据、自定义端口、重定向，不携带会话。限制 6 图、单图 5 MiB、全部附件 20 MiB / 12 个，校验实际图片签名，转换本地附件，与正文原子导入；任一失败不冒充完整下载。示例图片不属于内容，不能下载到条目。
2. 对已经下载的单条提示词，在广场详情提供显式“补全参考图”。先完整获取后事务追加、按内容去重，不覆盖正文/分类/已有附件；目标删除或来源变化拒绝。合集保留现有成员文件关联，不把合集封面擅自分配给成员。
3. 复用一个轻量大图查看器到广场参考图、公开图片附件、本地图片附件：点击查看、适应窗口/100%/缩放、滚动、关闭及 Esc、键盘焦点回归。保持其他文件只读预览/导出，不执行文件。
4. 前端验证新下载、失败原子性、旧副本补图与幂等；原生验证 URL / 图片类型 / 追加事务；浏览器验证大图和窄屏。构建桌面包，保留用户本地数据，不重置库；更新规格并提交。

## Given / When / Then

- GIVEN 有参考图的单条广场提示词 WHEN 下载 THEN 本地附件包含真实图片字节，断网仍可查看，正文不混入来源信息。
- GIVEN 任一图片损坏/过大/断网 WHEN 下载 THEN 报告失败且没有半份导入，可以重试。
- GIVEN 已下载且正文已编辑 WHEN 补全参考图两次 THEN 正文与已有附件保持原样，图片不重复；失败不写入部分图片。
- GIVEN 广场或本地图片 WHEN 点击大图并缩放/关闭 THEN 显示未裁切图片、可滚动，Esc 只关闭大图并恢复触发点焦点。
