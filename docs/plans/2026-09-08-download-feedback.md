# 广场下载反馈与防重复

## 实施

1. 本地查询返回已有 remote_id，以真实未删除副本恢复下载状态，不凭标题或临时设置猜测。
2. 下载入口先查本地来源并合并同一条目的并发请求；已有提示词（合集以其下载成员为准）不重复创建，不重复计数。历史重复副本不删除。
3. 卡片、详情统一显示下载中/已下载；固定轻提示提供成功/失败反馈与前往本地入口，刷新本地数量不依赖当前空间；统计失败不影响本地成功。
4. 自动测试、桌面构建和实际界面验证后提交。

## 场景

- GIVEN 尚未下载 WHEN 点击下载 THEN 写入成功后出现可见轻提示，卡片和详情显示已下载；失败仍可重试。
- GIVEN 同一条目被快速点击或从另一个入口下载 WHEN 请求完成 THEN 只有一份新增副本，一次统计。
- GIVEN 已有 remote_id 的本地副本 WHEN 重启或切换广场分类 THEN 恢复已下载状态，不因筛选隐藏本地副本而误判。
- GIVEN 同一来源的全部本地提示词已删除 WHEN 再进入广场 THEN 可重新下载；合集尚有成员时不重复导入整套。

## 验证

- 前端 51 个测试文件、355 项测试通过，覆盖忙碌状态、失败重试、重复请求、恢复状态和删除后重新下载。
- Rust 库测试 69 项通过、1 项原有忽略；验证下载来源 ID 的保存和查询返回。
- 桌面 debug 应用构建通过，文档检查 229 份 Markdown 通过。
- Playwright 实测滚动后的卡片下载：固定轻提示可见、按钮禁用且显示已下载、本地数量更新。
- 原生桌面端重启后，已有「自然光群像」「全栈软件开发（英文）」均恢复已下载状态；历史副本保留。
