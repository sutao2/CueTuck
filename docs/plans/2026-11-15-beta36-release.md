# beta.36 应用锁发行验收

1. 固定 beta.36 源提交，构建使用现有签名材料的 Apple Silicon DMG、更新归档和 Windows x64 NSIS、便携 ZIP。
2. Given 在独立测试数据中启用应用锁，When 安装后重启并输入错误口令，Then 工作台保持锁定；正确口令恢复工作台，手动锁定可重复。
3. Given 在已录入的设备上启用系统解锁，When 取消系统验证，Then 保持锁定并可用口令恢复；When 本人完成系统验证，Then 返回工作台。分别记录 Touch ID、Windows Hello 的设备实测与不可用回退。
4. 核验安装、签名和版本。两端安装包及系统验证通过后，按预览通道发布并核验公开下载与更新清单。

## 候选版现场反馈

1. 应用锁移入隐私与安全；顶栏显示开锁按钮，锁屏显示闭锁图标。验证有草稿时的锁定确认。
2. 统一片段编辑器、选择器、标题栏及靛蓝双层卡片图标；所有语言仅用 CueTuck 作为品牌名。验证键盘、浅色与深色布局和原有数据标识。
3. 区分缺少默认钥匙串、授权取消和其他凭据错误；用可用的系统凭据库验证实际保存、读取与删除。完成修改后重新构建两端候选包。
4. 已启用设备解锁且主窗口在前台时，每次进入锁屏自动请求一次；验证取消、设备不可用、主窗口失焦和启动器隔离，再测试口令回退及手动重试。
