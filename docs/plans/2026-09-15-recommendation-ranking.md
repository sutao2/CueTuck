# 推荐轮换与排序

状态：已随 beta.17 发布；交付记录见 [剩余优化闭环](2026-09-15-completion.md)。以下保留该切片实施时的验收记录。

## 设计

- 权重：种子探索 60%、精选标记 20%、30 天线性新鲜度 10%、对数归一化累计下载量 10%；id 次排序。不采集用户画像，不引入模型调用。
- 推荐按精选标记、累计下载热度、30 天新鲜度和确定性随机探索综合排序；默认每小时一轮，桌面/网页「换一批」生成新种子。不使用账号画像，不把累计热度称为近期热度。
- 每轮保存仅包含 ID 的有界服务端快照（两小时、最多 64 轮/总计 50 万 ID）；分页使用同一种子和筛选条件。新发布/指标变化不改动本轮顺序；下架条目实时过滤，分页游标按原快照位置推进，不挤移剩余记录。过期/被回收明确提示重新加载，不混入新一轮。
- 最新按上架时间倒序，热门按累计下载倒序、标题/id 稳定次排序；收藏保持账号隔离。明确页面说明。
- 服务端仅首次排序读取轻量候选元数据；分页只返回最多 48 条摘要，不读取正文。旧 /items 和 MCP /search 保持兼容。
- 独立启动器只消费第一批推荐；桌面、网页传递轮次，筛选/排序改变重置，续页复用，换一批清空旧分页并隔离旧响应。

## 验收场景

- Given 相同种子和筛选 When 重复获取或翻页 Then 顺序稳定且无重漏；换种子有足够候选时顺序变化。
- Given 下载量变化、新增或下架 When 续页 Then 不重复已读记录、不泄漏下架内容，新内容下轮出现。
- Given 快照过期/丢失 When 请求续页 Then 明确提示换一批；不得静默从新列表相同 offset 继续。
- Given 搜索/分类/模型/语言切换或换一批 When 旧请求迟到 Then 不覆盖当前结果。
- Given 最新/热门/收藏 When 查询 Then 各自排序、统计口径与鉴权保持清晰。

## 验证

后端快照单测及真实隔离 PostgreSQL 集成；前端/网页轮次传输与刷新回归；原生编译、前端构建、docs-check。部署发版另行执行。

### 验收结果（2026-09-15）

- 前端 624 项、后端 174 项通过；后端另有 4 项依赖专用外部设施的既有测试未执行。
- 网页接口 7 项通过；真实 Chromium 验证续页种子、换一批重置、最新切换和 390px 窄屏。
- `cargo check`、桌面构建与 docs-check 通过；原生编译有 10 条既有警告。
- 隔离 PostgreSQL 20,000 条候选测试：首批约 321ms、续页约 22ms、首批响应 14,493 字节。为本机测试结果，非线上 SLA。
- 推荐指标变更、新发布、下架、整页下架、快照失效、旧响应迟到均已覆盖；最新同时间使用稳定 ID 次序，热门及收藏鉴权回归通过。
- 线上尚未更新，本切片不含部署或发布。
