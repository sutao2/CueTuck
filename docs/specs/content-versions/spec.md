# 内容版本与更新

状态：存储基础已实现；作者和下载者流程仍为目标，不代表功能已上线。

提示词、合集与社区 Skill 保留稳定公开身份。公开版本采用单调递增编号和不可变快照；当前指针只在审核通过的同一事务中前进，收藏及统计仍引用原 ID。历史版本记录提交标识、基准版本、更新说明及发布时间。相同提交只可对应相同快照，过期基准不得覆盖已发布新版。

旧公开内容补齐 v1 时不修改旧表或合并同名内容；重复迁移不改变已有版本。旧本地副本无确切下载快照时标记未知，不以当前远端内容倒推基准。作者只能更新本人内容，待审、驳回或撤回候选不改变当前公开内容；内容整体下架仍限制历史读取。历史附件须跟随快照保留，不能被清理任务提前回收。

本地下载记录来源 ID、所装版本及基准快照。更新前比较基准、本地与远端，用户明确确认；本地修改冲突必须保留或另存，只有显式备份替换可覆盖。应用/恢复时再次检查本地摘要，防止预览后修改被覆盖。合集成员使用稳定标识关联附件；旧数据不按名称、顺序猜配。社区 Skill 分安装位置更新并沿用路径校验、完整包校验、备份与恢复，不改写外部管理链接。

详细 Given/When/Then 与各阶段验收见[实施计划](../../plans/2026-10-15-content-versioning.md)。
