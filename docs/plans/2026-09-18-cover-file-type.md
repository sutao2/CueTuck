# 合集封面类型修复

状态：已修复并随 beta.19 发布，发行验收见 [beta.19](2026-09-18-beta19-release.md)。

## 步骤

1. 封面按实际字节识别 PNG/JPEG/GIF/WebP，统一生成 MIME 和扩展名，兼容历史封面声明错误；保留原字节及顺序，不改变九宫格布局。
2. 选图时使用相同识别和附件大小校验；读图期间禁止保存，失败保留原封面并显示错误，不静默丢图。
3. 增加格式误标、九图顺序、非法内容及发布往返回归，运行客户端测试和构建后提交。

## 验收

- Given JPEG/WebP/GIF 原字节被标为 PNG When 发布已保存的合集 Then 上传名称、MIME 与实际格式一致，原图不转码。
- Given 九张混合格式封面 When 上传和下载 Then 数量、顺序和九宫格布局不变。
- Given 不支持的字节或超限文件 When 选择封面 Then 当场提示错误且保留旧封面，不能绕过原有附件校验。
- Given 封面正在读取 When 保存 Then 等待读取完成，不保存过期封面。

## 验证结果

- 旧实现复现：JPEG 内容标为 PNG 导致发布调用未发生，混合封面无法通过附件校验；新增用例先失败后通过。
- 客户端 106 个测试文件、654 项全量回归与生产构建通过；涵盖九张混合格式、原字节与顺序保留、误标封面上传/下载往返、无效内容/超限拒绝、读取期间禁止保存及失败保留。
- 文档检查 331 份通过。只修改客户端，无服务端部署需求；现有已安装版本需更新至 beta.19 才能获得修复。
