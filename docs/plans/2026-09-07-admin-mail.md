## 安全设计与合同

- owner 当前密码重新认证后保存 revision 配置。字段为服务器、端口、TLS 模式（隐式 TLS 或强制 STARTTLS）、发件人、用户名、密码、启停；凭据复用 AEAD 密钥，密钥缺失不得生成替代文件。配置响应/历史/审计不含密码或密文；修改后旧测试不代表当前可用。
- SMTP 使用 [Lettre 异步连接](https://docs.rs/lettre/latest/lettre/transport/smtp/client/struct.AsyncSmtpConnection.html)。DNS 验证全部地址为公网并连接已校验 IP，TLS 证书/SNI 使用原域名；只允许 465/587，不允许禁用证书检查、明文或降级。整个发送最多 20 秒，不回显 SMTP 原始响应。测试可显式注入本机模拟连接，运行配置无绕过开关。
- 保存不会发信。显式测试只向输入的一个邮箱发送固定说明；注册/邀请等使用固定模板，不开放任意正文群发接口。SMTP 接受不等于用户收件箱送达，页面标记“服务器已接受”。
- 持久化 outbox 保存加密邮件载荷，元数据为用途/收件人/状态/尝试次数/过期时间；管理 API 不返回正文、验证凭据、SMTP 密钥。队列与相关业务事务同时写入。
- worker 通过 SKIP LOCKED 认领、租约和认领代号避免多实例并发重复认领；网络调用不持有数据库锁。重试最多 3 次、退避并有期限，过期验证邮件不再发送。SMTP 无端到端幂等，进程在发送成功但确认落库前崩溃可能重复投递，同一验证凭据仍只可使用一次；明确记录此边界。
- 手动重试仅针对失败记录、owner、限流、带版本/审计，不修改收件人或载荷。服务端停用时暂停队列；旧配置版本邮件不擅自切换发件身份，要求重新发起。

## 任务与验收

1. 先写配置校验/密文/权限/密码/版本、投递 lease/重试/过期/并发失败用例，再实现表和 API。
2. 验证 TLS/STARTTLS 拒绝降级、私网拒绝、SMTP 拒绝/超时不假报发送成功；仅本机隔离服务，不给现有用户发测试邮件。
3. 管理端表单、显式单收件人测试、记录列表/筛选/分页与重试；失败保留草稿，窄屏和权限检查。
4. 后端 worker 与重启恢复，先独立验证；注册、邀请与找回业务另写认证切片计划后接入。
5. 自动测试、构建、浏览器、文档检查后正常提交。真实 SMTP 凭据由用户配置后单列验证。

## Given/When/Then

- GIVEN 未配置 SMTP 或配置错误；WHEN 测试；THEN 显示不可用/失败，不创建“已送达”的虚假记录。
- GIVEN 多 worker、租约过期或进程重启；WHEN 处理邮件；THEN 只有当前认领者可确认状态，失败退避可追溯，过期邮件不发送。
- GIVEN 旧版本或错误密码；WHEN 保存/重试；THEN 拒绝且无秘密泄漏，业务与审计写入原子完成。
