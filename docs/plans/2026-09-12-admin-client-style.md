# 管理端对齐客户端视觉

## 范围与计划

只改管理端呈现与导航组织，复用客户端的中性配色、字体、滚动条与线性图标。保留全部 20 个管理页面、登录流程、权限矩阵、草稿离开保护和写入锁；不修改后端或运行中配置，不新增弹窗。

1. 使用客户端 tokens / AppIcon，统一灰白侧栏、紧凑顶栏、中性主按钮、细边框、焦点和反馈。登录改为简洁单页，不保留绿色宣传大屏。
2. 导航分为工作空间、内容与目录、智能审核、站点与接入、系统，沿用 permittedPage 过滤权限；账号固定底部，导航和正文独立滚动。列表适当宽，配置限宽阅读。
3. 统一全部配置/表格子页的硬编码颜色、表单密度和圆角，保留危险动作的红色语义；移动宽度下导航有界滚动，表格在自身区域横向滚动。
4. 单测验证三个角色导航完整、无空分组，沿用全部管理端回归。Playwright 使用隔离测试会话/数据，检验登录、列表、配置、概览及窄屏，绝不提交真实管理操作。构建、文档检查后提交。

## Given / When / Then

- GIVEN 任意管理角色 WHEN 展示分组导航 THEN 仅出现有权限的页面，没有功能遗漏，写入时不能跳页。
- GIVEN 内容列表或长配置 WHEN 调整浏览器宽高 THEN 侧栏账号与主要操作可达，正文和表格分别滚动，页面不被长文本撑宽。
- GIVEN 登录/保存失败或危险操作 WHEN 页面展示 THEN 保持清晰的错误、禁用、确认与键盘焦点，不因风格改造弱化保护。

## 验收

- 已完成客户端 tokens、品牌图片和线性图标复用，20 页入口分组与权限保留；配置限宽、独立滚动，切页回到正文顶部。
- 管理端 100 项测试通过（含三个角色的完整导航与无空分组、离开保护和滚动复位），生产构建通过。客户端图标相关 5 项测试通过。
- `scripts/admin-browser-smoke.mjs` 使用隔离 API / 会话验证登录、列表返回、驳回、失败保存及重试、退出；截图检查登录、站点配置，以及概览 / 广场内容 / OAuth 在 1440、800、390 宽度下的布局，验证正文不横向溢出、底部账号不被裁切。此验证不代表第三方登录、邮件等真实外部服务已配置或联调。
- 文档检查通过；真实管理数据和运行配置未修改。
