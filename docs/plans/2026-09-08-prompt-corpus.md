# 公开提示词批量筛选与本机导入

## 范围

用户清空旧内容后要求继续寻找有用提示词，目标为万条级，图片类优先附对应效果图。仅向本机开发广场追加；不恢复旧库、不改账号设置、不向生产发布。

## 实施与验收

1. 从公开开源仓库及 DiffusionDB 获取许可与数据快照，记录 URL、版本/哈希、数量。遵守公开访问边界，不使用 YouMind 私有 CMS 密钥或禁止抓取的 API。
2. 正文保留原始提示词，不追加来源、作者、许可说明；来源与许可仅放 reference 和独立许可文件。优先采用 CC0 数据，不能把仓库许可解释为所有第三方素材的商用保证。
3. 筛除空白、过短、重复/近似变体、明显危险或成人内容及低置信安全评分，按主题归类；自动筛选和人工抽查分别报告，不声称逐条人工验收。
4. 固定本机 Docker 数据库目标，先备份、验证全部字段和字典，再事务追加；重复运行不增副本。公开原始快照、候选与筛选报告保存在 output，脚本与规格提交 Git。
5. 大列表按固定页大小渲染，筛选变更回到第一页，完整结果计数不截断；测试分页、筛选、下载正文无附加尾注，并实测导入数量与接口响应。

## 场景

- GIVEN 同一正文含大小写/空白变体 WHEN 筛选 THEN 只保留一条，统计去重数量。
- GIVEN 元数据评分缺失或不达标 WHEN 处理图片提示词 THEN 拒绝，不能以缺失当作安全。
- GIVEN 条目有来源信息 WHEN 下载复制 THEN 正文无导入器附加说明，来源仍可在广场 reference 查阅。
- GIVEN 万条列表 WHEN 浏览/切换筛选 THEN 一次渲染不超过 48 张卡片，页码重置，全部内容仍可检索。
- GIVEN 同一批数据再次导入 WHEN 事务提交 THEN 新增零条，现有内容和账号设置不变。

## 验收（2026-09-09）

- 扫描 DiffusionDB 2,000,000 条元数据，规则合格 35,905 条；按信息量排序、规范化去重和主题前缀/词集去重后选取 20,000 条。安全分数必须存在且双方均不高于 0.05；排除低信息量、明显风险词、重复长段落和不合理参数。不是逐条人工审核或安全保证。
- prompts.chat 2,169 条候选保留 1,653 条；YouMind 公开 README 的 129 条保留 122 条。总计 **21,775 条**，其中图片类 **20,397 条**，仅 **122 条带来源配对参考图**。其余不伪造图，不把未抓取的图片算作已有附件。DiffusionDB 为 2022 年 Stable Diffusion 数据，不宣称现代模型实测效果。
- 抽查 21 条大库正文，追加重复片段/夸张镜头参数过滤与标题提取；通用风景、插画不再统一归到人像。未知图片模型不填成某个已知模型，难以判定用途的任务不默认塞进生活类。
- 本机分两次新增 1,775、20,000 条；随后同包重放新增 **0**。SQL 校验 id/正文唯一数均为 21,775，带图条目 122；两个账号、禁用旧种子设置保留。个人 SQLite 不写入。
- 抽查 11 个来源图 URL 均返回 200 和 image/jpeg；浏览器首屏实测显示来源配图，第二页可返回。完整广场显示 21,775 / 454 页，每页最多 48 条。完整列表仍为一次请求（约 18.2 MB、本机一次测量 1.07 秒），当前只限制 DOM 数量，不冒称服务端分页；继续扩容需另做有界服务端分页。
- 427 项客户端测试、2 项导入器测试、5 项筛选器测试通过；桌面调试包构建成功。原生窗口因电脑锁屏未重启，解锁后重启才能加载新包；浏览器验收不冒称原生验收。
