# 客户端侧栏调宽

## 范围与步骤

用户反馈侧栏无法拖拽。本切片实现侧栏右边缘调整宽度，不涉及分类排序或独立启动器。ADR 0017 的 260px 保留为默认宽度，不改写已接受的 ADR。

1. 在工作台增加独立分隔条，使用 pointer capture；拖动不触发原生窗口移动。
2. 顶栏和侧栏共用宽度；范围 200–400 CSS px，并为内容保留至少 560px（极窄宿主以侧栏最小值优先）。当前窗口生命周期内保留用户宽度，收起不重置。
3. 分隔条可聚焦，用左右方向键调宽；pointercancel、失焦和卸载结束拖动。窗口缩小时限制显示宽度，放大后恢复偏好宽度。
4. 回归组件测试、构建、文档检查，并在真实桌面包验证拖动、折叠和顶栏对齐。

## 验收场景

- GIVEN 侧栏展开；WHEN 拖动右侧边缘；THEN 侧栏和顶栏同步调宽，主窗口不移动。
- GIVEN 拖动超过范围或窗口缩窄；WHEN 继续拖动；THEN 宽度受限，不允许把内容挤到不可用。
- GIVEN 已调宽；WHEN 收起再展开；THEN 保留当前宽度。
- GIVEN 正在拖动；WHEN 松开、取消或失焦；THEN 后续指针移动不再改变宽度。
- GIVEN 分隔条获得键盘焦点；WHEN 按左右方向键；THEN 有界调宽，辅助技术可读取当前值。
