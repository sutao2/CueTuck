# 桌面应用锁

- Given 本机尚未启用应用锁，When 打开工作台或启动器，Then 原有入口可直接使用。在设置 → 隐私与安全 → 应用锁设置并确认至少八个字符的口令后启用，独立保存随机盐和 PBKDF2 校验值。
- Given 已启用，When 重启桌面应用或点击全局搜索旁的开锁图标，Then 主窗口和启动器停止展示工作内容。业务命令须先通过原生锁状态检查，运行中已注册的启动器、快捷新建和最近粘贴快捷键带回主窗口解锁。
- Given 锁定，When 在主窗口提交正确口令，Then 本次会话解锁。更改口令、关闭保护或修改系统验证选项均需原口令。
- Given 用户已启用设备验证，When 点击系统解锁，Then macOS 调用 Touch ID，Windows 调用设备提供的 Windows Hello 验证方式。系统成功验证才解锁，取消或不可用时可继续用口令。
- Given 启用应用锁，When 配套 MCP 客户端请求本机提示词，Then 即使此前建立过缓存也拒绝读取。应用锁只控制应用访问，普通提示词、导出文件及既有备份仍使用各自原有格式。

- Given 已锁定，When 显示解锁页，Then 顶栏显示闭锁图标，口令和设备验证继续在主窗口处理。
