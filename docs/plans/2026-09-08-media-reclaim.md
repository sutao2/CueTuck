# P1e 云端未引用附件回收

状态：本地验收完成。保守补齐手动回收，不扫描或清空存储桶。

## 实施步骤

1. media_objects 追加 deleting 与 last_used_at；旧记录 last_used_at 初始化为迁移时间（不直接回收历史对象）。只选择 ready、完整元数据、标准 promptark/media.UUID 对象键且超过 7 天未复用的对象。未完成上传保持人工排查，不计入本片回收。
2. 全部 library_changes（含软删除）以及全部 publications（含驳回/下架）中的 asset_refs 都算引用。没有引用的已完成对象才列为候选；目录不显示凭据、对象键或下载链接。系统状态页显式读取最多 25 项，单项确认后清理，不自动运行。只允许配置管理员。
3. PostgreSQL 事务级、按实例隔离的媒体锁串行化上传复用、同步引用写入、投稿插入和回收声明。声明前重新验证权限、年龄与引用，标 deleting 并写审计后提交；引用校验必须在相同锁内，拒绝 deleting 对象。上传复用更新 last_used_at 并提交租期，避免复用后尚未提交快照的窗口被回收。
4. 仅删除该记录已校验的标准对象键，不接受客户端路径。存储请求有界且拒绝重定向；成功或 404 才删除数据库记录并写完成审计。存储/数据库失败保留 deleting 记录，可再次显式重试；不能撤销 deleting 以免未知存储结果的对象被重新引用。两次清理可安全重试；不访问其他键。
5. 私有及公开下载拒绝 deleting 状态。既有引用始终阻止声明；数据库声明与引用写入的并发测试证明不能出现已引用对象被删。UI 取消无请求、错误保留候选和重试、忙碌防重复、重查冲突不冒充成功。
6. 隔离 PostgreSQL 与对象存储验证，相关全量回归/构建后独立提交。不得对本机真实用户对象执行清理。

## Given / When / Then

- GIVEN 新上传、上传中、迁移前未知元数据或被任意历史快照引用；WHEN 读取候选或伪造 ID 执行；THEN 不列出且不得删除。
- GIVEN 无引用且过期的完成对象；WHEN 管理员确认；THEN 精确删除对象、释放配额、记录审计，其他对象不变。
- GIVEN 普通用户、审核员或撤销权限；WHEN 列表/清理；THEN 拒绝，不请求存储。
- GIVEN 候选已被复用或新增引用；WHEN 使用旧列表清理；THEN 冲突保留文件。
- GIVEN 回收先声明；WHEN 同步/投稿并发建立引用；THEN 拒绝新引用，不保存悬空快照。
- GIVEN 存储失败或删除后数据库失败；WHEN 清理；THEN 明确失败并保留可重试状态；重试不误删别的文件。
- GIVEN 前端确认区；WHEN 取消或连续点击；THEN 取消不请求，忙碌时只发送一次；失败保留候选和错误。

## 边界

离线设备尚未提交的草稿不在服务器引用范围；7 天保护期不能识别无限期离线草稿。确认区告知备份，回收不删除本地文件，但离线草稿可能需要重新上传。保留所有历史引用，不提供强制解除引用、历史稿件清除、存储桶扫描、上传中残留自动清理或自动定时回收。已删除对象不能通过应用撤销，恢复依赖运维备份。
