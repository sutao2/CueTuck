# 自动审核实施切片

| 字段 | 值 |
|---|---|
| 状态 | 本地初筛切片已验证；外部 AI/图片检查仍按人工降级，下一切片接入 |
| 范围 | A15 发布限额、重复/结构/规则检查、自动通过与转人工；A16/A17 接口在后续切片实现 |

## 设计边界

- 默认关闭自动审核，保留人工队列。开关、日限额（1–1000）、低风险通过阈值、高风险转人工阈值、重复/结构/敏感词/图片检查与需要 AI 开关由 owner 配置，带版本并审计。
- 启用时发布事务先复核登录/禁用状态、取得作者锁与分类锁，再按真实 24 小时记录检查限额。重复只比较已主动提交的标题/正文/合集成员，不查私有同步库。
- 确定性初筛返回规则集版本、配置版本、命中解释。图片审核和 AI 尚未接通时，开启对应要求就进入人工，不伪造图片或模型通过。只有明确不要求 AI、结构完整、未触发人工条件且低于通过阈值时允许“本地规则自动通过”，事件操作者明确标为系统。
- 投稿、初筛结果、自动上架（如有）、审核事件和审计同事务；失败整体回滚，不产生部分成功。人工审核复用原有状态竞争保护；系统不能覆盖先前人工结论。
- 新增结果 JSONB 保存版本/风险/理由，不保存密钥或外部原始响应。旧投稿为 null，不回填假历史。作者仅看到可公开结果，管理员可查看实际检查依据。

## 步骤与验收

1. 写隔离数据库用例：关闭时 pending；启用且仅本地规则时可明确自动通过；命中、高风险、缺结构、重复、图片/AI 不可用时 pending；限额原子并发拒绝。
2. 增量配置表、投稿结果字段；提取投稿事务写入与审核事务内部操作，既有 API 行为和测试不变。
3. 实现 owner 配置 API 与管理页；失败保留草稿，缺数据库不能保存默认值。审核页展示实际初筛状态与理由。
4. 验证绕过客户端直接投稿同样执行规则，禁用账号/撤销会话不能写；审计故障整单回滚，重启配置保持。
5. 自动化、浏览器、构建和文档门禁后正常提交，不跳过评审门禁；继续后续 AI 服务配置与 Skills 切片。

## 场景

- GIVEN 未配置 AI 或图片检测；WHEN 策略要求该检查；THEN 风险结果明确待人工，不能自动上架。
- GIVEN 同作者并发提交且只剩一个配额；WHEN 提交两份；THEN 仅一份成功，另一份 429。
- GIVEN 自动通过但审计故障；WHEN 提交；THEN 投稿、广场、事件均回滚。
