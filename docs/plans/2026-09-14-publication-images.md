# 投稿图片可见性与 GIF 检查

状态：实施中。用户反馈本地图片投稿后广场不显示，并询问 GIF。

1. 保留显式选择公开附件：增加图片缩略预览、全选图片、选中数量与仅文字提醒，避免误以为本机图片默认公开。提交仍只发送选中附件。
2. 分页列表为已批准在线稿件返回首张图片附件元数据及图片/文件数量，不能带文件字节或正文；客户端沿用受鉴权的公开附件接口按可见区域加载，图集展示同一清单图片。未批准、下架及未选附件不泄漏。
3. GIF 原字节保留，列表本地派生缩略图静态，原图使用浏览器图片播放；追加多帧保留测试。验证投稿选中清单、列表封面、详情图集、失败重试及原有附件下载权限回归。

不修改历史稿件清单，不从作者本机自动补传；历史漏选图片需用户重新提交并审核。API 变更仍待 SSH 授权后部署。

代码验收：568 项前端测试、164 项后端单元测试通过（4 项既有显式忽略）；新增原生 GIF 多帧保留测试通过。测试覆盖图片显式选择、详情无外部参考图时的图集、失败重试和旧请求隔离、三路并发与有界缓存、分页首图及未审核/下架访问隔离。列表为附件封面预留空间，避免图片加载后卡片被裁切。API 尚未部署；历史漏选的附件不会被静默补传。

本机 beta.12 已安装；原生实测用户已发布的“鹈鹕骑自行车的 2D 动画”实际带 1.8 MB PNG，旧版仅在附件列表显示，新版详情图集已自动加载。进一步将图集改为完整适应，避免单图被横向裁切。封面接口仍待服务端部署。
