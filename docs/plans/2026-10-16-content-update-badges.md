# 下载内容新版提醒

## 范围与步骤

1. 只读检查已关联且版本已知的提示词、合集、社区 Skill；相同来源合并请求，最多三个并发，五分钟缓存。后台不读取包或写本地文件。
2. 本地列表显示“有新版”，点击进入既有比较和确认流程；Skill 按安装位置比较版本，任一位置落后则列表显示角标。
3. 进入页面、回到前台及可见页面每五分钟检查；关闭广场访问、断网、未知版本不误报。会话变化丢弃旧请求结果。
4. 回归已修改副本、未知旧数据、多安装位置、确认前无写入，并完成前端门禁后提交。

## Given / When / Then

- Given 已下载 v1，When 广场 v2，Then 显示有新版但不改变本地正文。
- Given 同一 Skill 分别安装 v1 / v2，When 广场 v2，Then 仅 v1 位置提示。
- Given 旧下载没有版本，When 后台检查，Then 不猜测版本，不自动替换。
- Given 检查失败或切换账号，When 旧请求返回，Then 不复用无效结果。
- Given 用户点击角标，When 比较完成，Then 仍需明确确认才能备份替换。
