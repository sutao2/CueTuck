# 17. 按用户 Codex 截图细化主窗口框架

- Status: superseded（仅搜索位置与用途，由 [ADR 0022](0022-global-search.md) 替代；其余框架决策继续适用）
- Date: 2026-09-06
- 关联：[ADR 0016](0016-workbench-frame-and-settings.md) · [工作台规格](../../specs/workbench/spec.md)

## Context

用户提供了正在使用的 Codex 主窗口截图。可确认其窗口操作行与侧栏品牌行分离，侧栏和内容面以贯通直线分隔，深色侧栏比内容面稍亮；前版品牌挤在系统窗口操作行，内容区圆角套框不符合这张参考。

## Decision

在 ADR 0016 的四区与功能约束下细化主窗口：顶栏左侧仅保留固定侧栏折叠按钮和系统窗口按钮预留区；品牌和启动器搜索归侧栏首行，顶栏内容侧显示空间图标和当前位置，侧栏收起时顶栏提供搜索入口。采用 260px 侧栏、贯通的细分隔线、无外边距和圆角套框的内容面、底部账号分隔行。深色使用较亮侧栏和更深内容面，浅色保留对应层级；不强制改变用户主题选择。

不添加截图中的聊天、前进/后退、PR、通知或环境检查面板占位。它们不属于提示词工作台现有操作。设置继续遵循 ADR 0016，本图不作为设置页布局依据。独立启动器及数据行为不变。

## Consequences

需要验证品牌/搜索归属、折叠前后按钮坐标、侧栏收起仍能搜索、直线分栏、两种主题和窄窗口，保留新建、编辑、搜索、分类与设置操作。截图用于布局参考，不声称复刻所有 Codex 页面。
