# 24. 启动器精简复制操作

- Status: accepted
- Date: 2026-09-13
- Supersedes: [ADR 0023](0023-launcher-explicit-actions.md) 的快捷操作与粘贴入口部分

## Context

用户反馈启动器粘贴到原窗口不可用，且复制当前输入无实际价值，明确要求移除两者。

## Decision

启动器输入快捷操作仅保留创建提示词、AI 优化、搜索广场；最终文本仍可复制。移除填写页粘贴按钮及相关调用分支。0023 的独立窗口、显式联网、本机 AI 凭据与草稿边界保持不变。单独的快速粘贴最近使用全局快捷键不在本次移除范围内。

## Consequences

填写页不再需要依赖目标应用聚焦和辅助功能权限；现有共享原生粘贴能力仍供独立全局快捷键使用。
