# 本地列表缩略图

## 计划

1. 本地单条提示词以第一张已保存图片作为封面；网格沿用广场 150px 封面高度，行视图使用紧凑缩略图，无图片保持文本布局。点击缩略图打开已有大图查看器，标题仍进入编辑。
2. 列表查询仍只返回计数。可见卡片按需读取单张图片，不读取全部附件、不联网；离开可见区释放图片，重新保存后重新读取，异步旧结果不能覆盖新条目。沿用现有本地分页，无新增数据库结构。
3. 验证无图/多图/删除/失败、按需读取与旧请求隔离，浏览器网格/行视图和大图返回；构建桌面包并提交。

## Given / When / Then

- GIVEN 本地条目含多张图片及文档 WHEN 浏览列表 THEN 仅使用第一张图片，不读取其余附件，离线可见。
- GIVEN 卡片不在可见区域 WHEN 浏览其他条目 THEN 不加载该图片；移出区域后释放已加载图片。
- GIVEN 切换条目或保存替换图片 WHEN 旧请求晚返回 THEN 不显示旧图；删除最后一张图片后恢复文本卡片。
- GIVEN 点击缩略图 WHEN 查看并关闭大图 THEN 返回列表而不是进入编辑；点击标题仍可编辑。

## 验收

- 前端 446 项、原生 81 项测试通过；覆盖可见区读取/释放、修改后重读、旧请求隔离、读取/图片失败及只读取首张图、软删除排除。
- 隔离浏览器实际下载后，网格和行视图显示本地缩略图，点击打开大图、Esc 返回列表、标题进入编辑均通过；800px 窄窗口行缩略图 80px、无横向溢出，网格封面高度与广场一致。截图已检查。
- macOS 调试包构建成功；本轮未重启正在运行的客户端，等待用户确认保存编辑。未修改真实本地条目或附件。
