# P1a 私有附件传输基础

状态：P1a 代码、本地存储往返与权限验证已完成；属于[本地完善队列](2026-09-08-local-completion.md) P1 的第一片，不代表附件同步或公开投稿已接通。

## 决定与步骤

1. 复用既有 MinIO 和 media_objects，不另建文件服务。上传仅接受单个 multipart file；保存文件名、类型、字节数和 SHA-256。白名单与单文件 5 MiB 上限对齐本地附件；禁止路径文件名、HTML/SVG、伪装类型，整请求上限 6 MiB。
2. 私有对象必须由有效会话的所有者访问（其他账号含管理员不隐式获权）。旧匿名预签名接口改为鉴权后返回相对 API 路径；新增鉴权字节下载，由后端代理、限时、限长和校验哈希，禁止客户端取得可转发的存储签名 URL。
3. Postgres 仅追加元数据字段；旧对象不删除，元数据缺失时不冒充完整附件。数据库不可用时不上传。每账号最多 256 对象 / 100 MiB（含上传中预留），账号行锁下预留配额，完成上传才标 ready；失败时先清理本次新对象，确认清理成功再撤销预留。崩溃或清理失败留下记录供排查，不自动扫描/删除历史对象。
4. 不信任对象存储返回的类型/长度；下载强制 attachment、nosniff、no-store。存储请求不跟随重定向，15 秒超时。写入或完成登记失败不返回成功。上传响应丢失的跨请求幂等和未引用对象回收留待引用接入切片，不能把此接口直接当自动同步队列。
5. 隔离 PostgreSQL schema 与本机存储/替身验证所有者隔离、无会话、停用、重启、大小/内容校验、失败清理与字节往返；更新 API 合同和前端合同测试，再提交。

## Given / When / Then

- GIVEN 用户 A 上传一个有效文件；WHEN A 读取或重启后读取；THEN 字节数及 SHA-256 一致，不暴露存储凭据/签名 URL。
- GIVEN 用户 B、管理员或无令牌；WHEN 请求 A 的地址或内容；THEN 无令牌 401，非所有者统一 404，存储不收到 GET。
- GIVEN 停用或撤销会话；WHEN 再用 API 路径下载；THEN 拒绝，而不是依赖旧签名链接到期。
- GIVEN 多 file、非法名称、类型伪装或超限文件；WHEN 上传；THEN 拒绝且没有对象登记。
- GIVEN 同账号配额临界且并发上传；WHEN 预留；THEN 配额原子受限，不因并发突破。
- GIVEN 存储故障、哈希不符或返回超长正文；WHEN 传输；THEN 失败，不返回伪成功或未验证字节；其他人的对象不受影响。

## 下一片

P1b 在此基础上设计附件引用清单、上传重试幂等和显式同步开关。私人文件默认不自动公开，投稿必须显式选择；获准公开后通过与条目可见性绑定的代理读取，不能复用私有下载链接。现有本地附件/备份继续可用，发布和同步仍不发送文件。

存储桶必须禁止匿名读取，不能将媒体桶设为公开来实现广场图片。旧版本已经发出的预签名 URL 最多仍有原 600 秒有效期；更新 API 不会追溯撤销它们，本轮不轮换存储密钥。
