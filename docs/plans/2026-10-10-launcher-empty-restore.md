# 恢复空输入启动器搜索栏

## 设计（已完成）

用户澄清固定尺寸仅指展开后的窗口。空输入且无反馈时恢复 64px 搜索栏，不显示引导、列表或底栏；输入后搜索等待、零/少/多结果、填写和草稿仍统一使用所选展开尺寸。清空恢复搜索栏，原生窗口顶部不移动。错误反馈仍展开以便阅读。

## 验收场景

- Given 初始或清空查询且无反馈 When 搜索态显示 Then 高度 64，仅显示搜索栏。
- Given 有输入 When 等待或返回不同数量结果、进入填写和返回 Then 保持所选展开高度，不随结果数变化。
- Given 初始化错误或操作反馈 When 查询为空 Then 展开反馈，不将错误藏在搜索栏中。

## 记录

57 项前端回归、12 项原生启动器测试、生产构建及文档门禁通过。Playwright 实测：初始 64、单条搜索 420、填写 420、清空 64。原生配置初始高度同步恢复 64，展开尺寸仍来自设置；已随 beta.28 发布，见[发行记录](2026-10-10-beta28-release.md)。
