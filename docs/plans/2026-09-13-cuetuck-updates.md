# CueTuck 品牌、更新与可搜索选择器

## 实施顺序

1. 统一当前产品展示为 CueTuck · 唤词，英文标语 Your prompts, a shortcut away.；重命名公开 GitHub 仓库及发布入口。保留旧版应用 identifier、数据库及凭据命名作为兼容协议，历史 ADR/发布记录不改写。工作目录和线上持久卷不随展示改名迁移。
2. 完成签名更新包发布、后台检查、侧栏提醒、设置页状态、下载字节进度、失败重试及用户确认安装。自动下载只下载和验证，安装必须显式触发；预览构建默认预览通道。语言切换仅在设置保留。
3. 给发布来源/分类/模型，以及编辑、筛选、批量整理等长选项选择器增加搜索、键盘操作、清空与空结果。两项偏好开关继续直接选择。
4. 回归、原生构建、更新签名校验和双平台发布；每个切片更新规格并提交。

## 验收场景

- GIVEN 旧版已有本地数据与凭据 WHEN 安装 CueTuck THEN 数据继续可读，当前页面/窗口/安装包/仓库使用新名称。
- GIVEN 主窗口打开 WHEN 后台发现更高可用版本 THEN 侧栏提示可更新，语言切换位于设置，点击提示进入更新页。
- GIVEN 更新可下载 WHEN 用户下载或已开启自动下载 THEN 显示真实字节进度，不自动安装；失败可重试且不声称最新。
- GIVEN 下载完成且签名验证通过 WHEN 用户确认安装并重启 THEN 安装匹配版本与平台的包；签名不符、旧版、下载未完成不得安装。
- GIVEN 有大量发布来源、分类或模型 WHEN 输入关键词或用方向键 THEN 筛选匹配选项，Enter 确认，Escape 关闭且不修改原值；空结果提示可清空。
