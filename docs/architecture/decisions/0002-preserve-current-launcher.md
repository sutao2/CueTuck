# 2. 保留旧启动器实现

- Status: accepted
- Date: 2026-08-22
- 关联：[启动器规格](../../specs/launcher/spec.md)

## Context

原型里的快捷搜索是主窗口上的覆盖层。旧产品的启动器是独立 Tauri 窗口，含失焦隐藏、焦点交还、粘贴到活动应用、macOS 选中文本，已经过真实桌面约束打磨。

## Decision

只移植旧启动器代码：独立窗口、全局快捷键、本地即时搜索、变量填写、复制、粘贴与降级。不采用原型覆盖层作为启动器实现。

## Consequences

- 主窗口与启动器视觉可以不一致。
- 启动器数据口必须接到新 SQLite，而不是旧 repository 整文件照搬。
- 原型启动器文案与范围切换仅作产品参考，不是实现合同。
