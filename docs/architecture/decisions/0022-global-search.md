# 22. 全局搜索与页面筛选分离

- Status: accepted
- Date: 2026-09-13
- 关联：[工作台规格](../../specs/workbench/spec.md) · [ADR 0017](0017-screenshot-workbench-frame.md) · [ADR 0020](0020-workspace-pages.md)

## Context

顶栏、侧栏与页面内搜索均聚焦同一筛选框，用户无法跨分类或跨空间查找，入口语义重复。

## Decision

右上角只保留「全局搜索」入口，Cmd/Ctrl+K 打开独立临时查找面板，侧栏品牌行不再放搜索。Cmd/Ctrl+F 仍聚焦页面内筛选。面板默认查全部本地提示词和合集，显式切换到广场才联网；查询不继承底层页面条件。最多展示 48 条并提示进一步细化，广场复用现有有界读取和访问开关。

临时查找面板是 ADR 0020 页面规则的有限补充：仅用于输入、选择和取消，不承载编辑、详情或使用流程。取消不改变底层页面；选择结果使用现有页面和草稿离开保护。保留焦点约束、键盘选择、输入法保护及请求取消。原生独立启动器不受影响。

## Consequences

仅替代 ADR 0017 的搜索位置和用途，框架其余决策继续适用；不改变 ADR 0020 的连续操作页面规则。需验证入口分工、跨范围结果打开、设置/编辑草稿保护和离线状态。
