# 本机 Skill 发布选择同步

## 计划

1. 复现详情进入发布页时文件包已加载但选择框为空。
2. 同步当前安装路径与发布选择框，保留完整文件包校验、切换来源及公开确认。
3. 验证普通详情及已有安装预览后的发布路径、切换来源、提交回归；通过后提交。

## 验收

- Given 本机 Skill 详情（含同名不同目录） When 点击发布到社区 Then 自动选中当前安装路径并准备完整文件包，无需再次选择。
- Given 详情已有准备好的安装包 When 点击发布 Then 选择框仍显示当前 Skill。
- Given 已带入当前 Skill When 选择其他 Skill 并确认选择 Then 校验新文件包，重新要求公开确认，提交新文件包。
