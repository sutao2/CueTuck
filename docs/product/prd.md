## 1. 定位

面向 AI 高频用户的本地优先提示词工作台。日常路径是：在主窗口整理或从广场下载提示词，用全局启动器搜索、填写变量，复制或粘贴到当前应用。

气质：像轻量编辑器一样安静，像启动器一样随叫随到。

## 2. 设计与代码来源

| 来源 | 用途 | 不是 |
|---|---|---|
| `../PromptLauncher/提示词软件 2` | 主窗口、弹窗、分类、合集、使用向导的交互与视觉 | 启动器实现 |
| `../PromptLauncher/prompt-launcher` 启动器窗口与 Tauri 命令 | 独立启动器、快捷键、粘贴、失焦隐藏、本地搜索 | 主窗口、路由、Atelier Zero 壳 |
| 旧 Spring Boot / admin-web | 后期可复用的参考，不是第一期依赖 | 第一期运行时 |

## 3. 用户与权限（第一期）

| 操作 | 离线未登录 | 说明 |
|---|---|---|
| 浏览、增删改本地提示词与合集 | 可以 | 数据在本机 SQLite |
| 使用启动器搜索、填写、复制、粘贴 | 可以 | 不等待网络 |
| 浏览广场、下载、收藏、发布 | 不可以 | 第一期不做在线能力 |

登录、广场、发布的完整权限矩阵在 [广场规格](../specs/square/spec.md) 与 [发布规格](../specs/publish/spec.md)，于接入后端的里程碑生效。

## 4. 第一期必须交付

### 主窗口

- 顶栏、左侧「本地提示词」空间、两级分类树、卡片网格/列表、底栏
- 本地提示词新建、编辑、删除、搜索、分类
- 合集：创建、封面、内含提示词、详情
- 从正文识别 `{{变量名}}`，使用向导逐步填写后复制
- 设置：常规、快捷键、数据与备份、外观（本机设置，无账号同步）

### 启动器

- 独立 Tauri 窗口，全局快捷键唤起
- 输入即搜本地提示词，方向键选择
- Enter 进入填写或预览；修饰键 + Enter 直接复制
- 填写后复制或粘贴到活动应用；粘贴失败时明确降级为仅复制
- macOS 可读选中文本并填入变量；其他平台不展示该能力

### 数据

- 本地 SQLite，软删除
- JSON 导入预览与导出、备份与恢复
- 访客工作区即可使用，不要求注册

## 5. 明确不做（第一期）

- 广场浏览、匿名下载、收藏、发布审核
- OAuth（Google / GitHub / QQ / LinuxDo）与云同步
- 订阅、兑换码、管理后台
- 完整 Web 个人库、移动端
- 把启动器改成主窗口内覆盖层
- 在旧 `PromptLauncher` 仓库里继续改主应用

## 6. 非功能

| 类别 | 要求 |
|---|---|
| 性能 | 1 万条本地提示词下启动器查询 < 50ms |
| 离线 | 断网时本地库与启动器 100% 可用 |
| 可访问 | 核心路径键盘可完成；弹窗焦点不逃逸 |
| 安全 | 无私有内容默认外传；无密钥进仓库 |
| 文档 | 每个 MUST 能指到测试或发行 QA |
| 兼容 | 以开发者本机（macOS）为第一验证面；Windows / Linux 在桌面里程碑再做 smoke |
