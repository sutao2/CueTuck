## 设计边界

- owner/admin 可管理广场条目，reviewer 只能审核，不得操作已发布内容。
- 列表支持关键词、状态与分页；详情只读提交正文，可改广场展示摘要、系统分类、模型、推荐和排序权重，不改作者标题/正文/合集成员和私有库。模型暂为有长度限制的文本，字典管理在后续切片。
- 状态 online/offline/trashed；下架不删除，上架保留同一 ID，移入回收站保留收藏/下载计数，回收站恢复为 offline 后明确上架，不提供永久删除。
- 每次编辑带 revision（从 0 起）；事务内验证当前角色、令牌及版本，旧版本返回 409，防止并发覆盖。状态改变须提供原因，审计与数据一起提交。
- 公开列表、详情、正文、收藏列表和下载计数统一排除 offline/trashed；已下载副本不受影响。已知 ID 不能绕过下架。关闭匿名浏览后登录仍可访问，匿名详情/正文 401、列表为空（兼容旧客户端）。配置/数据库失败不默认放行。
- 推荐优先后按权重/id稳定排序；最新列表独立按上架时间，不被推荐权重颠倒。旧条目没有日期保留 null。
- 启动种子检查表内是否存在任意状态条目，不能把「全部下架」当成空库重新灌入或清空。
- 作者的我的发布同步返回广场可见状态，审核通过不等于当前仍在线。
