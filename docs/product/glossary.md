# 术语

一个词只在这里定义。规格里用词必须与本表一致。

| 术语 | 含义 |
|---|---|
| 提示方舟 / PromptArk | 本产品与本仓库的名字 |
| 旧仓库 | `../PromptLauncher`，只读参考 |
| 原型 | `../PromptLauncher/提示词软件 2` 静态页面 |
| 主窗口 | 桌面主 Webview，工作台与设置所在窗口 |
| 启动器 | 独立 Tauri 窗口，全局快捷键唤起，不是主窗口覆盖层 |
| 工作台 | 主窗口中「广场 / 本地」切换后的内容区 |
| 空间 | 广场或本地 |
| 大分类 | 分类树第一级，例如「软件开发」 |
| 小分类 | 分类树第二级，例如「前端工程」 |
| 合集 | 一组提示词的容器，可有单图或九宫格封面 |
| 提示词 | 一条可搜索、可填写变量、可复制的文本模板 |
| 变量 | 正文中 `{{名称}}` 占位，使用前填写 |
| 使用向导 | 逐步填写变量并预览最终文本的流程 |
| 浏览器工作台 | 独立浏览器里的工作台 SPA，不是桌面安装包，不是原生移动应用 |
| MCP 服务 | 给 Codex 等宿主用的本机 stdio 服务，查询并渲染本地提示词 |
| 下载 | 把远端提示词复制到本地 SQLite，`source=downloaded`，不要求登录 |
| 收藏 | 账号级远端关系；未登录只开登录，不写本地副本 |
| 发布 | 把本地内容提交到广场审核，不锁、不删本地正文 |
| 现行规格 | `docs/specs/` 中描述今天必须为真的行为 |
| 变更 | `docs/changes/<name>/` 中尚未合并的提案 |
| 门禁 | CI 或发行前必须通过的检查 |
| MADR | 本仓库 ADR 使用的精简决策记录格式 |
