# 启动器搜索面板精修

## 范围与设计（已完成）

依据用户 Windows 实机截图：结果优先，辅助操作压缩为次级列表；统一线性图标、简短分组和真实摘要，变量数量替代重复类型标签。Windows 保持不透明原生独立窗口与系统阴影，降低客户区边框强度。

搜索高度随结果数变化，以所选尺寸为上限，顶部保持固定；空查询 64，填写和草稿仍采用完整所选尺寸。等待搜索时保留上次高度，避免每次按键先收再展开。正文不生成虚构简介。

## 验收场景

- Given 单条/零条/多条结果 When 输入查询 Then 搜索窗口按内容展开、多条到上限后滚动，三个辅助操作均可键盘到达。
- Given 正在搜索 When 后续输入尚未返回 Then 不因临时空结果收缩；迟到结果不覆盖当前查询。
- Given 单条带重复变量的提示词 When 展示结果 Then 图标无 VAR/TXT 字样，数量按唯一变量计算，摘要去除开头的角色标记但不更改存储正文。
- Given 搜索进入填写或创建 When 返回 Then 恢复当前结果高度和高亮，不重新定位。
- Given 中英文及明暗主题 When 显示搜索面板 Then 标签完整、底栏不溢出、选中状态清晰。

## 实施与验证

已完成前端层级、原生可选高度接口及上下限约束；搜索等待期间保留已展开高度，首次搜索仍显示加载状态。

- 55 项前端回归通过：搜索、排序、快捷操作、变量填写、失焦恢复、偏好和窗口接口。
- 14 项 Rust 启动器测试通过，新增搜索高度上下限、无效值和填写尺寸隔离。
- `npm run build` 与 `./scripts/docs-check` 通过。
- Playwright Windows 平台样式预览：620 宽，单条结果 342 高，两条 406 高；浅色中文、深色英文结果区无溢出。截图位于 `output/playwright/launcher-polish-windows-light.png` 和 `launcher-polish-windows-dark-en.png`。
- Windows 原生系统阴影保持不变；客户区细边框降低强度。DPI 与原生窗口外观需实机复验，本轮未发布安装包。
