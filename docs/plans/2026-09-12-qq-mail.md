# QQ / Foxmail 邮件配置

## 计划

沿用已有 SMTP 配置、owner 重认证、加密存储与测试投递功能，不新增另一套邮件服务。

1. 管理端添加显式 QQ / Foxmail 参数按钮，仅设置主机 smtp.qq.com、465、隐式 TLS；保留发件人、用户名、秘密和启停草稿，不自动保存或发信。
2. 标明 QQ 邮箱使用授权码而非登录密码，提供邮箱服务开启提示。补充参数及不自动写入的回归，使用隔离浏览器数据检查页面。
3. 用户提供 owner 当前密码后通过已有 API 保存真实配置；未提供时明确等待，不绕过重认证。只有用户确认后才向指定邮箱发固定测试邮件，SMTP 接受不等于收件箱送达。

## Given / When / Then

- GIVEN 配置页加载成功 WHEN 点击 QQ / Foxmail 参数 THEN 只更新连接参数，保留账号与凭据草稿，不调用保存或测试 API。
- GIVEN 配置加载失败或正在写入 WHEN 查看快捷入口 THEN 不允许写入默认参数。
- GIVEN QQ 主机 WHEN 填写密码 THEN 明确要求邮箱授权码，保存仍要求 owner 当前密码且不回显已保存密钥。

## 验收

- 管理端快捷参数和授权码说明完成；101 项测试、生产构建、文档检查通过。
- 隔离浏览器验证快捷填充、不自动保存、放弃草稿和退出，并检查 1440 / 390 宽度下邮件页无横向溢出。夹具不含真实凭据，不向外部发信。
- 真实配置等待用户提供 owner 当前密码，真实测试邮件等待明确确认；尚未保存用户 SMTP，未声称连通或投递成功。真实邮箱、授权码不进入代码、测试夹具或 Git。
