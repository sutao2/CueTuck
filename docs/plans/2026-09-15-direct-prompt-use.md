# 提示词直接使用

状态：已实现验收，未发版。

## 范围

1. 广场卡片读取完整正文后直接使用；详情和合集成员使用当前显示语言。无变量直接复制，有变量填写预览；复制失败保留正文供重试。
2. 独立启动器的广场结果进入相同填写/复制流程，合集仍打开详情选择成员，保留明确的查看详情入口。
3. 广场使用不下载附件、不新增本地内容、不记录本地使用或增加下载次数。缺失译文沿用界面可见原文；不得自动付费生成译文。
4. 去掉广场更多菜单中的查看详情及本地重复复制按钮；创建副本明确为「创建本地副本」。

## 验收

- Given 列表只有截断摘要 When 点击使用 Then 读取完整内容及已就绪中文版本，复制完整正文，不写库、不计下载。
- Given 详情选择英文或合集成员版本 When 使用 Then 填写和复制该版本，返回详情保持选择。
- Given 本地详情切换译文 When 使用 Then 使用可见译文，原始本地内容不变。
- Given 网络/剪贴板失败或详情关闭后旧请求返回 When 完成操作 Then 明确报错或忽略旧响应，不误报成功。
- Given 启动器显式搜索广场 When 回车选中 Then 读取正文并填写/复制，合集打开详情，默认本地搜索不联网。
- Given 广场卡片/本地卡片 When 展示操作 Then 主要入口无重复，空正文不改剪贴板。

## 检查

组件/平台回归覆盖语言、变量、剪贴板、异步失效及只读边界；前端全量测试、构建、docs-check。部署与发行不属于本次请求。

- Vite production build 与 docs-check 通过，git diff --check 无空白错误。

- 独立启动器页面显式搜索广场后回车填写、末项 Enter 实际复制中文，仍无本地副本；展示搜索结果及填写页的查看详情入口。
