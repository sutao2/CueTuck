## 实现设计

- 认证请求采用 60 秒窗口：全实例最多 300 次、同真实连接 IP 60 次、同邮箱登录或同操作者重新认证 10 次。限制的是尝试，不因成功清零，防止并发绕过；不存在邮箱使用相同限制和错误。返回 429 和 Retry-After，不进行后续密码运算。
- Postgres 原子计数并在多进程/重启间共享；键使用带作用域的 SHA-256，不保存原邮箱/IP/密码。到期清理。数据库故障拒绝认证，不降级绕过；纯内存测试模式使用同样语义。只信任连接对端，不信任客户端自填 X-Forwarded-For，反向代理部署须另设网关限制。
- 管理页使用白名单 hash 地址，支持直接打开、返回/前进；刷新后按现行内存会话约定重新登录，随后回到请求页面，不把令牌写入 Web Storage。角色无权访问的地址回审核页并说明。
- API 401 统一清空登录和敏感草稿；旧请求不能清空新登录或向新会话注入数据。403 保留会话并显示权限错误。
- 导航/退出/浏览器关闭前检查当前表单草稿和提交状态；保存中禁止站内导航；未保存离开须确认。设置读取失败禁止用默认值保存覆盖服务器。
