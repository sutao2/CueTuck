# 桌面滚动条与组合控件焦点

状态：已实现，滚动与焦点验收完成；原生模型菜单键盘选项切换仍需手工复验。

## 实施与验收

1. 在主窗口与独立启动器共用样式中统一滚动条：窄轨道、圆角滑块、透明背景、浅深色适配；保留原生滚动、拖动及键盘能力，不隐藏滚动条或增加自制滚动组件。
2. 实际滚动容器预留稳定滚动槽，启动器变量表单增加右侧安全间距；检查侧栏、内容区、设置导航和正文、编辑弹窗、文本域、结果列表与预览。
3. 模型筛选仍为原生 select，仅去掉内部外观与重复描边；组合控件只在外层提供单一键盘焦点提示，搜索框同样不叠加焦点圈。
4. 浏览器验收浅深色、长内容滚动和模型键盘选择；复跑全部前端测试，原生隔离包复验，更新正式桌面包、规格与索引后提交。不改窗口尺寸、业务数据或复制行为。
