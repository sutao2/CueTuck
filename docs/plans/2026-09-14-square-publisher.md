# 广场详情发布者署名

状态：实施中。

1. 详情接口为已批准稿件关联发布账号的公开显示名与简介；不返回登录邮箱、角色或凭据。无昵称使用“未设置昵称”，导入条目无发布账号时返回空；既有来源作者保持独立。
2. 原生转发保留 publisher 字段，详情标题下展示发布者署名、头像首字和可选简介；导入内容展示已有来源作者，不能把来源作者误称发布者。旧服务兼容无字段。
3. 测试数据库公开字段、缺省昵称、下架权限、原生转发与界面；部署 API、构建安装并实际验证。

- Given 已审核公开的社区稿件 When 查看详情 Then 显示当前公开昵称和简介，不暴露账号邮箱；修改公开资料后下次读取更新。
- Given 昵称为空 When 查看详情 Then 明确显示未设置昵称，不拿登录邮箱替代。
- Given 开源导入条目 When 查看详情 Then 显示来源作者，不虚构本平台发布账号。
- Given 下架或未批准内容 When 请求详情 Then 保持现有不可见性，不提供发布者信息。
