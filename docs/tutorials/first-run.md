# 教程：从文档开始

本教程带你走完 M0，不涉及安装桌面应用。

## 你会得到什么

知道现行合同在哪、怎样查门禁、怎样避免读错文件。

## 步骤

1. 打开仓库根目录的 `README.md`，确认阶段是文档先行。
2. 打开 `docs/INDEX.md`，找到「宪法」和「产品需求」。
3. 读宪法第 3 条和第 11 条：启动器保留旧实现；第一期不接后端。
4. 在终端运行 `./scripts/docs-check`，确认通过。
5. 若你要做的是「本地提示词」，只再打开 `docs/specs/library/spec.md`，不要打开广场规格。

## 下一步

等 M0 关闭后，实现计划会出现在 `docs/plans/`。在那之前不要创建 `src/`。
