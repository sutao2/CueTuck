# 工作台页面与交互优化

状态：计划已完成，按以下四个切片实施和独立提交；验收结果在各片完成后补充。

## 范围与设计

延续现有桌面视觉和独立启动器。本轮仅修改 desktop 主工作台，不改变 Web、后台或同步合同。主搜索框保留，重复入口弱化；阅读、使用与编辑分开。新能力复用现有本地存储和操作反馈，不自动投稿。

## 实施切片

1. 浏览与使用衔接：本地卡片打开只读详情；卡片更多菜单与右键共享动作；无变量直接复制；已下载打开本地副本；缩减页头说明、空库新建/导入/广场入口；移除真实详情的排版示例入口。验证只读不写入、复制失败不计数、重复下载不增副本及合集定位。
2. 编写与填写：逐步填写增加参数导航、未填提示及预览跳回修改；编辑器支持选区插入变量、试填预览，预览不写库/不计使用。验证跳转保留输入、默认值、原正文不变、取消和忙碌保护。
3. 整理：合集可搜索并多选加入；本地提示词可批量移动分类/加入合集；明确成功与失败项，只重试失败项，刷新失败不重复写入。验证选择范围、保留正文附件、重复提交和部分失败。
4. 设置与账号：账号入口可直接进入我的发布页面；复用原发布列表及操作；导入支持选择/拖入 JSON 文件、预览后确认；恢复支持原生文件选择，保留手输高级入口。验证取消不写库、非法文件提示、账号切换及原设置能力。

## Given / When / Then

- GIVEN 本地列表或合集成员 WHEN 点击标题 THEN 展示只读正文与附件，编辑需显式点击；返回保留父级页面。
- GIVEN 无变量提示词 WHEN 直接复制 THEN 成功才记录使用，失败保留当前页面并提示。
- GIVEN 已下载广场内容 WHEN 点击打开本地副本 THEN 打开对应提示词或合集，不请求重新下载；副本消失时恢复下载状态。
- GIVEN 多个参数 WHEN 从任意填写步或预览跳转 THEN 当前输入先保留，未填项可辨识，仍可逐步填写。
- GIVEN 编辑正文 WHEN 插入变量或试填 THEN 选区正确替换，预览不覆盖正文、不保存、不记录使用。
- GIVEN 本地多选或合集选人 WHEN 执行整理 THEN 只操作选中提示词，失败项保留可重试，成功项不重复提交；正文附件不变。
- GIVEN JSON 文件或备份路径 WHEN 选择/拖入或取消 THEN 选择后可预览、确认才导入/恢复，取消不改变已有输入和数据。
- GIVEN 已登录账号 WHEN 打开我的发布 THEN 在工作台页面查看本账号稿件，设置中不重复维护第二份列表。
