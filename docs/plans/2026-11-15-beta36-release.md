# beta.36 应用锁发行验收

1. 固定 beta.36 源提交，构建使用现有签名材料的 Apple Silicon DMG、更新归档和 Windows x64 NSIS、便携 ZIP。
2. Given 在独立测试数据中启用应用锁，When 安装后重启并输入错误口令，Then 工作台保持锁定；正确口令恢复工作台，手动锁定可重复。
3. Given 在已录入的设备上启用系统解锁，When 取消系统验证，Then 保持锁定并可用口令恢复；When 本人完成系统验证，Then 返回工作台。分别记录 Touch ID、Windows Hello 的设备实测与不可用回退。
4. 核验安装、签名和版本。Windows 安装口令通过正式应用的系统辅助功能控件验收；需要复验时，使用打包工作流的 `retest_run` 在新虚拟机上安装同一附件，并记录其 SHA256。两端安装包及系统验证通过后，按预览通道发布并核验公开下载与更新清单。

## 候选版现场反馈

1. 应用锁移入隐私与安全；顶栏显示开锁按钮，锁屏显示闭锁图标。验证有草稿时的锁定确认。
2. 统一片段编辑器、选择器、标题栏及浅色底的双环图标；所有语言仅用 CueTuck 作为品牌名。验证键盘、浅色与深色布局和原有数据标识。
3. 区分缺少默认钥匙串、授权取消和其他凭据错误；用可用的系统凭据库验证实际保存、读取与删除。完成修改后重新构建两端候选包。
4. 已启用设备解锁且主窗口在前台时，每次进入锁屏自动请求一次；默认隐藏口令表单，通过主按钮下方右对齐的文字按钮切换。验证取消、设备不可用、主窗口失焦和启动器隔离，再测试口令回退及手动重试。

## 安装验收记录

- 紧凑锁屏候选源码 `4780326`，[全量回归](https://github.com/sutao2/CueTuck/actions/runs/43718496311)与桌面前端 744 项通过。macOS 原生库 157 项通过，正常登录用户的钥匙串与指定的独立测试钥匙串均通过随机密码保存、读回和删除，SQLite 正文字段为空。通过已安装应用的常用片段表单保存密码，核对了默认遮挡、显示、再次遮挡与删除。
- Apple Silicon DMG 通过磁盘映像校验、固定签名身份和版本核对。更新归档通过应用内置公钥验证，修改一个字节后验签失败。
- 已启用 Touch ID 的 Mac 在锁屏进入前台时自动弹出原生验证，用户现场确认触碰后直接进入工作台。同源 DMG 取消原生验证后仍停在锁屏并显示口令回退。
- 通过设置启用独立测试口令；顶栏小锁可锁定，错误口令被拒绝，正确口令进入工作台。经 Launch Services 打开升级后的安装版仍先要求解锁，原口令可继续使用。开启设备验证时首屏只显示设备按钮与文字切换入口。
- 双环版 DMG 与更新归档内的 ICNS 均与品牌源资源一致。重新安装后实测紧凑锁屏，可用回车提交错误或正确口令；已启用 Touch ID 的测试配置显示设备主按钮与右下角口令入口。浏览器组件验收检查了深色设备模式与 320 × 220 窄窗中的滚动、回车和错误反馈。
- Windows x64 通过原生测试、便携启动、NSIS 安装、窗口最大化/还原/最小化/关闭。初次安装验收的设置导航未完成；[同一安装包复验](https://github.com/sutao2/CueTuck/actions/runs/43719588012)通过设置口令、手动锁定、错误与正确口令、重启解锁和卸载。安装包 SHA-256 为 `45897b87cc8d4149558ecf864b4f2a31c5ba85f5770fad050e4d638ccd6c223b`。
