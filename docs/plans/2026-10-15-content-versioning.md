# 内容版本与安全更新

## 目标与边界

提示词、合集、社区 Skill 统一支持作者发布更新和下载者安全升级。保留现有公开 ID、链接及统计，不按名称合并；GitHub Skill 继续原更新流程。本轮不自动部署。

## 分阶段切片

1. 版本基础与旧数据兼容：增加不可变公开快照和当前版本指针，幂等收录旧公开内容为 v1；来源未知的本地副本不伪造基准。验证重复迁移、重复请求、过期基准和事务回滚。
2. 作者更新与审核：原发布项选择更新、填写说明、比较差异、提交独立候选版本；审核期间旧版保持；批准时锁定原版本并原子切换。拒绝、撤回、权限与审核并发不影响旧版；回退历史内容按新版本发布。
3. 下载来源与本地更新：持久化内容 ID、所装版本和下载快照；更新检查和差异预览，显式选择保留、另存或备份替换。写入前重新比较本地摘要，更新与备份同事务；恢复也检查并发修改。社区 Skill 按安装位置校验/备份/替换，复用原生安装保护。
4. 合集成员与附件：稳定成员标识，不以标题或排序匹配；旧成员无可靠关联时只允许保留或另存，不自动删除。新版删除成员而本地已修改时保留该成员；附件及封面随确定版本读取。
5. 接口、UI、兼容和全链路验收：老客户端继续获取当前公开内容；旧 API 默认首次投稿。后台、前端、原生与隔离数据库端到端回归，分别提交切片，全部验收后才可发行。

## Given / When / Then

- Given 旧公开条目 When 重复执行迁移 Then 原 ID/正文/统计不变，仅补齐一次 v1。
- Given 旧下载无版本基准 When 检查更新 Then 标记版本未知，不把当前线上内容冒认为下载时快照，不直接覆盖。
- Given 已发布 v1 When 提交 v2 待审或驳回 Then v1 继续可读；批准后同 ID 指向 v2，v1 可追溯。
- Given 相同提交重试 When 快照相同 Then 幂等；不同内容或过期基准 Then 冲突，不覆盖新版。
- Given 他人内容 When 提交更新 Then 拒绝；审核者修改内容身份也拒绝。
- Given 本地未修改 When 确认更新 Then 先备份再应用，失败保持旧版。
- Given 本地已修改或预览后再次修改 When 更新 Then 明确冲突，不静默覆盖。
- Given 合集成员改名/换序/新增/移除 When 更新 Then 使用稳定标识关联；无法证明的旧映射保守处理。
- Given 多处 Skill 安装 When 更新 Then 分位置操作和反馈，不改外部管理链接，不运行包内脚本。
