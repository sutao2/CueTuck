## 协议与边界

采用管理员明确配置的 Chat Completions 兼容 HTTPS 接口，不绑定某个模型名，不自动填写或购买 API 凭据。核对 [官方请求和结果格式](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)：发送 model/messages、非流式 JSON 结果，服务端再次验证 risk_score/decision/reasons/matched_rules；不能将合法 JSON 等同于合法审核结果。兼容接口与 OpenAI 新项目优先使用 Responses 的建议用途不同。

- 配置与凭据写入仅 owner，要求当前密码；列表不返回密钥/密文。复用后端 AEAD 密钥并按配置 ID 绑定附加认证数据，修改凭据或端点立即清除旧测试状态。已存任何加密配置时丢失密钥必须停止启动，不能生成新密钥覆盖。
- 只接受 HTTPS、无用户信息/片段/查询参数。发送前 DNS 解析所有目标，拒绝回环、私网、链路本地、组播、保留地址；绑定已校验地址，禁止环境代理和重定向，限制响应体/超时/重试。仅测试代码可显式注入隔离 loopback 服务，不提供运行时关闭安全检查选项。
- 文本发送前可脱敏邮箱、疑似令牌等；结果只存结构化结论，不回显提供商错误正文。配置/测试和主动投稿是明确发送边界；本地私有库不触发调用。测试按钮标明将发送指定样本。
- 主备路由按优先级尝试，双模型一致或三模型多数需要足够独立启用配置；任何必须结果缺失、超时、非法结构都转人工，不捏造分数。整个链路有限时，所有 HTTP 调用在数据库事务外。
- Skills 每次保存追加新版本，保留历史；支持名称、提示词、适用提示词/合集、远端分类、启停、路由方式。测试使用所选已保存版本；历史判定携带实际模型/Skill/规则/策略版本。
- 发布先安全持久化 pending/本地初筛，再执行有限时 AI；模型失败保留人工任务。最终写入时锁定投稿并复核策略/规则/模型/Skill 版本，不覆盖人工先到结论；审核状态、上架、历史与审计同事务。进程中断留下 pending 供人工处理，不声称已自动审核。
- 图片链接不由模型配置自动当作看过图片；只有显式支持且完成实际图片输入检查才可消除图片待人工标记。

## 步骤与验收

1. 先写网络目标、JSON 输出验证、模型权限/密文/版本、Skills 历史用例，再实现增量表/API。
2. 实现有界 HTTP 适配器与真实本机模拟服务测试（正确响应、拒绝、超时、非法 JSON、超长、跳转），无真实凭据不发送外部请求。
3. 管理端模型与 Skills 页面：完整表单、加密凭据提示、配置/已测试状态、显式测试、版本、错误/草稿/权限和窄屏。
4. 联动投稿与审核页，测试主备/一致/多数/失败、人工并发及版本变化不能自动上架；审核结果仅含可公开信息。
5. 自动化/浏览器/构建/文档后正常提交；真实外部授权与能力验收单列，不用模拟服务冒充生产验证。

## Given/When/Then

- GIVEN owner 保存密钥后重新加载；WHEN 查看配置/审计；THEN 不含明文或密文，错误密码/非 owner 不写入。
- GIVEN 端点解析为私网或返回重定向；WHEN 测试；THEN 拒绝且不跟随，密钥不发送到第二目标。
- GIVEN 模型返回不合结构或链路少一个必要结果；WHEN 运行审核；THEN 转人工且说明失败来源，不自动通过。
- GIVEN AI 运行期间管理员已驳回或策略已变更；WHEN 收到旧结果；THEN 不覆盖人工判定或沿用旧策略自动上架。
