# 客户端交互补齐

## 范围与实施顺序

用户授权优化上一轮五项建议，并反馈登录后账号入口仍打开登录表单。本轮不扩大到服务端身份机制或新账号中心。

1. 登录入口按真实会话分流：未登录打开登录，已登录直接打开现有设置的「账号与广场」页；退出失败反馈与重复操作保护，退出后刷新账号和收藏状态。
2. 提示词/合集编辑新增未保存关闭确认，继续编辑保留全部输入；保存中禁止关闭/删除，失败不丢输入。本轮先防误关闭，不引入跨重启自动草稿存储。
3. 广场搜索 250ms 防抖，输入法组字不请求，清空立即查询；本地搜索即时但组字结束再执行。分类/模型字典每次进入广场或显式刷新更新，连续输入不重复取字典；旧请求不能覆盖新查询。
4. 本地设置保存侧栏宽度、折叠状态、网格/列表；初始化完成后才写入，坏值回退默认。拖动结束再写，不逐像素写 SQLite。
5. 分类箭头仅展开/收起，名称仅筛选；保留键盘可操作名称和展开状态。
6. 系统主题 change 监听只在跟随系统时更新；手动主题不受影响，卸载清理监听。构建并在桌面验证。

## Given/When/Then

- GIVEN 已登录；WHEN 点击侧栏账号；THEN 显示当前邮箱与退出入口，不显示密码表单；未登录仍可登录。
- GIVEN 编辑内容发生变化；WHEN 关闭/遮罩/Escape；THEN 先确认，继续编辑不丢内容；未改动直接退出，保存中不允许离开。
- GIVEN 连续输入或中文组字；WHEN 搜索广场；THEN 仅最终稳定文本发出列表请求，不重复获取字典；旧结果不覆盖新结果。
- GIVEN 已调整布局；WHEN 重建工作台；THEN 恢复有效偏好，首次读取不被默认值覆盖。
- GIVEN 大分类展开且当前筛选为其他类；WHEN 点箭头；THEN 只改变展开状态；点名称仅改变筛选。
- GIVEN 主题跟随系统/手动选择；WHEN 系统切换主题；THEN 仅跟随模式实时更新。
