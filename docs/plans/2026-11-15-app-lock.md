# 应用锁与密码片段

1. 在桌面数据目录单独保存加盐口令校验值。主窗口与启动器共用原生锁状态，启用后重启锁定。验证首次启用、错误口令、手动锁定、重启及关闭应用锁。
2. 接入 macOS Touch ID 和 Windows Hello。仅由主窗口发起系统验证，取消或不可用时保留口令入口。核对原生接口，分别记录能覆盖的编译、自动测试和设备验收范围。
3. 在本机工作区分列提示词、片段和 Skills，整理广场入口。密码仅按需显示或复制，失焦、切页及超时重新隐藏。验证现有添加、搜索和复制流程。
