# 23. 启动器显式联网与本机 AI

- Status: accepted
- Date: 2026-09-13
- 关联：[启动器规格](../../specs/launcher/spec.md) · [交互计划](../../plans/2026-09-13-interactions-launcher-ai.md)

## Context

用户要求独立启动器增加创建提示词、AI 优化和广场搜索，并明确客户端用户自行配置供应商及模型。

## Decision

保留 ADR 0002 的独立原生窗口、本地即时搜索和粘贴边界；扩大快捷操作范围。默认输入仅搜本地，显式选择广场后才请求有界公开搜索；返回本地或关闭取消旧查询。点击远端结果在主工作台打开详情并遵循未保存保护，不下载或投稿。

AI 优化只发送当前输入到用户保存的兼容端点，不读取整个库或使用服务端审核密钥。配置整体保存到系统凭据库，返回前端只含端点、模型和是否有密钥；不进入 SQLite、JSON 备份或云同步。端点变更须提供新密钥，不能静默携带旧凭据。支持 HTTPS 和用户本机 HTTP 接口，禁止重定向，请求/响应有界。

优化结果保留原输入，编辑后显式采用或保存。快捷创建在独立窗口完成，显式保存才写本地库；另提供复制当前输入。关闭清理草稿，失焦暂存草稿。

## Consequences

启动器规格中绝对禁止广场请求的旧约束由显式用户操作取代，默认本地及禁止管理接口保持。没有系统凭据库后端的平台不能冒充安全保存成功。图片临时预览使用居中对话框，连续编辑/详情仍遵循 ADR 0020 页面方式。
