# 提示方舟应用图标

状态：已完成设计、资源替换与本地 macOS 应用打包。

## 设计与实施

1. 延续现有深青绿品牌，以白色折纸方舟表达收纳与调用提示词；无文字、无细碎装饰，透明外边缘、圆角方形底座，适合 macOS Dock。
2. 使用内置 imagegen 生成栅格源图，保存到仓库；通过 Tauri 图标工具派生 PNG、ICO、ICNS，不手工分别绘制不同版本。
3. 替换打包图标，并使启动器的品牌占位块使用同源图标；保持原有尺寸、布局和功能。
4. 检查透明度及 32/128 像素辨识度，运行前端回归、构建及桌面构建检查，完成后提交。

## 验收场景

- GIVEN 桌面应用打包配置加载图标，WHEN 生成 macOS/Windows 资源，THEN 图标使用同一源图，macOS 有明确 ICNS 资源且透明角保留。
- GIVEN 打开启动器，WHEN 在浅色或深色主题查看，THEN 品牌图标可见，不改变搜索栏位置和键盘行为。

## 源图与生成提示词

使用 imagegen 技能的内置图像生成工具（非 CLI/API）。源图：`desktop/assets/app-icon-master.png`，1254×1254 RGBA。界面用 `desktop/src/assets/app-icon.png`；桌面派生资源在 `desktop/src-tauri/icons/`。源图保留生成的透明通道，Tauri 工具负责尺寸与格式转换；仅拷贝本项目消费的桌面格式，不引入无关移动端产物。

复用方式：运行 `npm run tauri icon -- assets/app-icon-master.png --output <临时目录>`（在 desktop 中），将 32x32.png、128x128.png、icon.png、icon.ico、icon.icns 同名拷贝到 src-tauri/icons，并将 128x128.png 拷贝到 src/assets/app-icon.png。

最终生成提示词：

```text
Use case: logo-brand. Asset type: production desktop application icon for PromptArk / 提示方舟, a professional local-first prompt library and launcher. Create ONE original square 1024x1024 raster app icon, not a presentation or mockup. A deep teal (#176b62 to #0e554e) rounded-square macOS-style tile, centered with about 7% genuinely transparent margin outside the tile. On the tile, one bold ivory-white folded-paper ark/boat emblem: a broad simple folded hull and an angular upright folded paper sail, subtly suggesting a prompt chevron through negative space. The emblem should occupy about 60% of the canvas width and be instantly recognizable at 32 pixels. Sophisticated restrained tactile finish: very subtle satin bevel and soft shading on the tile and paper folds, crisp silhouette, mostly flat readable faces. Straight-on view, balanced optical centering, generous clear space. No text, no letters, no tiny details, no waves, no stars, no sparkle, no extra symbols, no scene, no watermark, no drop shadow outside the tile. Real transparent alpha outside the rounded square; do not draw a checkerboard or white background. Deliver only the single final icon.
```

## 验收记录

- 检查 128px、32px 成品，方舟与船帆清晰；源图角像素为 RGBA (0,0,0,0)，源图及 32px 图 alpha 范围均为 0–255。
- 新增 5 项图标资源回归；前端 37 文件 / 264 测试通过，生产构建通过；docs-check 与 diff-check 通过。
- macOS 本地包构建退出码 0：`npm run tauri build -- --debug --bundles app --config '{"bundle":{"createUpdaterArtifacts":false}}'`。仅本次省略更新签名产物，不改仓库发布签名配置；保留既有数据库未使用导出警告。
- 产物为 `desktop/src-tauri/target/debug/bundle/macos/PromptArk.app`；Info.plist 指向 icon.icns，已核对包内 ICNS 与仓库资源 SHA-256 一致。启动器及网页标签页使用同源 PNG，未修改现有操作逻辑。
- 未声称 Windows/macOS Dock 缓存刷新已实测；如运行中的 Dock 图标未更新，需退出后重开新构建应用。不清理用户系统图标缓存，不为图标替换强制结束未保存编辑。
