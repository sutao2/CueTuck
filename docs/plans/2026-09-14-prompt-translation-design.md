## 设计计划

1. 核对现有广场、详情和使用流程，查证百炼翻译模型的价格与接口限制。
2. 绘制广场、详情/原文对照、使用预览、客户端设置与管理端翻译任务；沿用工作台主题，新增语言控制而不重复卡片操作。
3. 用浏览器验证切换、首次翻译、失败重试、复制反馈和窄窗口布局；保存设计与证据。生产 API、数据库及模型调用属于后续实施，不以示例状态声称完成翻译。

## 内容与语言合同（拟实施）

- 原始标题、正文、来源与许可不可覆盖。中文是展示版本，英文原稿直接复用；中文原稿翻译为英文。第三种语言的中英文分别从原稿生成，不通过中文中转。
- 广场标题、简介与正文一起提供中文；保留原始搜索入口，中英文都能检索到同一条目。分类、作者、模型 ID、来源地址、附件不重复翻译。
- 原文、中文、英文是同一提示词的版本，不创建三个广场条目；下载量、收藏量、远端 ID 保持唯一。下载原稿及已有语言版本供离线使用，未生成的版本不阻塞下载。
- 模板翻译前保护变量语法及标识符、代码、JSON 键、URL 和模型参数；翻译后校验占位符集合、结构和完整性。变量说明另行本地化。保护失败或输出截断的译文不得标成可用。
- 使用页先选择模板语言再填写变量；用户输入值按原样填入，不自动上传或翻译。另有需要时再设计明确的「同时翻译填写内容」，不混入首版。
- 源内容版本、目标语言及翻译规则版本共同标识缓存；源内容改动使旧译文过期，生成中/失败不能覆盖最后已确认版本。并发相同请求合并，重复点击不重复计费。
- 已有译文切换即时；未生成显示「翻译为英文」，用户点击后开始。等待、取消等待、失败重试和离线不可用均有反馈；取消等待不宣称模型费用已取消。

## 页面安排

| 页面 | 控件与行为 |
|---|---|
| 广场 | 工具栏「内容语言：中文 / 原文」，只影响内容语言，不影响界面语言；卡片中文标题/摘要，译文小标记；动作仍为下载、收藏图标 |
| 详情 | 正文顶部「中文 / English」；可查看原文对照；原稿标记、译文状态；未生成时提供单一翻译按钮 |
| 使用提示词 | 同一语言选择；主按钮「复制中文 / Copy English」，跟随预览；参数与参考资料不挤压正文 |
| 客户端设置 | 常规里的内容语言偏好；AI 与模型中的本地翻译服务，默认未启用，个人 Key 仅本机凭据库；明确点击翻译才发送所选正文 |
| 管理端 | 翻译模型单独配置，服务器密钥不下发；待翻译/可用/失败/过期、用量费用、抽样审阅、开始/暂停/重试；测试连接、保存配置、批量任务是不同动作 |

## 模型与费用

推荐候选 `qwen-mt-flash`（百炼，北京），备选 `qwen-mt-lite`。正式采用前用真实样本比较语义、变量保真和耗时；本轮未进行付费调用，不声明模型已经可用或质量已验收。

截至 2026-09-14 官方资料：Flash 输入 ¥0.7 / 百万 Token、输出 ¥1.95 / 百万 Token；Lite 为 ¥0.6 / ¥1.6。Flash 支持术语/领域提示，最大输入与输出各 8192 Token，不支持 Batch API 或上下文缓存。应用侧持久化译文可复用，但不等于供应商缓存折扣。长文需按结构切分、保护不可翻译片段并检测输出截断；任务按实际账户 RPM/TPM 限流，有界重试。

示例预算：若 22,391 条全部需要翻译、每条平均输入 1000 和输出 1000 Token，Flash 约 ¥59.34，Lite 约 ¥49.26；仅说明计算方式，不是实测报价。已有中文和可复用英文跳过。真实费用须先统计语种、采样 Token 与长度，再显示预计费用、预算上限及失败重试增量；不能按条数承诺固定费用。批量暂停只停止新任务，在途请求可继续产生费用。

官方依据：[Flash 模型](https://help.aliyun.com/zh/model-studio/qwen-mt-flash)、[价格表](https://help.aliyun.com/zh/model-studio/model-pricing)、[翻译接口](https://help.aliyun.com/zh/model-studio/machine-translation)。

## 后续实施顺序

1. 只读盘点语种、长度与已有中文；抽取常规、中英混合、变量、代码/JSON 和长文样本，测试候选模型并记录 token 用量、耗时和人工检查结果。
2. 新增语言版本存储、模板保护校验、按版本缓存与鉴权/配额接口；同一提交补充广场/设置/API 现行规格和迁移回滚方案。
3. 对接本设计的客户端与管理端页面，覆盖失败/离线/并发/源文更新/下载兼容；本地翻译采用用户自己配置的密钥，不复用平台密钥。
4. 备份后先生成小批中文版本，验证内容与搜索、下载，再按预算逐步执行广场批量任务。保留原文，不改用户本地内容。

## Given / When / Then 验收

- Given 英文原稿已有中文 When 切换 English Then 展示原稿，不产生翻译调用。
- Given 中文原稿没有英文 When 主动翻译 Then 展示处理中，成功后可复制；失败可重试且中文仍可读。
- Given 本地模板包含变量 When 切换语言并填写 Then 变量标识不变，复制当前语言模板及原样填入的值。
- Given 用户未配置本地服务 When 请求本地翻译 Then 指向设置，不自动发送私人正文到平台。
- Given 未翻译完成或离线 When 浏览/下载 Then 可回退原文，已有译文可用，计数与同条目身份保持。
- Given 任务运行中 When 暂停 Then 停止领取新工作，保留进度与失败清单，不承诺在途请求不计费。

## 页面验收记录

- CUA 浏览器检查：中文/原文列表切换、英文搜索匹配、详情中英文切换、原文对照、英文原稿无需翻译状态。
- 使用页检查：首次英文入口、处理中、模拟失败与重试、生成后预览、原样保留填写参数、复制按钮成功反馈。自动化剪贴板读取与页面写入通道未对齐，未将其计作剪贴板内容或原生复制验收。
- 设置检查：个人服务默认关闭、开关控制配置字段、测试连接明确提示未联网；未输入真实密钥。
- 管理端检查：模拟进度从 64 到 73、暂停、模型/预算弹窗，以及明确的示例数据标识。
- 1280px 桌面布局与 483px 窄窗口检查；修正窄窗口使用页为上下布局，正文不横向溢出。预览后恢复浏览器原尺寸。
- 原型脚本语法检查与 docs-check 通过。未调用模型，未测试译文质量，未修改生产或本地提示词数据；所有模型结果与任务计数为页面示例。
