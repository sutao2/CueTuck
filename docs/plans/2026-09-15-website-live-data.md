# 官网重设计与真实广场

状态：已实施、部署并验收。替代上一版设计中的暖绿装饰风格与广场示例数据。

## 范围与步骤

1. 提示词接同源 `/v1/square/catalog`、`/v1/square/browse` 和公开详情/正文；每页 24 条，搜索防抖、取消旧请求，计数采用接口 total 与全局分类聚合。失败显示重试，不回退示例。
2. Skill 广场复用客户端 15 个来源和分类规则，通过公开 GitHub API 固定提交并读取真实 SKILL.md 目录。按来源显示总数、搜索、分类和分页，详情显示源码链接与实际内容；不声称网页可安装本机文件。
3. 官网改为中性、清晰的产品站点，主视觉采用真实客户端截图；工作台紧凑展示真实图片、来源和下载/收藏数量。暂存收藏和草稿明确标为当前标签页，不假装已写入账号库。
4. 验证分页/搜索/切换的竞态、详情、模型筛选、Skills 来源一致性、失败重试和多尺寸布局，重新部署独立 Compose 预览并确认 API/管理端正常。

## 验收场景

- Given 提示词广场 When 首次打开或筛选 Then 页面总数与相同 API 请求一致，首批仅请求 24 条；分类数量不按已加载项累加。
- Given 连续搜索或切换空间 When 旧响应迟到 Then 不覆盖当前列表，失败没有示例内容兜底。
- Given 选择 Skill 来源 When 加载 Then 条目来自该仓库真实固定提交下的 SKILL.md，类别复用客户端规则；无法读取时给出错误及重试。
- Given 查看详情 When 加载正文 Then 保留真实作者/来源；内容按文本渲染，不执行提示词或 Skill 指令。
- Given 桌面或窄屏 When 使用搜索、分页、详情和导航 Then 无页面横向溢出，主要操作可达。
- Given 既有服务器 When 更换静态预览 Then 原 API、管理端、数据库与账号配置保持；保留上一预览目录可回退。

## 验收结果（2026-09-15）

- 线上入口：[官网](https://prompt.likh.cn/preview/)、[提示词广场](https://prompt.likh.cn/preview/#app)、[Skill 广场](https://prompt.likh.cn/preview/#skills)。中性白灰视觉、真实客户端截图、实际参考图与详情来源已生效。
- API 返回 22,392 条，每页 24 条；第二页内容变化，软件开发分类 524 条且全局总数不变，搜索“鹈鹕”返回 2 条。模型 ChatGPT 筛选的 24 条均匹配。
- Skills 源目录与分类在构建时直接复用客户端。Anthropic 提交 `34040c9c568585f6929bedeaad110ad08f079624` 下 20 条，Vercel 提交前缀 `063bee94c3f4` 下 9 条；来源切换、React 搜索、固定提交的真实说明读取通过。计数是当前来源，不冒充全部仓库汇总；访问仍受 GitHub 公共 API 限流约束。
- 6 项数据模块测试通过。浏览器模拟 503 后展示错误与重试，未渲染假数据；恢复后重新加载 24 条。延迟旧搜索响应没有覆盖较新的“鹈鹕”结果。
- 4 页 × 3 种宽度（1440、960、390）无页面横向溢出。详情实际来源作者 William AI、变量替换、图片弹窗、列表缩略图和手机布局经公网复验通过；公网会话没有 JavaScript 或控制台错误。截图留在本机 `output/playwright/cuetuck-live-*.png`。

- 发布目录 `20260915-live-2`，独立 Compose 容器 healthy；`.mjs` 正确返回 JavaScript 类型，10 个公开静态文件哈希全部匹配。原 API 的 Postgres、Redis、MinIO 均为 true，管理端 HTTP 200。上一目录保留，回退见[部署说明](../../deploy/README.md#官网与-web-设计预览)。
