# 启动器本机偏好

## 范围与顺序

1. 常规页增加独立启动器分组：大小三档、默认位置、正文/填写字号、搜索结果上限及恢复默认。沿用即时保存/失败回滚，不重复已有自动关闭和快捷键；导航十类不变。
2. `launcher_preferences` 单键 JSON 原子存储，不加入云同步白名单。设置页、独立启动器和原生窗口分别读取，非法/历史缺省字段安全回退。保存后下次唤起生效，不中断填写。
3. 原生窗口按所选大小与当前显示器工作区定位，尺寸不超过工作区；搜索/填写同尺寸，清空仍只改高度，保持左上角。浏览器入口读取尺寸但不声称原生位置生效。
4. 单测覆盖保存失败/重开/重置、消费者生效、损坏偏好和缩放定位；真实浏览器检查最小/最大尺寸及大字号，原生测试与本机打包后提交。

## 验收场景

- GIVEN 默认设置，WHEN 打开常规页，THEN 显示紧凑/偏上/12px/20条。
- GIVEN 任一选项变更，WHEN 保存成功并重新唤起，THEN 相应原生窗口、字体与结果上限实际改变；失败保持旧值和错误提示。
- GIVEN 搜索/填写/清空查询，WHEN 布局切换，THEN 不因偏好重新定位，搜索与填写不缩窗。
- GIVEN 宽敞窗口遇到较小工作区或非 1 倍缩放，WHEN 唤起，THEN 以逻辑像素计算并限制在工作区。
- GIVEN 自定义过这四项，WHEN 恢复默认，THEN 仅重置该 JSON，不改快捷键、自动关闭或用户提示词。

## 验收记录

- 设置四项、重置、关键词检索及原生消费完成；沿用十类导航。`launcher_preferences` 不在同步设置白名单。
- `npm test` 桌面 425 项通过；最终监听顺序/导入调整后相关 39 项再次通过。覆盖逐项保存、重开、失败回滚/保存中禁用、重置保留其他偏好、损坏值回退、结果上限与字号刷新、浏览器弹窗尺寸。
- `cargo test --locked`：75 通过、1 个性能测试忽略；含 10 项启动器测试，覆盖三档尺寸、2 倍缩放/偏移屏、居中和小屏限制。原生实机多显示器与全局按键本轮未重验。
- Playwright 隔离内存库：实际操作设置页保存 large/center/16/50，随后在同一测试文档挂载真实启动器消费保存值；紧凑 620×420 与宽敞 760×560 的 16px 输入/正文、独立预览滚动、固定底栏视觉通过。最小视口无水平溢出，操作栏底边 420px。测试夹具首次使用不同 Vue 模块产生警告，改为应用同版本运行时后重验；未写入用户库。
- 截图：本机 `output/playwright/launcher-preferences-{settings,compact,large}.png`。`npm run build:local` 成功生成 macOS 调试包；本轮未强制重启用户当前进程，重启后可使用新增设置。
