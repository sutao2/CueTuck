# 19. 设置采用应用内完整页面

- Status: accepted
- Date: 2026-09-08
- Supersedes: [ADR 0016](0016-workbench-frame-and-settings.md) 的固定设置弹窗决策；主工作台继续遵循 [ADR 0017](0017-screenshot-workbench-frame.md)

## Context

用户提供 Codex 设置页截图，明确要求设置不要弹窗。原固定 760×600 弹窗已不符合用户期望。

## Decision

设置在同一个原生主窗口内切换为完整页面，左侧为返回应用、搜索及十类设置导航，右侧为居中限宽的设置表单。保留系统窗口控件与拖动区域，不显示背景工作台、遮罩、悬浮边框或关闭叉。工作台仅隐藏，返回时保持查询、筛选、视图和滚动位置。

已有开关与表单、权限及保存逻辑不变，未保存离开与危险操作仍确认，账号入口直达账号设置。搜索只筛选设置分类，不自动跳页、修改配置或上传内容。独立启动器不变。

## Consequences

设置使用页面导航语义而非 aria-modal/dialog；仅确认框和登录继续是对话框。需要验证返回焦点、草稿、搜索、十页短视口和原生拖动，不把截图中本软件没有的功能添加为占位。
