# 广场与本地列表精修

## 计划

1. 校准展示语义：广场排序不显示未查询的虚假零计数，标题跟随排序和分类；本地标签计数遵守模型筛选。
2. 明确筛选上下文：显示搜索/分类/模型条件及清除入口，清除不修改内容或当前排序。空结果提供清除筛选，本地空库提供新建。
3. 广场请求期间显示加载状态而非空库，不允许操作旧查询结果；失败仅展示一处错误说明及重试/本地入口。保护旧请求不覆盖新状态。
4. 统一紧凑头部、工具栏、列表行与卡片层级，合并重复广场页头并保留站点品牌/公告/支持入口，补充合集明确打开入口；保留已有下载、收藏和页面式编辑行为，不增加弹窗。
5. Vue 回归、浏览器浅深色/800–1200px/有数据与空态检查，构建桌面包。正常提交，不绕过 WorkLog。

## Given / When / Then

- GIVEN 广场不同排序；WHEN 切换最新/收藏和分类；THEN 标题反映当前内容，未获取的总数不伪装成零。
- GIVEN 本地模型、分类和搜索筛选；WHEN 清除单个或全部条件；THEN 正确刷新且保持原排序，标签计数与模型一致。
- GIVEN 网络请求未完成或失败；WHEN 浏览广场；THEN 显示加载或一次可恢复错误，旧结果不可误操作，旧响应不能终止新请求状态。
- GIVEN 长标题、合集、提示词及窄窗口；WHEN 切换两种视图/主题；THEN 标题和操作可见，无横向溢出，合集有键盘可达的打开按钮。
