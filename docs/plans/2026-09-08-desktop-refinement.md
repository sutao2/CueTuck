# 全客户端视觉细化

## 范围与计划

用户确认是整个桌面客户端，不仅设置页。保留 ADR 0017 的主壳、ADR 0019 的完整设置页、独立启动器和全部业务行为；不改管理台、不新增装饰性功能。

1. 统一中性表面、辅助文字、焦点色和系统字体；减少零碎字号，浅深色均可读。
2. 细化侧栏与搜索工具条的对齐、卡片/列表的信息密度及悬停反馈，不靠浮起位移表现交互。
3. 统一编辑、登录、使用、发布、合集、详情与设置中的表单边框、圆角、按钮与反馈；外观页预览卡和偏好分别分组。
4. 启动器沿用原生独立窗口与既有尺寸/定位，只统一中性色、字体、字段和预览层次，不触碰复制/粘贴/焦点生命周期。
5. 用 Playwright 在隔离浏览器数据中验收工作台、各弹窗、十类设置及启动器的浅深色、长文本和小窗口；运行全量桌面测试、构建并检查真实 macOS 包。正常提交，不绕过评审门禁。

## Given/When/Then

- GIVEN 浅色或深色客户端；WHEN 浏览各内容面；THEN 同等级标题、正文、辅助文案和控件使用一致视觉语言，悬停与键盘焦点可区分。
- GIVEN 网格、列表、弹窗与设置包含长文本；WHEN 缩窄窗口或滚动；THEN 无页面横向溢出，主要操作可达，卡片悬停不改变布局。
- GIVEN 启动器搜索和多变量填写；WHEN 切换与键盘操作；THEN 保持既有窗口尺寸、位置及 Enter/Shift+Enter/复制行为，文本与操作层次清楚。

## 验收结果

- 桌面 Vitest 44 个文件、328 项测试通过；前端与 macOS debug `.app` 构建通过，保留原有 9 个 Rust 未使用项警告。
- Playwright：主工作台网格/列表与十类设置，浅深色 × 1280×800/800×600，共 48 组无横向溢出；登录、编辑、使用、分类弹窗另 16 组通过，底部操作可见。
- 本地合集、广场只读详情小窗口检查通过；发布弹窗用隔离浏览器测试会话验收两种窗口尺寸，未提交发布。该假令牌产生一次预期的收藏读取 401，不作为真实登录或服务鉴权验收。

- 重启真实 macOS 客户端，检查主窗口与常规设置并返回；保留原有两条提示词。截图与测量产物在忽略的 `output/playwright/refinement-*`。
