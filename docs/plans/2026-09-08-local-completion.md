## 边界与顺序

在本机服务、隔离数据库和测试文件内验收，不操作生产、真实扣费、外部账号或用户现有资料。支付继续 mock。仅规划当前切片的详细步骤；后续每片开工前读取对应规格，补变更合同及逐步计划，验收后独立提交，不自动推送。

| 顺序 | 交付范围 | 验收标准 |
|---|---|---|
| P0 删除反馈 | 提示词/合集删除前非模态确认，成功/失败固定提示；分类保留原有确认，补结果提示 | 取消不写库；失败保留内容可重试；连续点击只执行一次；删除合集/分类不删成员正文 |
| P1 附件完整流转 | 先明确私人附件与公开附件权限；接本机对象存储、账号同步、显式选择投稿附件、人工审核、下载落盘 | 两个隔离账号不能越权；上传/下载失败不产生伪成功；文件哈希往返一致；未批准/下架文件不能公开访问；原有本地文件不被覆盖 |
| P2 MCP 广场与接入 | 保留默认本地只读 stdio；增加显式启用的广场搜索/读取、分类模型筛选与分页；客户端生成可复制的绝对路径配置 | 本地调用不发网络；广场超时/离线有界返回；私有数据不上送；下架不可读；真实子进程与本机后端联调通过。不包含远程 HTTP MCP 或向量模型 |
| P3 客户端一致性 | 逐流程核对新建、编辑、删除、发布、同步的忙碌/成功/失败/空状态、焦点和键盘操作 | 失败不丢草稿、重复操作不重复写入；窄屏/深浅色可用；核心路径可用键盘完成；减少非必要弹窗 |
| P4 数据可靠性 | 断网重连、账号切换、并发同步/冲突、软删除、备份恢复、附件引用及大库性能 | 隔离双账号和双库故障注入，不串库、不静默丢内容；恢复逐项比对；性能记录数据规模与环境，不预填通过 |
| P5 自动回归 | 前后端/管理端/Web/MCP 测试及构建接入 CI；核心流程端到端脚本 | 本机能从空测试环境复现；失败给日志；测试不依赖真实凭据或用户库；远端配额不足只报告未运行 |
| P6 发行准备与状态整理 | 统一服务地址配置、校验更新源、开发与发行打包分离、部署及备份模板、更新验收清单 | 本地打包及配置校验通过；无私钥入库；正式发布前明确更新仓库和公钥配套；状态区分代码完成、本地已验、外部待验 |

P1、P2 可分别验收；P4 覆盖二者的数据边界；每片测试随实现添加，P5 负责集中联跑，不把测试推迟到最后。

## P0 实施步骤

1. 在工作台按实际条目确定删除对象，右键与编辑页统一进入非模态确认条；取消保留编辑草稿，确认时禁用重复动作。
2. 复用固定轻提示样式，区分下载与删除的动作链接；删除成功关闭对应编辑页、更新列表/数量；删除写入失败保留对象和确认入口。
3. 区分删除写入与后续刷新失败，不能把已删除误报成删除失败。分类保留已有安全校验与确认；合集成员不删除。
4. 组件测试覆盖取消、确认、失败重试、重复提交、合集保留成员与刷新异常；前端全量测试/构建、文档检查后提交。

### Given / When / Then

- GIVEN 本地提示词；WHEN 从列表或编辑页点删除；THEN 先显示带标题的确认，取消不改数据。
- GIVEN 删除正在执行；WHEN 再次确认；THEN 仅执行一次，成功后可见结果且列表更新。
- GIVEN 数据库删除失败；WHEN 用户确认删除；THEN 显示错误并保留内容与重试入口。
- GIVEN 删除已写入但刷新失败；WHEN 返回结果；THEN 明确已删除及刷新失败，不冒充写入失败。
- GIVEN 合集有成员或分类有内容；WHEN 按既有校验确认删除；THEN 告知内容保留并实际保留正文。
