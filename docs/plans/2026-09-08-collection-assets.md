# P1d 合集成员公开附件

状态：已验收（2026-09-08）。承接 [P1c](2026-09-08-publication-assets.md)，复用既有私有上传、稿件范围下载与人工审核。

## 实施步骤

1. 投稿页读取合集成员附件，标明所属成员，默认不选。为每份附件生成独立的公开引用 ID，备份导入导致本地 ID 相同也不串联勾选。上传失败保留选择；切源/账号清空选择。提交时重读成员，所选文件的成员已移除则拒绝，不上传本地成员 ID。保持正文快照与本机独立。
2. 复用稿件 asset_refs 清单，成员追加 asset_ids 数组关联该清单。总数仍最多 12 个、20 MiB，每文件 5 MiB。服务端校验每个引用属于作者且 ready、元数据一致；合集清单中每项须且仅须关联一个成员，无重复、悬空或遗漏。旧正文合集没有这些字段仍可用。
3. 清单不为空仍强制人工；审核和公开详情按成员显示附件，复用按稿件/文件 ID 的受限代理，不增加对象存储直链。批准前/下架后不可公开读取。
4. 下载先校验关联与全部字节/哈希，再在既有导入事务一次保存合集、成员和附件；重新生成本地附件 ID，保持所属成员；失败不写入，重试不重复。
5. 隔离测试覆盖越权/伪造/重复/悬空/未关联、人工门禁、批准与下架，客户端逐项选择/切源/失败及多成员导入；回归并构建，更新规格/索引后独立提交。不在真实用户内容上发布、审核或删除。

## Given / When / Then

- GIVEN 两个成员各有文件；WHEN 只勾选一份；THEN 投稿仅含该文件及对应成员 asset_ids，未选文件不公开。
- GIVEN 附件关联重复/未知/遗漏或属于其他作者；WHEN 请求投稿；THEN 拒绝且不创建审核记录。
- GIVEN 选择完成后该成员被移出合集；WHEN 提交；THEN 告知重新选择，不生成错配稿件。
- GIVEN 带成员附件且自动审核全部通过；WHEN 提交；THEN 仍转人工，审核人员看到文件所属成员。
- GIVEN 批准且在线合集；WHEN 下载；THEN 文件归入正确本地成员，ID 重映射；重复下载不重复导入。
- GIVEN 第二成员文件损坏/下架；WHEN 下载；THEN 无新增合集、正文或部分文件，恢复后可完整重试。
- GIVEN 旧版纯文本合集；WHEN 读取与下载；THEN 继续成功。

## 不包含

合集封面上传、成员跨条目共享文件、对象回收、生产恶意软件扫描及已下载副本撤回。
