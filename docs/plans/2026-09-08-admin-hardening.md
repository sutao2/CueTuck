# 管理端五项补齐

状态：本机验收完成；五项代码已实现。仅操作隔离测试数据，不配置真实模型，不清理现有对象。

## 实施顺序与验收

1. 列表状态：通过账号会话内的显式状态容器保存各列表的已应用筛选和分页；离开重新读取数据，退出/换账号清空，不保留密码、草稿或数据结果。回归切换返回、重新登录清除。
2. AI 任务：投稿与唯一任务同事务落库；worker 使用持久化租约、过期重领、最多三次和退避。旧认领结果不写入，人工结论优先；管理端可查看任务并显式重试，冲突和权限在服务器复核。
3. 图片审核：模型追加默认关闭的视觉能力；仅显式投稿清单图片可经所有权、大小、哈希校验后以 data URL 发送，不发私有库或存储地址。限制图片数量/总量；非图片附件或不可用视觉链路转人工。保留含附件稿件最终人工公开确认，不将视觉通过等同于自动公开授权。
4. 存储治理：显式、有界、分页读取本项目对象前缀进行只读对账；返回数据库缺对象、无数据库对象及未完成上传计数/候选。只允许已有数据库记录、超过七天、无任何引用的未完成上传走单项确认清理；桶内无记录对象只报告不删除（可能属于其他实例）。重新检查引用、年龄和状态，网络失败可重试。
5. 管理浏览器回归：Playwright CLI 启动独立管理端与隔离 API 替身，覆盖登录、筛选恢复、审核提交、配置保存失败/重试、退出；真实后端权限/事务另由 PostgreSQL 隔离测试验证。接入统一验收和 CI；保留截图和日志，不混称替身为生产联调。

## Given / When / Then

- GIVEN 列表已检索并翻页；WHEN 去其他页后返回；THEN 恢复已应用条件和页码并重新请求，账号改变清空。
- GIVEN 审核任务入队后进程退出；WHEN 新 worker 启动；THEN 从数据库认领，租约过期可重领，过期执行者不能覆盖结果。
- GIVEN 人工已审核或配置已变化；WHEN AI 返回；THEN 不覆盖人工，也不按旧配置上架，任务显示真实终态。
- GIVEN 图片未获视觉配置授权、哈希不符、数量/字节超限；WHEN 运行；THEN 不发送图片、不伪造通过，留人工可见原因。
- GIVEN 投稿引用的图片合法且视觉模型启用；WHEN 模型返回结构化结果；THEN 判定记录模型和配置版本，仍要求人工确认公开附件。
- GIVEN 中断上传超过七天且无引用；WHEN owner 显式确认清理；THEN 再次校验后删除指定云端对象与记录并审计，取消无写入。
- GIVEN 存储扫描失败、未知桶对象或活跃上传；WHEN 查看对账/清理；THEN 明确失败或只读差异，不能误删、不能把截断扫描称全桶完成。
- GIVEN 空隔离浏览器；WHEN 执行管理回归；THEN 核心写流程与失败恢复可重复，不访问用户实例或真实外部服务。
