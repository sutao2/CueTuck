# 常用资料

- Given 桌面用户手动填写名称、类型和内容，When 保存网址、账号、模板或文本，Then 写入本机独立资料库，可按名称或正文查找、修改、复制和删除；不监听剪贴板，不参与提示词同步、导出、发布或 MCP。
- Given 输入密码，When 保存，Then 正文只交给系统凭据库；资料库仅保存名称、类型、分类关联和标识。凭据不可用时不降级。列表、搜索和编辑时不读出密码。
- Given 资料与提示词匹配同一查询，When 使用独立启动器，Then 同时列出两类结果；资料按原样复制到系统剪贴板，不执行链接、不解析变量、不写最近提示词；启动器仅在用户选择复制时读取密码。

- Given 本机渲染密码资料，When 用户点击「显示密码」，Then 仅当前条目短暂显示明文，点击隐藏、离开该行、失焦、切页或 15 秒后隐藏；显示不写剪贴板。

- Given 系统凭据库缺少默认钥匙串或授权被取消，When 保存失败，Then 资料编辑器保留输入并显示对应处理办法，数据库事务回滚。

- Given 升级前已保存资料，When 打开资料库，Then 原有记录仍可搜索和复制，默认归入「未分类」。自建分类独立于提示词分类；删除分类仅将其中资料移回未分类。
- Given 已选择资料分类，When 同时指定类型和关键词，Then 仅显示满足全部条件的记录，侧栏数量仍为各分类总数；新建默认使用当前分类。
- Given 选择添加或编辑，When 切换普通资料类型，Then 草稿正文保留；进入或离开密码类型时清空内容，保存时保留原有标识与分类，转为密码须输入密码，转出密码须填写普通正文。凭据操作失败或其他窗口已改类型时保留原记录。

- Given 独立启动器处于本地搜索，When 点击加号或选择「添加资料」，Then 在当前窗口编辑资料，非空搜索原样预填正文，HTTP(S) 网址预选网址类型。取消返回原输入，确认保存后可在启动器和工作台检索；不会执行链接、写入最近提示词或自动复制内容。
- Given 浏览资料列表，When 需要再次使用或维护资料，Then 行内可直接复制和按需显示密码，「更多操作」提供编辑和删除，删除需单独确认。

- Given 打开常用资料，When 浏览、筛选、添加或编辑，Then 页标题、结果摘要、主操作、搜索筛选与空状态使用工作台公共样式；宽屏左侧与本地提示词对齐，窄窗保留独立筛选入口。

- Given 文本或模板含换行、空行和缩进，When 在启动器粘贴、添加、重新编辑和复制，Then 保留正文排版，列表预览保留可见行的空白，工作台提供可调整高度的多行编辑区。
