# 提示词翻译

状态：已接受，实施状态见[实施计划](../../plans/2026-09-14-prompt-translation.md)。页面与内容语言规则沿用[设计方案](../../plans/2026-09-14-prompt-translation-design.md)。

## 本机模型配置

「设置 → AI 与模型」MUST 统一管理本机接口、Key、优化模型和翻译模型。两个模型均使用可搜索下拉框，由用户主动获取 `/models` 后选择；获取列表不要求先保存模型。保存但未在列表返回的模型保留并标明，不悄悄改成第一项。请求错误或空列表需可重试。更换接口时旧列表失效，旧密钥仅可用于与保存配置完全相同的规范化基础地址。

原启动器配置 MUST 兼容读取；翻译模型为空表示未配置，不自动调用优化模型或服务器审核密钥。列表发现允许未保存的草稿 Key，只在当前请求中使用，不持久化；公开配置永不返回 Key。具体服务仅在用户主动优化、翻译或测试时接收对应文本。

## 原文与翻译版本

MUST 以源正文摘要、目标语言和规则版本标识译文；源文修改后旧缓存不再作为当前译文。正文翻译只处理自然语言，变量语法、代码、链接和 JSON 键保留；保护或完整性校验失败即失败，不覆盖原文。英文原稿直接作为英文版本。中文版本先供广场展示，本地库只按用户主动请求生成。

## 验收场景

- Given 新设备未保存模型 When 填写接口及 Key 获取模型 Then 可获取和搜索选择，无需输入模型 ID。
- Given 已保存旧配置 When 升级 Then 优化模型与密钥保留，翻译模型仍未配置。
- Given 更换接口或 Key When 请求模型失败 Then 原设置不被覆盖，不把旧目录显示为新接口结果，也不向新接口发送旧密钥。
- Given 本地正文含变量 When 翻译模板并填写参数 Then 变量名称与用户值不变，复制使用当前语言的模板。
- Given 提示词已生成翻译 When 重复请求或下载 Then 复用同一版本，不重复创建条目或增加下载/收藏计数。
- Given 翻译任务失败/限流/输出截断 When 查看内容 Then 原文仍可用，有明确失败和重试入口。

## 广场版本与后台任务

公开内容默认中文优先，未就绪时显示原稿；列表以轻量标题/摘要连接翻译表，中文和原文均可检索，不拉取列表正文。翻译版本和下载、收藏计数分离。正文改变时数据库触发器清除旧版本/任务，运行任务用 claim 与源快照校验防止旧结果覆盖新稿。下载携带已经生成且源文一致的版本，缓存失败不撤销原稿下载。

`GET /v1/square/items/:id/translations` 沿用公开广场权限；`POST .../translations/:target` 必须登录，支持 zh/en，同条目去重，每账号每日最多 20 条新增任务。服务端串行消费持久队列、重试最多 3 次，租约回收后可重试；管理员可补全中文、暂停/继续及重试失败项。每日 token 上限在调用前保守预留，失败或中断保留预留，成功按供应商返回用量结算；缺少用量不按免费处理。模型在管理端单独配置且加密保存，不发送本地私有正文。

模型获取走公网 HTTPS、限制重定向/响应体/目录大小，不把目录出现当作模型测试通过。所有者配置保存要求当前密码与版本匹配，任务操作写审计。系统密钥缺失但存在翻译凭据时必须拒绝生成新密钥。

本机译文缓存独立 SQLite，按源摘要与目标语言保存，最多 500 个版本，不参与同步、发布或备份。译文读取无需配置模型，新的翻译须由用户主动发起。本机翻译失败可重试，切换语言不改变变量值。长文按字符边界分段，JSON 递归仅翻译自然语言字符串，保留键、数字、技术字段、附件 ID。

- Given 下载与收藏次数已经记录 When 生成/切换译文 Then 次数不变。
- Given 任务正在翻译 When 作者改正文 Then 旧 claim 不得写回新版本。
- Given 日额度不足 When 后台准备调用模型 Then 不发送请求，任务继续等待。
- Given 链接后紧接中文标点 When 恢复受保护文本 Then 链接内容一致即可通过，不把标点误判成 URL 改写。

专用模型若漏掉保护标记，MUST 改为仅翻译自然语言片段，由程序原样拼回变量/代码，最多 32 个保护片段；重组后仍校验。降级调用也计入预留与用量，不通过则明确失败。
