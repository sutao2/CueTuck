## 实施顺序

1. 核验已安装应用的签名、版本及与发布构建的可执行文件摘要；仅对确认可信的 PromptArk 移除下载隔离标记，验证启动。发布页补充无证书安装指引，不关闭全局 Gatekeeper，不伪称已公证。
2. 未保存过匿名统计偏好时默认开启，保留显式关闭。成功保存完整内容后异步上报；服务端原子递增并返回真实次数，客户端更新对应卡片，不等待统计才确认本地下载成功。
3. 验证默认/关闭、失败、重复下载、并发计数、延迟返回与页面卸载；更新规格、提交，部署后端并构建下一预览版。

## Given / When / Then

- GIVEN 下载的 macOS App 完整且与可信发行一致，只有隔离限制；WHEN 仅放行该应用；THEN 可以打开且原有签名仍通过，不改变全局安全设置。真正损坏的签名不得用重新签名掩盖。
- GIVEN 尚未设置统计偏好；WHEN 成功保存正文及全部附件；THEN 默认匿名上报一次并在收到服务端计数后更新卡片。
- GIVEN 用户明确关闭统计；WHEN 更新客户端或下载；THEN 保留关闭，不发统计请求。
- GIVEN 下载失败、并发点击或打开已有本地副本；WHEN 操作结束；THEN 不增加失败/重复下载次数。
- GIVEN 统计失败、超时或返回无计数的旧接口；WHEN 下载已保存；THEN 本地成功不被撤销，不伪造次数；迟到响应不得更新已卸载组件。
