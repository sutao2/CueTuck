# AI 优化结果契约

## 计划

1. 优化请求明确返回 JSON prompt 字段，以 SQL 草稿示例区分重写请求与回答任务。
2. 原生解析仅提取 prompt 字符串，兼容外层 JSON 围栏；拒绝说明文字、缺字段与非完整输出，保留原文，不猜测删除正文片段。
3. 回归截图形态拒绝、合法结构提取、正文 SQL 代码块与变量保留、原有错误处理和启动器流程。

## 场景

- Given SQL 优化请求 When 构造模型请求 Then 草稿保持不变，指令要求保留 SQL 与变量，不输出自我说明或任务答案。
- Given 合法 JSON 或外层 JSON 围栏 When 解析 Then 只返回 prompt 正文，内部代码块不删除。
- Given 截图中的解释加 text 围栏或不合法结构 When 解析 Then 拒绝为优化成功，提示格式错误且原文仍保留。
