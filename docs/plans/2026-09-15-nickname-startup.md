# 启动时重复弹出昵称设置

状态：已修复并验收，随 [beta.16](2026-09-15-beta16-release.md) 公开发布。

1. 为已有昵称的延迟读取、重复启动和真正缺少昵称补充回归，复现先弹表单再读取资料的问题。
2. 昵称组件在读取完成前不渲染弹窗；仅成功读取且昵称为空时展示设置表单。资料读取失败使用独立错误文案与重试，不将未知状态视为未填写。
3. 保留登录后的资料检查、发布续接、保存简介与账号切换响应隔离；不使用全局本地标志跳过其他账号校验。
4. 运行相关及桌面全量测试，构建验证并提交。

- Given 已有昵称且读取延迟 When 恢复登录 Then 读取期间与完成后均不出现昵称弹窗。
- Given 已保存昵称 When 多次重新挂载工作台模拟重启 Then 每次读取既有资料，均直接继续且不调用保存。
- Given 尚未填写昵称 When 资料读取完成 Then 才展示表单，保存成功后继续原流程。
- Given 读取失败 When 展示错误 Then 明确读取失败而非要求设置昵称；重试返回已有昵称后继续，不弹表单。

## 验收结果

- 修复前新增 3 项组件回归均失败，复现资料读取前弹窗及读取错误仍提示设置昵称的问题；修改显示条件和错误标题后全部通过。
- 15 项专项测试通过，覆盖延迟已有资料、确认缺少昵称、读取错误重试、重复工作台启动、邮箱/Google/GitHub 发布续接、简介保留及旧请求隔离。
- 桌面全量 95 文件、602 项测试通过；正式 API 地址的 macOS 本机构建通过，文档检查通过。
- 未修改服务端或个人资料存储。修复已作为 beta.16 新发行公开，保留 beta.15 历史附件；本机安装未替换。
