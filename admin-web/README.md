# CueTuck 管理台

独立浏览器应用，不进桌面安装包。合同见 [admin.yaml](../docs/reference/openapi/admin.yaml)。本仓库 `backend/` 是预发。

```bash
cd admin-web
npm install
npm test
npm run dev
```

默认 `http://localhost:5174`。先另开终端跑 `backend`（`127.0.0.1:8787`）。默认开发管理员 `admin@promptark.local` / `adminpass` 只在后端显式开发模式首次初始化时创建；改过密码后使用新密码，服务重启不会重置。正式初始凭据见[后端启动说明](../backend/README.md)。Refresh 不写入 Web Storage。

## 本人账号安全

侧栏「账号安全」可验证当前密码并修改本人密码，或确认后退出所有设备。两者成功都会撤销本人的全部 Access/Refresh 并返回登录页，不影响其他账号。没有本地密码的第三方账号可通过找回密码验证邮箱后设置密码（需要 SMTP），不能绕过当前密码直接进行敏感操作。页面显示访问令牌数量，不将其误称为设备数量。完整范围与验收见[最终联调记录](../docs/plans/2026-09-08-admin-acceptance.md)。

## 配置第三方登录

owner 登录后打开「第三方登录」，为 Google / GitHub 填写 Client ID、Client Secret 与回调地址，输入当前密码后按配置版本保存。回调是后端的 `/v1/session/oauth/callback`，本机默认 `http://localhost:8787/v1/session/oauth/callback`，不是管理台地址；正式环境须使用 HTTPS。回调必须与提供商控制台登记值完全一致。保存后可显式「验证授权」并刷新结果；测试不创建账号或退出管理会话，修改配置使旧验证失效。

提供商侧创建应用的说明：[Google Web 应用 OAuth](https://developers.google.com/identity/protocols/oauth2/web-server)、[GitHub OAuth App](https://docs.github.com/en/apps/oauth-apps/building-oauth-apps/creating-an-oauth-app)。软件不会替你创建这些第三方应用，也不会把参数保存当作真实登录验收。

配置保存在 Postgres，立即影响后续登录请求。密钥输入留空保留原值，输入新值替换；停用保留凭据。数据库配置覆盖环境配置。普通第三方用户不会自动取得管理员身份。

后端首次启动自动生成 `.promptark/oauth.key`（相对后端工作目录），Unix 文件权限 0600。可通过 `PROMPTARK_OAUTH_KEY_FILE` 固定绝对路径。Client Secret 使用 AES-256-GCM 加密后入库，API 不回显原文或密文。数据库备份必须配套保管这个密钥文件，多实例共用同一密钥；密钥丢失时应恢复原文件，不能重新生成后覆盖已有配置。文件被 Git 忽略，不要提交或分享。未显式设置 OAuth state 签名密钥时，运行时从此独立密钥派生，避免使用公开的开发签名值。
## 用户管理与固定角色

用户页支持服务端搜索、角色/状态过滤、分页、公开资料详情、停用/启用与撤销全部会话。所有者可调整固定角色；运营管理员仅能操作普通用户；审核员仅有审核与本人安全入口。高危操作确认时输入操作者的当前密码，停用/启用还需原因，不会直接修改目标用户密码，不展示私人提示词或令牌。

旧实例通过服务器 `PROMPTARK_OWNER_EMAIL` 一次指定现有管理员；新库初始账号为 owner。迁移后配置入口仅 owner 可用，重启不会恢复已撤销权限。「注册与邀请」控制新账号注册、邀请固定角色；用户页可发起重置邮件，验证码不会向操作者回显。

## 配置与运营入口

- 内容审核与广场内容：审核原因/历史/批量结果；公开元数据、推荐排序、下架恢复和回收站。不改作者本地正文。
- 分类/模型：大/小分类及模型字典、停用、安全删除和引用迁移；本地自定义分类不受覆盖。
- 自动审核、审核模型、Skills、安全规则：发布限额、规则初筛、版本化文本审核和主备/共识路由。默认关闭；缺模型凭据或含图内容转人工，不能认为图片已被模型检测。
- 邮件服务：加密 SMTP、显式测试、注册/邀请/重置邮件队列及失败记录。SMTP 接收不等于进入收件箱。
- 通知与日志：固定风险元数据的邮件/Webhook、签名和有限重试；渠道和清理默认关闭。清理前备份，安全审计永远保留。
- 模拟账单：持久化测试订单/权益/兑换码批次及使用记录；与真实 Pro 分开，无真实扣费。
- 站点设置、概览、操作审计、系统状态：真实客户端配置、带口径统计、脱敏受限导出和依赖探测。备份恢复按[手册](../docs/how-to/backend-recovery.md)，没有一键执行服务器命令入口。

所有配置先保存再测试；真实 Google/GitHub、SMTP、模型 API 和通知目标由站点所有者提供，开发替身测试不代表真实提供商已经验收。当前本机仍为预发，不是生产发布。
