# ADR 0018：管理台固定角色与显式所有者迁移

## Status

accepted · 2026-09-07

## Context

补充 ADR 0009 的单 admin 基线，不改写旧决策。

## Decision

完整管理台采用 owner、admin、reviewer、user 四种角色，权限在 API 强制校验。新库的服务器初始化账号为 owner；已有实例不自动提升所有管理员，通过服务器 `PROMPTARK_OWNER_EMAIL` 明确选取现有管理员一次迁移。迁移完成后重新启动不会恢复被撤销的权限。未迁移实例兼容既有 admin 配置入口，迁移后仅 owner 可配置登录/站点。

高危用户操作使用当前密码重新认证；操作本人必须使用独立账号安全入口，运营管理员仅可处理普通用户。用户操作与审计同事务，停用和角色变更撤销目标全部会话；所有认证入口拒绝停用账号。管理员操作序列化以保护最后一个有效 owner，不依靠前端按钮隐藏保证安全。

## Consequences

管理写操作使用短事务表锁，适合单站点低频运维；后续达到高并发管理需求时再评估专用锁。OAuth-only 管理员的重新认证由后续身份切片实现，当前明确禁止密码校验无法完成的高危操作。
