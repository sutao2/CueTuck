# 缩略图缓存与卡片摘要

状态：缩略图/缓存及摘要已独立提交，前端/原生回归、浏览器验收和 macOS 调试包构建完成。

## 范围与步骤

1. 专用本地缩略图：原生在后台有界并发读取第一张图片、缩放到最长边 480px 并返回 PNG；不修改原附件。列表不传输原图，显式点击后再读取原图；损坏或超出解码限额时保持占位与原图入口。浏览器内存实现同样生成小图。
2. 缓存：以提示词 ID 与修改版本复用缩略图，共享同一请求；内存 LRU 最多 40 项、编码字符串估算最多 8 MiB，不缓存失败或原图；离屏卸载图片 DOM但允许有界缓存复用，修改版本、导入/恢复与重置失效，旧异步结果不回填新缓存。
3. 卡片只渲染最多 240 字符摘要，不改存储正文、全文搜索、复制与详情编辑。前端/原生回归、浏览器带图往返与长文、macOS 构建验收后分片提交。

本计划替代旧缩略图计划的「每次离屏即释放所有图片字节」要求；其余离线、首图、原附件保留规则不变。

## Given / When / Then

- GIVEN 大图附件 WHEN 卡片进入视口 THEN 仅传输尺寸受限缩略图，生成不阻塞原生 UI；点击后才按需读取原图，关闭释放原图。
- GIVEN 相同条目往返滚动 WHEN 缓存仍在容量范围内 THEN 不重复读库或解码，缓存超限淘汰最久未用项。
- GIVEN 编辑换图或导入/恢复 WHEN 旧请求晚到 THEN 不能覆盖新版本，失败可重新进入视口重试；原图预览不因卡片离屏而关闭。
- GIVEN 超长正文 WHEN 浏览、搜索与打开 THEN 卡片 DOM 为短摘要，搜索仍匹配全文，详情/编辑/复制保留完整正文。
