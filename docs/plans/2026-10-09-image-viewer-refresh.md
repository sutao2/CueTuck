# 图片预览视觉统一

## 计划

1. 将旧黑色查看器接入共享浅深色变量，明确标题、图片画布、工具栏三个区域；放大按钮并增加现有操作提示。不修改加载、缩放、拖动或关闭语义。
2. 保持工具栏与图片不重叠，适配窄窗口和两平台窗口栏。验证加载失败、图片更换、快捷键和关闭焦点返回。
3. 运行相关回归与构建，浏览器检查横竖图、长文件名、浅深色和窄窗口；记录结果并提交。

## 场景

- Given 浅色或深色主题 When 打开图片 Then 预览使用一致的中性配色，图片保持比例，工具栏与关闭按钮清晰可用。
- Given 大图和窄窗口 When 适应、原尺寸、缩放或拖动 Then 图片与工具栏不重叠，既有交互保持。
- Given 加载失败或更换图片 When 查看预览 Then 状态反馈可读，旧图片尺寸及位移不会残留。
- Given 键盘打开预览 When Esc 关闭 Then 焦点回到原入口。

## 验收

已完成。预览接入浅深主题，采用独立圆角画布、40px 操作按钮与自然流工具栏；长文件名截断并保留完整悬停标题。保留原有缩放、双击、拖动及关闭逻辑。

18 项相关测试通过（查看器、公开图片、附件与投稿），桌面构建通过。Playwright 隔离图片检查 1200×800 横图、400×500 竖图、明暗主题、原尺寸/适应及 Esc 关闭；无横向溢出，画布与工具栏不重叠。浏览器唯一控制台错误为测试页未提供 favicon。
