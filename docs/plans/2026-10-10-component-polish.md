# 客户端控件质感与合集封面

## 方案

延续 ADR 0026 的中性视觉，用户要求设置和其他页面的控件更细腻，并让广场九宫格封面铺满图片框。

1. 合集独立切片：广场网格九宫格保持三行三列，铺满与普通图片一致的卡片媒体框；详情与列表缩略图保持原比例。多尺寸核对尺寸、占位格及底部操作后提交。
2. 共用控件切片：轻边框、柔和悬停、明确键盘焦点、克制阴影；按钮、输入框、菜单与开关统一细节。设置短选项使用现有选择组件的无搜索模式，长模型/分类列表继续可搜索；选中项用勾号标识。
3. 设置页保留完整页结构和全部保存/失败/未保存确认行为，精修行间距、分组、导航与主题选择；全局改动限客户端已有控件，不改独立启动器窗口边界与服务器数据。

## 场景

- Given 广场合集 When 以网格查看 Then 九个格子铺满媒体框，与相邻普通图片等宽等高，缺图仍占位；窄窗、深色与长标题不裁切操作。
- Given 设置短选项 When 打开下拉 Then 无冗余搜索框，当前值有勾选，方向键/Enter 可选，Escape 返回触发按钮且不改值。
- Given 模型/分类长列表 When 搜索与键盘选择 Then 有界渲染、中文输入法、空结果及既有已选项保持正常。
- Given 设置保存失败或进行中 When 选择新值 Then 失败仍显示旧值和错误，进行中不能重复提交；未保存退出确认保持。
- Given 浅/深色、舒适/紧凑和 1440/820/600px When 查看设置、本地编辑与广场 Then 控件状态可辨，弹层不越界，按钮和文字不裁切；减少动态效果偏好生效。

## 验收

已实现，客户端未发版。全量前端测试与生产构建、docs-check 通过。浏览器验证十个设置页在 1440/820/600px 下无横向溢出，短菜单键盘取消/选择与浅深色外观已验；真实合集组件九格齐全，高 180px，宽度等于卡片内框（684px，外框 686px 含边框）。截图：`output/playwright/settings-polish-light.png`、`settings-polish-dark.png`。
