## 实施与验收

1. 新增持久化字典，保留现有分类 ID 与模型值；首次种子不覆盖编辑，删除保留墓碑，重启不复活。
2. 后台分类、模型页面提供搜索、启停、排序、新建/编辑/安全删除；分类最多两级，模型包含厂商和类型；写入复核 owner/admin 与当前会话，版本冲突不覆盖，审计与业务同事务。
3. 公共字典只返回有效启用项，停用父级隐藏子级；公开大分类筛选支持新增子分类。投稿不能引用不存在或停用的分类；停用已知模型不能继续投稿，兼容既有自由模型字符串。
4. 管理内容表单使用远端字典；桌面/Web 广场与发布表单联动分项验证，未接通项明确记录。远端配置不覆盖本地自定义分类或私有正文。
5. 测试真实 Postgres 的权限、第三层/循环/重名拒绝、引用保护、并发版本、重启和审计回滚；前端验证保存失败草稿保留、删除确认、导航保护；构建与文档检查通过后提交。

## 数据边界

- 字典名称可改，ID/模型值不可改。分类有直接引用、合集成员引用或子分类时拒绝删除；保留投稿历史，不静默改写作者快照。
- 停用不是下架：已有内容仍可访问，不再作为新投稿可选值。
- 数据库事务序列化字典修改与新引用写入，避免删除检查后的并发悬空引用。
- 本切片不配置 AI 审核服务，不发通知或调用第三方模型。
