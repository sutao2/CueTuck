# 全量回归与交互边界修复

状态：计划完成，实施中。

1. 执行三前端测试与构建、原生和 MCP 全量测试；服务端使用远程 CI 隔离数据库，记录本机依赖缺失与失败，不混作通过。
2. 浏览器回归覆盖创建/编辑/变量/复制、图片下载补全与预览、分类整理、发布、设置和后台审核失败重试；原生检查广场、Skill、更新和重启登录。
3. 对已确认问题先补失败用例再修复：启动器布局变化意外触发悬停选中；下拉框右侧溢出、百项以外的当前值被回车改掉。登录恢复测试使用无代理的本地假服务，避免环境代理干扰。
4. 补验、构建并安装修复版；提交规格和验收记录。当前任务不另建公开发行版。

- Given 启动器列表展开且鼠标静止 When 新行出现在鼠标下 Then 不改变键盘高亮；实际移动鼠标后仍可选行。
- macOS 实机补验发现布局变动也会产生零位移 mousemove，选行须检查实际位移，不能仅把 mouseenter 换成 mousemove。
- Given 下拉框靠近窗口右边且宽度大于 280px When 打开 Then 弹出层保持在视口内。
- Given 当前模型位于第 100 项之后 When 打开并直接回车 Then 保留当前模型，渲染不超过 100 项，搜索仍可找到全部选项。
- Given 本机配置网络代理 When 登录恢复测试请求隔离 loopback 服务 Then 测试直接连接假服务，不依赖外部代理。
