# 客户端图片附件与内容展示

## 计划

1. 在本地 SQLite 增加提示词附件 BLOB 表，正文与附件事务保存，列表只读计数、不加载文件正文。允许 PNG/JPEG/GIF/WebP、PDF、TXT/MD/CSV/JSON、DOCX/XLSX/PPTX；每文件 5 MiB、每提示词 20 MiB、最多 12 个。不执行附件或渲染 HTML/SVG。
2. 新建/编辑页增加非模态资料区：文件选择、拖入、粘贴图片、删除草稿、图片和纯文本预览、另存副本。保存前不写库，读取/保存失败不丢草稿；原有未保存保护覆盖附件。使用页可查资料但复制仍仅正文，原生启动器不变。
3. SQLite 备份、ZIP 和 JSON 导入导出保留附件。云同步与广场投稿排除附件，远端输入不能覆盖本地附件；界面明确本地范围。远端上传权限和附件审核不纳入本切片。
4. 重新整理卡片和列表信息层级：标题/摘要为主，分类、模型、图片/文件计数为次；去掉列表固定大标签列，缩小空白、保持操作可见，覆盖长标题、空内容、合集、窄屏、浅深色。
5. Rust 事务/限额/备份/隐私测试，Vue 添加/删除/预览/失败测试，浏览器真实文件与布局测试，构建 macOS 包，正常提交（不绕过 WorkLog）。

## Given / When / Then

- GIVEN 新建或已有提示词；WHEN 选择/拖入/粘贴支持的文件并保存重开；THEN 文件和正文均保留，取消不落盘。
- GIVEN 非法类型、超限或文件读取失败；WHEN 添加或保存；THEN 显示原因，不部分覆盖原内容。
- GIVEN 附件有未保存变化；WHEN 返回或切换侧栏；THEN 触发现有离开保护。
- GIVEN 带附件提示词；WHEN 备份恢复或 JSON 导出导入；THEN 附件完整保留且导入归属新提示词；同步/投稿不发送文件。
- GIVEN 窄窗口、长标题与不同类型内容；WHEN 切换网格/列表、浅/深色；THEN 无横向溢出，摘要截断合理，标题及操作键盘可达。

## 验收

- 已实现：本地事务附件、文件选择/拖放/粘贴图片、页内图片与文本预览、导出副本、附件草稿离开保护、读取失败禁止覆盖；使用页按需读取资料，复制只包含正文。主窗口关闭 Tauri 原生拖放拦截，使用 HTML 文件拖放，独立启动器不变。
- 已实现：内容优先的列表/卡片，分类与模型次级信息、图片/文件计数、窄窗口两行筛选工具栏；附件内容不随列表批量读取。
