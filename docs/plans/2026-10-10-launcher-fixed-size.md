# 启动器固定尺寸

## 设计（已完成）

用户明确要求固定大小。空输入、搜索等待、零/少/多结果、变量填写与草稿统一使用设置中所选尺寸（默认 620×420）；移除内容高度计算与原生可选高度参数。原生仍按显示器工作区限制大小，不改变定位与失焦恢复规则。空输入保留搜索栏、简短输入引导和底栏，不展示历史内容或联网。

此决定取代前两轮计划中的空查询收起与内容自适应高度。

## 验收场景

- Given 空查询 When 输入、清空以及搜索返回不同数量 Then 窗口高度保持所选值，长结果仅列表滚动。
- Given 搜索结果 When 进入填写/草稿并返回 Then 尺寸不变，查询、高亮与键盘语义保留。
- Given compact/standard/large When 显式重新唤起 Then 应用对应固定尺寸；小显示器继续按工作区限制。

## 记录

56 项前端回归、12 项原生启动器测试、生产构建与文档门禁通过。Playwright 实测空输入、单条结果、填写、无结果和清空输入均为 420 高；配置初始高度同步为 420。未发布安装包。
