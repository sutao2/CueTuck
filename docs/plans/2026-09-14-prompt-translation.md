## 独立切片

1. 本机 AI 配置整合优化/翻译两个模型选择；草稿地址/Key 可直接获取模型，解决必须先填写模型才能获取列表的循环。保留旧配置，凭据仍在系统凭据库。验证空列表、失败、地址变化、保存与旧配置迁移。
2. 共用翻译文本保护/请求/响应校验；本机按源摘要缓存，广场持久版本表与后台任务；管理模型发现接口使用现有公网访问与权限门禁。验证变量、代码、JSON、长文、拒绝/截断、并发和过期。
3. 对接广场/详情/使用页及管理配置与任务页；下载保留原稿和已有版本。验证中文/原文检索、离线、原文复用、失败重试、当前语言复制与同一条目计数。
4. 获取百炼模型列表并用公开样本评估；盘点线上条目、备份、设置有界任务后批量生成中文，跟踪进度与错误。记录实际模型、用量和已完成范围，不将排队等同于完成。
5. 完成前端/原生/后端回归、生产部署和客户端构建验收，提交切片与记录。

## 发布约束

只新增版本及缓存，不覆盖作者原文、不自动处理用户本地正文。模型列表由供应商实际返回，保留已保存但不在列表中的选项并标明；不把模型可枚举当作可调用。公开付费翻译须鉴权、并发合并和服务端用量限额；管理员批量任务独立控制。

## 进展

- 切片 1：本机统一配置已加入独立翻译模型；列表支持未保存草稿获取、搜索选择和原有选择保留。旧配置兼容，地址不同不复用旧 Key；3 项组件与 3 项原生配置测试通过。翻译调用与页面接入继续实施。

- 切片 2–3：共享变量/代码/链接与 JSON 翻译保护、本机独立缓存、服务端版本/持久任务/额度、管理配置与模型目录、中文优先轻量检索、详情及使用页切换和下载缓存已实现。首轮客户端 545 项、管理端 102 项、原生 118 项通过（6 项已有忽略）；新增 5 项语言交互测试与 5 项后端翻译/权限/失效测试通过。两个前端构建通过，后续修改继续复验。
- 实际模型目录返回 qwen-mt-flash/lite/turbo/plus；Flash 与 Lite 固定模板样本均 HTTP 200、finish=stop 且标记保留。Flash 样本 120 输入/33 输出 tokens，Lite 120/37。真实长文/JSON 任务测试继续执行；发现并修正中文标点紧贴 URL 导致保护校验误报。
- 线上只读盘点：22,391 条 prompt，正文共 10,256,742 字节，最长 15,646 字节；166 条正文包含汉字。尚未启动线上批量生成，原文未改动。

- 真实 worker 三类样本已通过：165 字节变量/代码/链接、166 字节嵌套 JSON、8,110 字节长文；保护标记缺失时采用只翻译自然语言片段的降级路径，原文参数由程序拼回，校验仍生效。浏览器实际使用页确认英文原稿复用、参数「小明」保留和语言控件布局。

- 功能提交 `1db0a7e` 已推送。最终后端 157 项单元回归通过、4 项显式忽略，15 项集成回归通过；管理端新增任务/目录 2 项与审核模型 4 项通过。客户端版本提升到 beta.10 构建新安装包，避免复用已发布 beta.9 资产。生产数据库备份后正在构建独立镜像。

- 远程回归指出合集详情会为每个成员重复请求翻译版本；已改为复用内容接口随正文返回的版本，保持附件与正文读取边界，并减少无谓网络请求。
