## 进入标准

- M0 完成记录已写，或你明确允许在 M0 收尾同时开工骨架
- 逐步计划仍有效（文件路径未过时）

## 交付物

- `desktop/`：Vue 3 + Vite + Tauri 2
- 主窗口：对齐原型节奏的工作台壳（顶栏、侧栏、内容区、底栏）
- 启动器窗口：可显示/隐藏，空库空态
- SQLite 可初始化

## 退出标准（完成时勾选）

- [x] `desktop/` 可 `npm test` 与约定的 Tauri 开发命令
- [x] 主窗口可见四段壳层
- [x] 顶栏或底栏可显示独立启动器（全局快捷键改到 M3）
- [x] 本地库初始化成功，底栏或启动器能表示就绪
