# 设计：M8 设置对齐原型

## 方案

设置弹窗左侧改为与原型相同的十类。已有页面上的已接通控件全部保留，在同一页追加缺失行。新分类先能打开并列出原型中的行。

本机行在 M8 接真实行为并写入 `settings` 表。云能力行只展示「尚未提供」，不发请求、不写假状态。账号页的「当前账号」复用 M5 已有邮箱密码会话，不新增 OAuth。

启动器唤起快捷键保持不变；新建提示词与快速粘贴最近使用作为额外全局快捷键注册，冲突时失败提示与现有快捷键相同。

主题增加 `system`，不得删除 `light` / `dark`。JSON 与库文件备份保留；ZIP 与自动备份是额外导出/调度，失败不得毁掉已有备份文件。

## 文件

- `docs/specs/settings/spec.md`：十类导航与行；已有场景保留
- `docs/specs/launcher/spec.md`：附加两条全局快捷键
- `docs/specs/variables/spec.md`：双语开关不得删正文
- `desktop/` 设置弹窗、快捷键、备份
- 测试映射未开始的场景在实现时补，不得删场景

## 风险

- 在未验证的 Windows / Linux 上声称开机启动或托盘已生效，违反宪法第 10 条
- 用占位开关假装同步或更新，违反设置规格
- 把 ZIP 做成唯一备份从而丢掉 JSON / 库文件恢复
