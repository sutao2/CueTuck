# 官网与 Web 工作台设计预览

状态：交互设计完成，已部署并验收。

## 本轮范围

用户要求先设计并部署到既有服务器。本轮交付独立静态交互原型，不替换现有 `web/` 业务应用，不接账号、收费或私有数据。原型清楚标记示例数据；复制真实写入浏览器剪贴板，其余收藏/新建仅当前标签页内存。

同站两层：官网用于产品介绍、真实桌面截图、下载与进入工作台；工作台用于提示词/Skills 发现、分类搜索、收藏、详情和变量填写。视觉采用 CueTuck 青绿、暖白纸面与紧凑卡片。正式信息架构拟为 `/` 官网、`/app/` 工作台、既有 `/v1/` API；先以 `https://prompt.likh.cn/preview/` 部署原型，避免改变 API 路由。

## 实施顺序

1. 完成官网、工作台、详情与填写、收藏和新建的响应式交互原型；导航支持浏览器前进/后退，输入文字安全渲染。
2. 通过独立 Playwright 会话验证桌面/窄屏布局、搜索分类、详情填写复制、收藏、新建和页面切换；检查控制台与断链。
3. 使用独立 Docker Compose 静态容器，仅绑定 loopback；备份站点配置并添加 `/preview/` 路由。Nginx 校验后 reload，验证 HTTPS 页面与既有 API/管理端健康；记录回滚位置。
4. 文档检查后提交源码与验收记录，不提交凭据或构建输出。

## 验收场景

- Given 官网 When 点击在线体验 Then 进入同站工作台设计，返回官网与浏览器前进/后退可用。
- Given 工作台示例内容 When 搜索或选分类、收藏 Then 结果、计数与空态一致，不请求线上私有 API。
- Given 含变量提示词 When 填写并复制 Then 预览替换变量，剪贴板成功才提示完成，失败保留文本。
- Given 手机窄屏或桌面 When 浏览官网与工作台 Then 主操作可达，无横向页面溢出，模态可通过 Escape 关闭。
- Given 已有生产部署 When 发布预览 Then API、管理端和数据库保留，只有新增预览路径及独立静态容器。

## 下一阶段设计边界

正式实现复用现有 Web 鉴权、账号库与广场服务，并补齐会话、错误重试和真实来源展示。网页使用账号库；桌面使用本机库，不默认声称自动同步。本机 Skills 安装、全局快捷唤起和离线本机文件由桌面端承担。预览中的 Skills 页只演示发现和说明，不执行安装。

## 已交付与验收

- [官网](https://prompt.likh.cn/preview/)、[工作台](https://prompt.likh.cn/preview/#app)、[Skills](https://prompt.likh.cn/preview/#skills) 和 [下载页](https://prompt.likh.cn/preview/#download) 共用导航与品牌。预览包含 9 条自写提示词和 3 个 Skill 信息结构示例，下载按钮连接已公开 beta.14 资产。
- 本机 Playwright 验证搜索、模型输入筛选、分类、空态、收藏、变量替换、真实剪贴板复制、Escape、草稿安全渲染、Skills 说明和浏览器前进/后退；6 页 × 3 种宽度（1440、960、390）无页面横向溢出。窄屏按钮换行问题已修正。
- 线上 Playwright 复验 6 页 × 2 种宽度及桌面首屏，检查账号说明、列表视图、复制拒绝时保留输入；无 JavaScript 错误，控制台无错误/警告。真实页面截图保存于本机 `output/playwright/cuetuck-website-*.png`。
- 独立容器 `cuetuck-website-preview-website-1` healthy；固定 Nginx 镜像，仅绑定 loopback 15175，静态目录只读。未修改业务数据库或账号配置。
- HTTPS 预览返回 200；5 个公开静态资源的 SHA-256 均与本机产物匹配，未发布路径返回 404。现有 `/v1/health` 的 Postgres、Redis、MinIO 均为 true，管理端返回 200。
- 初次 Nginx reload 后的即时请求曾返回旧路由 404；新 worker 生效后，本机 HTTPS 与公网、真实浏览器复验均通过。配置备份与回滚入口见 [部署说明](../../deploy/README.md#官网与-web-设计预览)。
- 本轮没有将设计原型作为正式账号库或同步功能上线；这些功能仍需下一阶段实现与真实业务验收。
