# 启动器紧凑化与主题完善

## 范围

本次按 macOS 日常使用完善独立启动器，不替换为主窗口弹窗，不改变剪贴板/辅助功能权限边界，不新增未经实机验证的跨平台自动粘贴。

## 实施顺序与验收

1. 统一原生配置、窗口命令和浏览器预览的尺寸；搜索结果与填写均为 620 × 420，空查询 620 × 64。验证：JS/Rust 尺寸与定位回归、浏览器入口参数一致。
2. 收紧头部、列表和双栏间距，保留文字大小、独立滚动与固定操作栏。验证：真实浏览器检查 0/3/12 变量、长正文、逐项回车、明暗主题，无水平溢出或遮挡。
3. 补齐启动器跟随系统主题。验证：系统变化、显式浅/深主题优先级和卸载清理；回归复制失败保留、输入法、关闭后不重新聚焦。
4. 前端测试/构建、原生测试与本机调试打包后提交；记录未做实机验证的边界。

## Given / When / Then

- GIVEN 搜索结果已展开，WHEN 进入填写或返回，THEN 窗口均保持 620 × 420，不跳位、不再次缩窗。
- GIVEN 查询为空，WHEN 输入再清空，THEN 高度在 64 与 420 之间切换但左上角不变。
- GIVEN 多变量或长正文，WHEN 滚动或按 Enter 前进，THEN 当前字段可见、预览独立滚动，复制/返回/粘贴始终可操作。
- GIVEN 主题为 system，WHEN 系统明暗变化，THEN 启动器同步；显式 light/dark 不被系统覆盖。
