# P3c 发布与同步反馈

状态：已实现；桌面前端 59 文件、406 项测试与前端构建通过。

1. 发布页立即展示加载、读取失败重试与空本地库；关闭/重开隔离请求，加载完成不抢回页面。
2. 提交失败保留选择；提交成功或仅本机入队用固定提示，队列处理失败不把已送达稿件误报成未提交。
3. 同步区分个人库与队列阶段；当前账号剩余任务需明确显示，提供仅队列重试；处理中不能关闭设置，账号切换不显示旧账号成功。
4. 隔离故障注入、前端全量测试与构建，更新合同后提交。

## 场景

- GIVEN 发布源读取延迟；WHEN 关闭再打开；THEN 旧结果不影响新页，加载中不可提交。
- GIVEN 源读取失败；WHEN 重试；THEN 只读取，成功后可选择；空库显示新建引导。
- GIVEN 投稿成功但本机队列后处理失败；WHEN 查看结果；THEN 明确已提交及队列异常，不诱导重新投稿。
- GIVEN 个人库已同步而队列仍有本账号任务；WHEN 同步结束；THEN 告知未送达数量，重试仅处理队列。
- GIVEN 正在同步；WHEN 返回或连续点击；THEN 不关闭也不重复同步；换账号后不显示旧账号结果。
