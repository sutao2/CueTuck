# 正文阅读与合集下载修复

## 计划

1. 补齐原生公开内容响应的 cover 字段，使用真实失败形状验证序列化往返，不放宽附件完整性校验。
2. 本地顶层浏览隐藏仍属于有效合集的 downloaded 成员，计数遵循相同视图；保留下载识别、合集详情、启动器与全库成员查询。解除归属后重新显示，不删除或迁移正文。
3. 广场单条/合集成员、本地详情使用共享安全 Markdown 阅读组件，默认预览、可切原文；仅渲染文本，不执行 HTML，不自动加载正文外链图片。复制/使用/编辑仍传原文。
4. 回归：封面独立附件、损坏关联拒绝、顶层和合集计数、移除成员恢复、Markdown 表格/代码/变量/恶意 HTML 与 URL；浏览器核对明暗及窄屏。分可验收切片提交，不自动部署。

## 场景

- Given 有九张独立封面的合集 When 原生读取并下载 Then 封面 manifest 保留，附件校验及原子导入成功。
- Given 下载合集 When 浏览本地顶层 Then 只显示合集；进入合集仍有完整成员；移出成员后独立显示；重新下载识别原副本。
- Given Markdown 正文 When 查看详情 Then 结构化阅读且能查看原文；使用与编辑保留 Markdown 及变量不变。
- Given HTML/脚本/危险链接 When 预览 Then 不执行或发起隐藏外链图片请求。
