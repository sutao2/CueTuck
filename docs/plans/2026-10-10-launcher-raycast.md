# 启动器 Raycast 视觉调整

## 设计（已完成）

用户否定上一版视觉并明确要求参考 Raycast。参考 https://www.raycast.com/windows 的真实命令列表：搜索优先、单行标题与次级说明、小尺寸语义色图标、柔和整行高亮、底部当前操作。

本轮调整搜索态的排版与视觉：将应用标识移至底部；顶部采用搜索图标；摘要同行省略，完整标题/摘要保留 title；去除左侧选中竖线与黄色高亮底色；右下角使用与复制均为真实按钮，调用现有操作。保留三项快捷操作、空查询收起、内容高度上限及所有现有键盘语义，不新增操作菜单或联网行为。Windows 保留实色客户区与原生阴影。此次用户指定的启动器参考优先于 ADR 0026 的通用视觉方向；主窗口继续沿用该 ADR，不修改历史决定。

## 验收

- Given 本地提示词与快捷操作 When 搜索 Then 标题和摘要同行，图标与文字对齐，标签不与标题争夺注意力。
- Given 方向键选中提示词或快捷操作 When 点击底部主操作 Then 与 Enter 相同，复制按钮仅在提示词选中时出现。
- Given 中文/英文、浅色/深色、长标题与多结果 When 渲染 Then 不横向溢出、底部固定可用，列表到上限滚动。
- Given 单条搜索进入变量填写 When 返回 Then 搜索高度和高亮恢复。
