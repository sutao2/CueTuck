# 详情页图片排版预览

## 计划

1. 选择两张 Pexels 自然光户外群像摄影，记录作者与来源。作为用户请求的排版样图，不修改广场条目、不声称是提示词生成结果、不加入下载数据。
2. 详情页增加显式的“加载示例图片（联网）”入口，点击后显示主图与缩略图切换、来源及关闭示例。离开条目后清空示例状态；加载失败可重试，不影响正文/下载/收藏。
3. 详情使用限宽阅读布局，返回和主要动作靠近标题；正文以文档展示，保留举报能力但降低视觉优先级。不创建新的模态窗口。
4. Vue 测试覆盖示例开关、切换、错误与条目切换重置、下载事件不含样图；浏览器与 macOS 检查真实加载及排版，正常提交。

## Given / When / Then

- GIVEN 没有示例的详情；WHEN 用户点击加载示例；THEN 才请求外站图片，并明确标注摄影样图而非生成结果。
- GIVEN 两张样图；WHEN 选择缩略图、图片失败或关闭；THEN 可切换/重试/退出，不影响真实正文与下载事件。
- GIVEN 已显示样图；WHEN 更换条目；THEN 示例状态重置，不把图片归属另一条目。
- GIVEN 窄窗口或长正文；WHEN 阅读详情；THEN 图像不变形，内容内部滚动，无横向溢出，动作无需滚至页底。
