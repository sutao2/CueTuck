# 启动器搜索框焦点样式修复

## 设计（已完成）

beta.38 将搜索框换成 textarea 以保留粘贴的多行文本，触发了启动器通用 textarea 焦点规则，出现蓝色矩形外框。针对搜索框覆盖该规则，恢复紧凑搜索栏的既有视觉。

## 验收场景

- Given 搜索框自动获取焦点，When 空查询或键盘输入，Then 浅色与深色下均无内嵌蓝色矩形，空查询栏保持 64px。
- Given 粘贴含换行、空行、缩进的内容，When 选择添加资料，Then 正文逐字保留。
- Given 使用 Tab 切换到加号和 Esc 按钮，When 按钮获取焦点，Then 保留键盘焦点标识。

## 验证记录

52 项启动器回归通过。浏览器以真实 Tab 焦点验证浅深色搜索框无矩形外框、空查询 64px、加号按钮保留焦点标识；真实粘贴的换行、空行、缩进与尾部空格在资料编辑器中逐字保留。截图位于 `output/verification/launcher-focus-light.png` 与 `launcher-focus-dark.png`。
