# 16. 以 Codex 风格方向重排工作台与设置

- Status: accepted
- Date: 2026-09-06
- Supersedes: [ADR 0015](0015-workbench-visual-system.md)

## Context

用户明确要求整体框架参考 Codex，尤其反馈设置布局不协调。前次只统一字体与颜色，重复标题、混杂的表单布局与横向空间切换仍有问题。当前工具不允许直接读取 Codex 原生窗口；这是框架风格参考，不是像素复刻。

## Decision

保留四区工作台、系统窗口控件、两级分类与全部原有动作。使用中性灰侧栏、白色/深灰内容工作面，纵向空间导航，账号和偏好收在侧栏底部；减少强调色与顶栏工具堆叠。

设置仍为固定尺寸弹窗，不改独立窗口或路由。取消跨栏重复标题，设置名称归左侧，右侧仅显示当前页标题；导航增加线性图标。简单选项左说明右控件，多字段资料与长文本纵向排布，控件统一尺寸、开关与焦点状态。十类设置及所有行为保持可用。

## Consequences

不改变数据库、网络规则或独立启动器；视觉变量仅在主窗口作用。需要验证十页布局、浅深色、较短视口、表单交互及浏览器内存与原生数据隔离。
