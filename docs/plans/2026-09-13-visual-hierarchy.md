# 工作台视觉层级

状态：方案已定，按浏览面和编辑面实施并验收。

## 设计与步骤

延续 ADR 0017 的中性色、直线主框架和独立启动器。只调整桌面内容层级，不恢复模糊背景，不改变缓存和虚拟列表策略。

1. 浏览面：当前结果标题与数量合入页头，取消列表上方重复标题；站点自定义标题/公告保留。侧栏去掉空间入口重复本地总数，分类计数保留，选中分类有清晰标记。卡片统一标题优先、图片其次、摘要和元数据层级；使用/下载为主操作，复制、收藏与更多为轻量次操作，全部保留键盘入口。混合图片行不伪造图片占位，不使操作超出虚拟卡片高度。
2. 编辑面：模型与分类使用紧凑行，空间不足时自然换行；压缩标题、元数据和工具间距，正文与试填保持主要空间。保留字段名称、草稿保护、快捷键和附件入口。
3. 验收：现有回归、浅深色/1280 与 800px/网格与列表截图，混合图片与长元数据不溢出、主操作可见；编辑试填与返回、macOS 构建和文档门禁。独立切片完成即提交。

## Given / When / Then

- GIVEN 浏览本地或广场 WHEN 搜索、切分类或排序 THEN 页头显示唯一当前结果标题与准确数量，活动筛选仍可清除，站点信息保留。
- GIVEN 图文混合及长标题/模型/分类 WHEN 切换视图、主题或缩窄窗口 THEN 标题优先、元数据次要、操作始终可达且不被虚拟卡片裁掉。
- GIVEN 侧栏展开或折叠 WHEN 切换空间与分类 THEN 分类计数保留，当前分类有明确标记，折叠/搜索/启动器行为不变。
- GIVEN 编辑提示词 WHEN 修改模型、分类或打开试填 THEN 正文保持主要空间，窄窗口字段不溢出，保存及未保存返回行为不变。

## 验收

浏览面：481 项既有前端回归通过，混合图文/元数据、浅深色、网格/列表和 800px 浏览器检查通过。截图发现固定高度广场卡片会压缩摘要第三行，改为完整两行并保持作者单行；后续复验与编辑面一起完成。
