# P3b 合集加载与成员反馈

状态：P3b 已实现并验收。

## 范围与步骤

1. 合集读取增加加载、失败、只读重试状态；请求只更新对应的当前打开实例，返回或切换后丢弃旧结果。
2. 成员加入/移出区分写入与刷新；写入失败保留选择，写入成功后刷新失败只允许读取重试，不重复写入。
3. 隔离内存库注入延迟与错误，验证键盘/忙碌/返回路径；全量前端测试、构建及文档检查后独立提交。

不改数据模型，不引入弹窗，不修改用户真实提示词；发布、同步另作后续切片。

## Given / When / Then

- GIVEN 合集尚在读取；WHEN 页面打开；THEN 显示加载而非空合集，编辑和成员操作不可用，仍可返回。
- GIVEN 旧读取尚未结束；WHEN 返回后打开另一个或同一个合集；THEN 旧成功或失败均不能覆盖新页面。
- GIVEN 读取失败；WHEN 点击重试；THEN 仅重新读取，恢复后显示真实成员。
- GIVEN 成员写入正在进行；WHEN 重复点击或尝试返回；THEN 只写入一次且不会离开处理中页面。
- GIVEN 加入写入失败；WHEN 显示失败；THEN 保留选择并允许重新提交。
- GIVEN 加入或移出已成功、后续读取失败；WHEN 显示结果及重试；THEN 明确操作已完成，仅刷新而不重复写入。
