# 高风险通知与运行日志保留

| 字段 | 值 |
|---|---|
| 状态 | 代码、自动化及真实页面验证通过；外部目标未配置，正常提交受 WorkLog 评审门禁阻塞 |
| 范围 | A19；复用 A08 邮件投递和 A12 审计，不扩展群发平台 |

## 配置与发送边界

- owner 当前密码 + revision 配置邮件收件人（单一邮箱）、邮件/HTTPS Webhook 开关、风险阈值 1–100、每日额度 1–1000。默认均关闭。邮箱渠道复用已启用且配置完整的 SMTP，未配置明确不可用。
- Webhook Endpoint 本身可能包含路径秘密，因此与签名密钥一起加密；GET 仅返回 endpoint_configured、主机和 secret_configured。空输入保留，签名密钥至少 16 字节；更新取消旧版本未完成 Webhook 工作，不把旧任务发往新目标。
- Endpoint 使用现有 outbound HTTPS/公网 DNS/IP 校验、固定解析、防重定向/no_proxy，禁本机/私网/保留地址、用户信息、查询和片段；单次最多 15 秒，失败仅固定诊断，无外部响应正文。
- Webhook POST 固定 JSON 元数据（事件 ID、来源、公开内容 ID、风险分数、时间、是否测试），不含作者邮箱、提示词正文、词库命中原文、令牌或凭据。HMAC-SHA256(raw JSON) 放 X-PromptArk-Signature（sha256= 前缀），X-PromptArk-Delivery 为稳定投递 ID；接收方据此验签和幂等。
- 显式测试仅发送固定测试通知到已保存渠道，响应 queued 不代表送达；不会在只保存配置时发测试。真实外部测试需要用户指定目标，开发只用隔离本地替身/队列测试。

## 事件与队列

- 只消费已有成功审计中的 publication_auto_screened / publication_ai_screened 高分事件；本地初筛与 AI 分开标注。启用时记录起点，默认不回补旧投稿/历史。新配置阈值对起点后的尚未处理事件生效。
- 持久化事件+渠道去重，采集/入队同事务，每轮有界；高风险事件经相同已提交审计驱动，不因通知故障回滚作者投稿。配额超限/依赖未配置也有可见跳过记录，不假报发送。只影响公开投稿，不读取本地库或私有同步库。
- 邮件复用 mail_outbox 的加密载荷、租约、有限重试和状态；通知列表关联真实邮件记录，SMTP accepted 仅表示服务器接收。
- Webhook 队列原子 claim、45 秒租约，最多 3 次、退避重试、24 小时期限；重复 worker 不同时发送同一租约。外部投递是至少一次，超时结果可能未知，UI 与文档明确提醒；相同 ID 供接收端去重。
- owner 查询分页投递列表和必要尝试历史，可显式重试未过期且未耗尽额度的失败任务。成功/取消/过期不能重试，旧版本不能跨配置发送；所有操作有脱敏审计。

## 日志保留

- retention_enabled 默认 false，保留天数 7–3650，owner 当前密码确认保存后才启动清理。页面明确说明清理不可通过本页面撤销，先按备份手册留存。
- 仅清理超过期限的 request_failures、终态通知/Webhook 尝试、终态邮件及其尝试、终态 OAuth 验证运行记录；不清理 security_audit、账号、身份挑战、配置历史、投稿、账单或私有库，不删除活动/待发送任务。
- 清理按小批次事务执行并记摘要计数，正常查询不触发删除。安全成功审计永远保留；无任意日志删除接口。

## 实施与验收

1. 配置、队列和增量迁移、密钥丢失启动保护；正文不外发的固定事件结构、出站保护和原子去重。
2. 高风险审计采集、邮件入队复用、Webhook claim/complete/retry、有限 worker；失败不改变已有业务提交。
3. 后台通知/日志策略页面、显式测试和重试、空/错/加载态、配置草稿/当前密码/密钥保护；系统状态展示通知队列。
4. 隔离测试权限/CAS/审计回滚/秘密保护、重复采集/配额/启用起点、租约/过期/旧配置、Webhook 签名与错误、关闭留存不删和开启后仅终态过期删除且保留安全审计；前端和全量构建/文档/浏览器后正常提交。

## Given/When/Then

- GIVEN 未启用渠道或没有 SMTP/Webhook 凭据；WHEN 保存/测试/发生风险事件；THEN 不发外部请求，显示未配置或跳过，不能标送达。
- GIVEN 两个 worker 同时处理同一已提交高风险事件；WHEN 入队或发送；THEN 相同事件/渠道只入队一次，租约防并发发送；不发送正文或作者邮箱。
- GIVEN 外部超时、目标变化或失败次数耗尽；WHEN 自动或手动重试；THEN 保留真实失败和次数，不跨配置重试、不无限循环。
- GIVEN 未开启保留策略或活动任务存在；WHEN worker 清理；THEN 不清理；显式开启后仅删除过期终态运行日志，security_audit 始终保留。
