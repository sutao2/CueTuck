# P3a 客户端保存与复制反馈

状态：P3a 本地验收完成。只修主窗口保存/复制及其刷新反馈；发布、同步和合集加载竞态留给后续切片。

## 步骤与验收

1. 用隔离内存库复现：写入成功但列表/父合集读取失败不能说保存失败；写入失败保留草稿及重试；重复点击只写一次。
2. 保存先完成写入，再退出编辑并提示成功；后续读取失败使用全局可见提示，提供只读刷新重试，不重新执行创建或更新。保持原列表筛选及父合集上下文。
3. 编辑页面内 Cmd+S / Ctrl+S 与保存按钮走同一路径；拦截浏览器保存，不拦截普通 S、组字、重复按键或放弃确认里的操作；忙碌/无效草稿不能提交。
4. 复制成功先完成使用页面，结果留在固定提示；使用记录失败与列表刷新失败分别说明，不能误报复制失败或诱导再次复制。剪贴板失败仍保留填写内容，不计数。复制期间禁用上一步并在处理函数校验忙碌。
5. 组件故障注入验证上述场景，客户端全量回归/构建、隔离界面检查；更新合同及 INDEX，独立提交，不推送。不使用真实用户数据执行写入。

## Given / When / Then

- GIVEN 新建或编辑提示词/合集；WHEN 数据写入成功后刷新失败；THEN 关闭已保存编辑器，固定提示「已保存，但刷新失败」，仅刷新重试且不重复写入。
- GIVEN 本地写入失败；WHEN 保存；THEN 草稿、附件选择与编辑页面保留，修复后可再次保存。
- GIVEN 保存请求未完成；WHEN 连续点击、保存快捷键或离开；THEN 仅一次写入，不丢草稿。
- GIVEN 编辑页正常/无效/组字/放弃确认；WHEN 使用 Cmd+S 或 Ctrl+S；THEN 只在可保存状态调用统一保存；普通输入不受影响。
- GIVEN 剪贴板成功且使用记录或读取失败；WHEN 完成使用；THEN 已复制结果仍可见，不假称复制失败，刷新重试不再写剪贴板或计数。
- GIVEN 剪贴板拒绝；WHEN 复制；THEN 保留变量填写、显示失败、无使用计数。
- GIVEN 复制未完成；WHEN 上一步、返回或再次复制；THEN 不切换步骤或重复复制。
