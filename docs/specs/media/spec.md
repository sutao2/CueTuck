# 附件传输

状态：P1a 私有接口、P1b 手动私有附件同步、P1c 单条投稿、P1d 合集成员公开附件及 P1e 保守手动回收已实现。

## Requirements

本地卡片 MUST 使用最长边 480px 的派生缩略图，有界内存缓存与失效规则遵循[缩略图缓存计划](../../plans/2026-09-12-thumbnail-cache.md)，替代旧的每次离屏全部释放策略。原附件 MUST 保留，显式查看大图时再读取原图；缩略图生成失败不得覆盖原文件。


单条广场参考图 MUST 随显式下载校验并保存成本地附件；已有副本可显式补图、按内容去重，不能覆盖本地正文或已有文件。参考图来源受固定 HTTPS 白名单与字节限额约束，不携带会话，不下载纯排版示例。广场及本地图片 MUST 可打开可缩放的大图查看器。行为与故障验收见[下载图片计划](../../plans/2026-09-12-downloaded-images.md)。

私有上传、所有权检查、传输与配额 MUST 满足[私有附件实施计划](../../plans/2026-09-08-private-media.md)的 Given/When/Then 场景。上传到服务器不等于提交审核或公开。私有下载 MUST 经 API 验证会话与所有者；不得对私有文件返回匿名可用的预签名链接。

稿件范围的审核读取和已批准公开读取 MUST 满足 [P1c 计划](../../plans/2026-09-08-publication-assets.md)，不扩大原有私有下载权限。公开字节不走存储直链，且不自动执行文档。

合集成员文件关联、整稿限制及原子下载 MUST 满足 [P1d 计划](../../plans/2026-09-08-collection-assets.md)，沿用稿件清单授权，不扩大作者或审核者的私有访问权限。

既有本地附件边界见[本地库](../library/spec.md)，本轮不静默改变自动同步和投稿行为。元数据字段通过追加迁移保留原记录；不清空数据库或对象存储。

手动私有引用、重试复用与客户端补齐 MUST 满足 [P1b 计划](../../plans/2026-09-08-private-asset-sync.md)。云端引用不能指向其他账号或未完成对象。正文旧客户端省略引用时 MUST 保留已有引用；文件字节不进入账号变更 JSON。

云端已完成未引用对象的手动回收 MUST 满足 [P1e 计划](../../plans/2026-09-08-media-reclaim.md)。引用校验与回收声明必须互斥，失败保留可重试状态。新增超过七天中断上传的显式单项回收和只读分页对账按[管理端补齐计划](../../plans/2026-09-08-admin-hardening.md)执行，取代禁止一切扫描的旧限制；仍禁止整桶清理、未知对象删除和无确认清理。只读扫描限定 promptark/ 前缀，单页桶对象 100 项/数据库对象 25 项、总时限 25 秒；必须显示分页尚未完成，差异不是自动删除依据。

图片审核仅能读取稿件明确选择的合法图片，且须站点启用图片检查、模型显式允许视觉输入。传输前复核所有权、清单、类型、大小和哈希；PNG/JPEG/WebP 最多 4 张、总量 10 MiB，使用内联字节而非存储或用户 URL。其他文档与外部图片引用仍转人工。模型判定不替代附件公开范围的人工作业，也不是病毒检查或图片隐私遮盖。

## 测试映射

`backend/src/media_tests.rs` 覆盖鉴权、所有者隔离、存储往返与故障；`desktop/src/platform/squareContract.test.js` 校验 API 鉴权合同。

GIF 支持按原字节导入、备份、公开附件传输与原图播放；本地列表缩略图仅派生静态帧，不覆盖动画原件。公开稿件封面仅传首张图片元数据，客户端按可见区域使用原有鉴权下载接口，限制并发与内存缓存，详情展示批准图片清单。

合集封面选择和发布 MUST 按实际 PNG/JPEG/GIF/WebP 字节签名生成一致的 MIME 与扩展名，不能信任旧 data URL 或原文件扩展名；保留原图字节、顺序及布局，不转码。未知内容仍拒绝，既有单文件/总量限制不变。选图失败保留原封面并显示原因，读取期间禁止保存。验收场景见[封面类型修复计划](../../plans/2026-09-18-cover-file-type.md)。

公开封面组件 MUST 将调用方布局属性绑定到封面本身，不能因为同时渲染大图弹窗而丢失。列表中封面及加载/失败状态占据同一左侧缩略图区域；打开弹窗后封面尺寸不变，弹窗不继承缩略图样式。

- Given 公开图片尚未加载或失败 When 查看列表 Then 封面不进入正文网格行或遮挡计数，重试不改变卡片结构。

### Requirement: 显式 AI 直接判定（替代强制人工公开边界）

启用 `ai_decides` 时，提示词、合集和 Skill 的完整 AI 结果可直接通过或拒绝；宽松判断与文件范围以 [AI 直接审核计划](../../plans/2026-09-18-ai-decisions.md) 为准，取代上文“一律人工审核”的要求。旧策略未启用时保持原规则；任何未完成检查、错误、版本变化或不明确结论不得假称通过或拒绝。图片传输范围升级为 PNG/JPEG/WebP 最多 12 张、总量 20 MiB，其他未支持格式仍转人工。技能脚本只按文本审查，绝不执行。人工处置和作者撤回优先，审核事件及审计须与结果同事务。
