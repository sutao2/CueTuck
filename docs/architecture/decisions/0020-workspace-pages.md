# 20. 连续操作使用工作区页面

- Status: accepted
- Date: 2026-09-08
- 关联：[主窗口框架](0017-screenshot-workbench-frame.md) · [设置页](0019-settings-page.md)

## Context

用户明确要求尽量减少弹窗，新建和编辑直接进入页面。过去的登录、编辑、使用、合集与详情弹窗中包含连续工作流程，反复遮罩打断了工作区上下文。

## Decision

这些流程（包括发布与新建分类）在主窗口右侧工作区显示页面，保留主壳导航，提供返回入口，不使用 aria-modal、遮罩或悬浮面板。原列表与必要的父详情仅隐藏，返回保留上下文。设置继续沿用 ADR 0019 的完整页面；从设置进入登录时保留设置草稿，返回恢复。

未保存内容、危险删除等短暂决定仍允许确认对话框。跨空间跳转必须处理未保存编辑及忙碌状态，不得静默丢弃。独立启动器保持原生窗口，不改成页面或覆盖层。

## Consequences

替代工作台规格中连续操作默认使用模态的要求，以及 ADR 0019 中“登录继续是对话框”的旧例外；两篇已接受 ADR 其他决策不变。需要覆盖嵌套详情返回、登录续接、保存失败与键盘导航；不声称这是 macOS 唯一合法交互。
