# P1b 私有附件的手动同步

状态：已实现并通过本地自动化与浏览器设置页验收。承接 [P1a](2026-09-08-private-media.md)，不包含公开投稿附件和云端垃圾回收。

## 决定与实施步骤

1. 设置页增加「本次包含私有附件」，默认关闭，不持久保存、不随账号偏好同步。明确本机库全部附件会发送到当前账号，不公开。仅 Wi-Fi 约束打开且无法确认 Wi-Fi 时，本次所有附件延后，正文照常。
2. 上传由服务端按所有者、文件名、类型、长度、SHA-256 复用 ready 对象；账号锁下检查并预留，重复上传中返回 409，失败可以再次手动尝试。不得复用其他账号对象。崩溃留下的 pending 不自动删除。
3. 提示词 payload 增加 asset_refs，保存本地附件 UUID 与私有媒体元数据，不含 base64 或签名 URL。服务端核验所有权、ready 和所有元数据，最多 12 个 / 20 MiB。旧客户端正文写入缺少此字段时保留已存引用。
4. 本片附件采用补齐合并：保留本机未同步附件和账号已有附件，不同步附件删除。合并超限时明确失败，不裁切文件；云端删除与回收另做切片。推送正文仍采用现有时间戳冲突规则。附件变更需要独立推进记录时间戳，避免正文已同步后的同时间戳拦截。
5. 原生客户端复用 API 地址和网络设置，私有上传/下载禁止重定向；下载限时限长并校验 SHA-256。所有文件准备成功且会话未切换后，再在 SQLite 同一事务合并附件；默认正文同步仍忽略远端附件字节。失败保留原文件，不显示成功；重复点击同步受忙碌状态保护。
6. 回归两库往返、默认隐私、正文旧客户端、重试复用、跨账号引用、Wi-Fi 延后、校验失败与事务回滚、保留本地和同版本补齐。运行前后端与原生相关测试、构建和文档检查后提交。

## Given / When / Then

- GIVEN 本机有附件；WHEN 未勾选本次包含附件；THEN 不读取/上传文件，已存云端引用不被正文写入清空。
- GIVEN 明确勾选且已登录；WHEN A 同步再在 B 勾选同步；THEN 私有附件字节一致，默认不进入广场。
- GIVEN 上传响应丢失或再次同步；WHEN 同账号重试同一文件；THEN 复用完成对象、不重复占配额；不同账号不复用。
- GIVEN 他人引用、伪造元数据或超限清单；WHEN 推送；THEN 整批拒绝，不写入部分正文。
- GIVEN 下载中断、哈希错误或会话改变；WHEN 同步；THEN 不落地未验证附件、不覆盖已有本地文件，不报告完成。
- GIVEN 同版本正文已经存在或本机有额外私人文件；WHEN 补齐附件；THEN 补入缺少文件并保留本机文件；保留本地策略不覆盖已有文件。
- GIVEN 仅 Wi-Fi 开启且网络未知；WHEN 勾选附件同步；THEN 正文继续同步并明确提示附件已延后。

## 后续

公开投稿附件需要单独选择、审核可见性和公开读取代理；云端附件删除/回收尚未实现。手动补齐会把账号仍存在的已移除文件重新补回，界面明确不传播附件删除。浏览器传输与原生命令共享同一 API 合同；原生实际网络传输的完整端到端故障注入仍需后续可靠性切片覆盖，不将组件替身测试称为原生实机双设备验收。
