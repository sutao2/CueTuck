# CueTuck 查看与启动器精简

## 计划

1. 移除启动器粘贴到原窗口、复制当前输入入口及专属分支，保留最终提示词复制。更新规格并验证复制成功/失败、失焦保护、三项快捷操作。
2. 图片查看改为深色中性遮罩、图片居中、轻量悬浮工具栏、适应/原尺寸/缩放、双击与拖动，关闭及焦点返回保持。测试加载失败、图片切换、缩放边界及真实浏览器。
3. 本地非虚拟网格按内容高度安排卡片，保留 DOM 顺序；广场有界虚拟滚动保持。修正模型筛选的嵌套边框与文字换行。验收混合图文、窄屏、切换行视图与缩放。
4. 用可维护矢量源设计 CueTuck 提示卡片/收纳意象图标，生成各平台资源；检查小尺寸和透明边界，构建安装。

## 场景

- GIVEN 非空启动器输入 WHEN 查看快捷操作 THEN 只有创建、AI 优化和广场搜索；最终预览可复制，没有粘贴按钮。
- GIVEN 横图、竖图或大图 WHEN 打开预览 THEN 完整适应可用区域，工具栏不遮挡图片；原尺寸可拖动，双击切换适应/原尺寸，Esc 恢复入口焦点。
- GIVEN 图片加载失败或切换图片 WHEN 查看 THEN 正确反馈并重置缩放与位移，不显示上一张图片的尺寸。
- GIVEN 同一批本地内容有短文和参考图 WHEN 网格展示 THEN 文字卡片不被图片撑高，后续卡片填入下方；操作顺序与查询排序一致，列表模式正常。
- GIVEN 应用新名称 WHEN 查看 Dock、启动器及安装包 THEN 使用统一的新图标，32px 仍有清晰轮廓。
