# 开源提示词样本导入

## 范围与步骤

1. 从 YouMind 官方公开同步库（CC BY 4.0）、PlexPt 中文库（MIT）和 f/prompts.chat（CC0）选择 48 条；记录来源、作者、许可、原始图片地址和抓取时间。
2. 生成固定 ID 清单，只向本机开发数据库追加；事务导入，冲突不覆盖；保留原记录及导入前备份。不改生产数据、账号或本地库。
3. 广场返回可选 reference 元数据，客户端展示真实参考图和署名；图片失败不阻断正文。下载保留正文尾部来源和许可，不下载远端图片。
4. 自动测试、重复导入检查、真实页面验收后提交。

## 验收场景

- GIVEN 原广场已有记录 WHEN 导入两次 THEN 首次新增 48 条、第二次零新增，原记录不变。
- GIVEN 图片提示词 WHEN 浏览分类及详情 THEN 展示对应原始图片、来源及许可，不将参考图片声称为本软件生成。
- GIVEN 来源图片失败或元数据缺省 WHEN 阅读或下载 THEN 正文仍可用，历史条目保持兼容。
- GIVEN 导入内容 WHEN 下载 THEN 署名许可随正文保留；外部文本仅作为数据，不执行其中指令。

## 限制

YouMind 仓库同时注明社区收集、教育用途，样本仅用于本机学习与排版验收，不作为商业再分发授权证明。未导入完整网站，不抓取登录后数据。星数只代表抓取时的仓库元数据。

## 使用

启动新版后端后，`node scripts/import-community.mjs` 只校验清单；`node scripts/import-community.mjs --apply-local` 备份并追加到固定本机 Docker 容器 `backend-db-1` 的 `promptark.public.square_items`。只接受本机 Unix Docker 连接，不提供生产库或覆盖模式。重复 ID 跳过，不刷新既有样本内容。

图片从来源站按需读取，不复制到本地附件库；离线图片不可用但已下载正文可用。原始变量写法保留，不承诺所有来源的自定义模板语法可由启动器直接解析。
