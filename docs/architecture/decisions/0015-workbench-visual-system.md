# 15. 以现行工作台能力为基础统一桌面视觉

- Status: accepted
- Date: 2026-09-06
- Supersedes: [ADR 0005](0005-ui-source-prompt-ark-prototype.md)

## Context

用户反馈页面不够专业，要求整体优化。原型的四区布局与分类/空间结构已落地，但宣传式标题、彩色字符图标和不一致的控件节奏不适合长期使用。

## Decision

保留四区工作台、两级分类、广场/本地切换与弹窗流程；现行规格定义交互，原型只保留为结构来源。主窗口采用系统无衬线字体、统一线性 SVG 图标、中性色表面与绿色重点色、适中的信息密度。主操作、选中态与反馈有明确层级；底栏低对比。统一卡片、输入、按钮与弹窗的尺寸和状态，支持深色及窄窗口。

## Consequences

视觉 token 在主窗口范围定义，不改变独立启动器的字体、布局和窗口实现。文案说明实际用途，不将开发阶段或 QA 门禁写进常规使用说明。现有功能入口、数据库和业务规则保留。
