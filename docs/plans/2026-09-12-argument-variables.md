# 导入参数格式兼容

## 计划

1. 桌面共享解析器支持 `{argument name="名称" default="默认值"}`，属性可交换顺序，支持单/双引号与转义引号；name 必填且非空，default 可省略，未知/重复属性或不完整语法保留原文。显式参数与 `{{名称}}` 同名共享，不解释或执行内容。
2. 主窗口和独立启动器预填默认值；同名多次声明采用首个声明的默认值，未填/清空回退默认值，没有默认值则保留原始占位符。替换值保持字面量，不二次解析。原有匿名空位、代码保护和命名变量行为不变，库中正文不迁移。
3. 以用户三个参数回归解析、默认值、修改、复制；补充混合语法、代码字符串、特殊属性名和无效标签测试，构建桌面包并实测生效。

## Given / When / Then

- GIVEN 用户广告正文的三个 argument 参数 WHEN 主窗口或启动器使用 THEN 显示 aspect ratio、background color、hand gesture，并预填 21:9 全景、产品主色调、做出射网手势的红色网纹手套。
- GIVEN 参数已修改或保留默认 WHEN 预览/复制 THEN 输出最终值，不含 argument 标签，原始库正文不变。
- GIVEN 同名参数、匿名空位及普通双括号共存 WHEN 填写 THEN 同名共享且匿名独立，不重复替换插入值。
- GIVEN 不完整/非法参数或转义标签 WHEN 解析 THEN 不把它作为 argument 参数替换。
