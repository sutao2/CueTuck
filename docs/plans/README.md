## 规则

1. 详细逐步任务只覆盖**当前**里程碑。见 [ADR 0006](../architecture/decisions/0006-plan-altitude.md)。
2. 格式见 [计划模板](../templates/implementation-plan.md)。
3. 完成记录必须带命令证据。
4. 没有对应计划，不写应用代码。
