# 常用片段

- Given 桌面用户手动填写名称、类型和内容，When 保存网址、账号、模板或文本，Then 写入本机独立片段库，可按名称或正文查找、修改、复制和删除；不监听剪贴板，不参与提示词同步、导出、发布或 MCP。
- Given 输入密码，When 保存，Then 正文只交给系统凭据库；片段库仅保存名称、类型、分类关联和标识。凭据不可用时不降级。列表、搜索和编辑时不读出密码。
- Given 片段与提示词匹配同一查询，When 使用独立启动器，Then 同时列出两类结果；片段按原样复制到系统剪贴板，不执行链接、不解析变量、不写最近提示词；启动器仅在用户选择复制时读取密码。

- Given 本机渲染密码片段，When 用户点击「显示密码」，Then 仅当前条目短暂显示明文，点击隐藏、离开该行、失焦、切页或 15 秒后隐藏；显示不写剪贴板。

- Given 系统凭据库缺少默认钥匙串或授权被取消，When 保存失败，Then 片段编辑器保留输入并显示对应处理办法，数据库事务回滚。

- Given 升级前已保存片段，When 打开片段库，Then 原有记录仍可搜索和复制，默认归入「未分类」。自建分类独立于提示词分类；删除分类仅将其中片段移回未分类。
- Given 已选择片段分类，When 同时指定类型和关键词，Then 仅显示满足全部条件的记录，侧栏数量仍为各分类总数；新建默认使用当前分类。
