# 客户端交互与 AI 快捷操作

## 范围与顺序

1. 广场/本地操作：下载和收藏图标及文字提示；更多只放补充操作，右键复用补充菜单；计数原地更新、本地收藏反馈、行视图缩略图。
2. 图片预览使用临时对话框；长提示词与展开参考资料保持各自可用空间。
3. 独立启动器增加输入创建、显式 AI 优化、显式广场搜索；额外快捷操作优先复用复制输入。客户端本地设置端点、密钥和模型，不使用服务端审核密钥。
4. 百炼审核：核对最新官方模型并用固定文本/合成图片测试；启用已验证的多模态路由，保持失败转人工和附件人工确认。只处理后续投稿，不批量重审历史数据。

每个可独立验收切片更新规格并提交。秘密仅保存受限本机/服务端配置，禁止提交。

## 验收场景

- GIVEN 广场卡片 WHEN 查看主操作、更多及右键 THEN 下载/收藏仅在主操作出现，补充菜单提供不同用途。
- GIVEN 已成功下载或收藏 WHEN 服务端确认计数 THEN 原地更新卡片和已打开详情，不重载列表；失败不得虚增。
- GIVEN 本地收藏或行视图图片 WHEN 操作/浏览 THEN 有成功反馈且缩略图可见。
- GIVEN 图片和长正文 WHEN 预览或展开参考资料 THEN 图片对话框可关闭回到原处，正文不会被挤成不可读区域。
- GIVEN 启动器输入 WHEN 创建/优化/广场搜索 THEN 使用当前输入；普通本地搜索不联网；异步旧结果不覆盖当前输入。
- GIVEN 用户自备 AI 配置 WHEN 保存或优化 THEN 密钥只在本机安全存储，模型可选择/手填；未配置显示设置入口，失败保留原文，优化结果须用户采用。
- GIVEN 审核配置 WHEN 固定样本和图片实测 THEN 记录实际可用模型；模型返回无效结果、超时或不可用则转人工。
