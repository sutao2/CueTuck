## 设计

- 固定 owner / admin / reviewer / user；审核员只有审核与本人安全权限；运营管理员管理普通用户，不能操作管理人员；owner 可管理角色。
- 已有实例通过明确的 `PROMPTARK_OWNER_EMAIL` 选择一位现有、未停用管理员，一次迁移，不修改密码。无 owner 时旧 admin 配置权限保持兼容；有 owner 后配置权限收紧到 owner。迁移标记阻止重启重新提权。
- 新库初始化直接创建 owner。账号停用字段默认 false，不推测旧账号创建日期。
- 列表服务端检索、角色/状态筛选、固定排序分页；详情仅公开资料、登录来源、投稿计数和权益状态，禁止返回私人库正文或令牌。
- 停用/启用、全会话撤销与角色修改必须明确确认并提供操作者当前密码。管理写事务先锁账号表，再重查操作者令牌/角色；禁止操作本人，禁止移除最后有效 owner；改角色或停用撤销目标所有令牌；脱敏审计与业务同事务。
- 本子切片暂不支持无本地密码管理员发起高危管理操作，页面明确说明，不能绕过重新认证。
