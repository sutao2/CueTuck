# 登录续期和联网恢复

## 方案

现行服务端 Access 无固定到期时间，不添加周期性轮换。桌面鉴权请求明确 401 时通过统一命令边界续期并最多重试一次；并发续期合并，迟到的旧 token 请求复用新 token。非 401 不重放写请求。登录、退出、切换账号改变会话代次，旧请求不能以新账号重试。

主窗口订阅登录状态变化，更新令牌与退出显示。启动恢复遇网络失败时，监听 online 和回到窗口自动再试，进行中合并；卸载移除监听，手动退出后清除恢复状态。退出清理文件失败必须显示错误，不假称持久凭据已删除。令牌文件错误、服务不可用、网络失败和明确失效分别显示，401 清文件且提示重新登录，无文件正常访客。

## 场景

- Given 两个鉴权请求返回 401 When 同时续期 Then 仅一次刷新，各请求最多重试一次。
- Given 切换账号或退出 When 旧请求迟到返回 401 Then 不以新账号重放。
- Given 断网启动恢复失败 When 联网或回到窗口 Then 自动恢复；配置损坏不反复自动尝试。
- Given 刷新被明确拒绝 When 服务返回 401 Then 清文件与内存，显示重新登录；网络失败保留登录信息。
- Given 请求超时、403 或 500 When 操作失败 Then 不自动重放原写操作。
