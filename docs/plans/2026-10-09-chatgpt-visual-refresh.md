# 双平台 ChatGPT 风格统一

## 范围

按用户要求参考当前 ChatGPT 的中性层次、简洁侧栏、柔和控件与正文优先方向，统一桌面工作台、提示词/合集、Skills、设置、搜索/编辑弹层和独立启动器。保留品牌与既有信息架构；不新增聊天能力、不修改业务流程、不发布或替换已安装客户端。

## 实施顺序

1. 统一浅深色语义变量、工作台侧栏/页头/卡片与控件。验证主窗口两平台、侧栏展开/收起、网格/列表、窄宽窗口。
2. 对齐 Skills、设置、搜索/编辑与启动器。保持菜单层级、固定操作栏、可见焦点、紧凑密度与系统减弱动态效果。
3. 完整前端回归与构建；Playwright 隔离数据检查 Windows/Mac 平台标识、明暗主题、800×600/1440×900、长文本和关键操作。保留 Mac 红黄绿 y=21 与 38px 顶栏，Windows 32px 原生控制区域；不以浏览器结果代替原生系统验收。
4. 文档与实现一同提交，记录截图及尚未验证的原生边界。

## 验收场景

- Given Windows/Mac 工作台 When 切换主题、折叠侧栏或缩窄窗口 Then 导航、内容与操作不遮挡，保留原生窗口按钮区域。
- Given 提示词、Skills 或设置 When 浏览/筛选/编辑/返回 Then 沿用既有操作、草稿与数据，视觉层级保持一致。
- Given 长 AI 结果或变量填写 When 在启动器滚动 Then 底部操作可见，内容可编辑/复制，原文保留。
- Given 键盘和紧凑密度偏好 When 操作页面 Then 焦点可辨认、控件不裁切，不覆盖用户偏好。
