# 自定义大分类

用户要求：本地大分类也可新增，不再限制为系统根节点。

## 实施与验收

- [x] 新建分类明确提供“无（新建大分类）”和已有父分类；全库默认大分类，分类内默认创建子类或同级小分类；完成后定位新分类。
- [x] 内存与 SQLite 接受空父级，校验空名、同级重名、两级上限；自定义大分类可删除，但有未删除子类时拒绝，保留内容。
- [x] 自定义根与子类在乱序同步、导出导入后保持关系；广场隐藏自定义树，无系统祖先的发布分类为空。
- [x] 补充自动化回归、界面验证、构建桌面包。

## 边界

不增加第三级，不自动级联删除子分类，不修改系统预置分类。

## 验收证据

- 前端 40 个测试文件 / 294 项通过；Rust 65 项通过、1 项性能测试忽略。
- Playwright：实际新建大分类、自动滚动可见、创建子分类、非空删除保护通过，截图检查表单布局。
- 独立 `app.promptark.audit` 桌面包：原生新建大分类、默认父级、子分类创建、非空删除保护通过；测试包已关闭，正式用户库未改动。
- 正式 macOS 调试包重新构建，包含本切片；文档检查通过。
