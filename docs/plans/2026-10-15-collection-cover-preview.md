# 合集封面预览

## 计划

1. 为本地合集详情的真实封面图片补充键盘可用的大图入口，复用 ImageViewer。
2. 卡片封面保留打开合集行为，空格不提供预览；公开封面继续复用 PublishedImage。
3. 验证单图、九宫格、关闭和切换数据后的预览状态，再提交。

## 场景

- Given 本地单图或网格合集封面 When 点击图片或键盘激活 Then 查看该图大图，关闭返回合集。
- Given 卡片或缺图占位 When 浏览 Then 不拦截卡片导航、不为缺图打开预览。
- Given 正在预览 When 切换合集封面数据 Then 关闭旧图，不残留旧合集预览。

## 数据边界

合集 cover 与成员 asset_ids 分别表示封面和成员附件；没有显式关联时不按顺序猜测。该修复不改数据归属。
