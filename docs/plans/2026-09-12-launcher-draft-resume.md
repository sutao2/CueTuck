# 启动器跨应用填写恢复

## 计划

1. 区分被动失焦隐藏与明确取消：失焦保留当前填写/预览、参数值、字段焦点及滚动；Esc、关闭按钮、可见时快捷键关闭及成功后关闭仍结束本次填写。搜索态失焦仍清空查询。
2. 再次唤起恢复内存中的填写，不重新初始化默认值、不覆盖本地正在使用的正文快照；重读偏好/主题并按填写尺寸展示，避免原生先收缩到搜索栏。不持久化参数、不跨重启恢复、不向网络发送。
3. 生命周期回归覆盖隐藏事件与 blur 命令双路径、多次切换、晚到隐藏响应、无变量预览、取消/成功清理；原生事件原因和布局状态测试，构建后实际跨应用验证。

## Given / When / Then

- GIVEN 已选提示词并填写部分参数 WHEN 切去其他应用取值后重新唤起 THEN 回到同一填写页、已填值和字段焦点保持，粘贴可继续。
- GIVEN 默认参数或无变量预览 WHEN 连续失焦再唤起 THEN 不重置值、不缩成搜索页，隐藏中不主动抢焦点。
- GIVEN 用户按 Esc 或完成复制并自动关闭 WHEN 下次唤起 THEN 空搜索，不恢复已结束的填写。
- GIVEN 失焦隐藏调用尚未返回 WHEN 已重新唤起或卸载 THEN 旧响应不得把新状态标成隐藏或清掉字段。

## 验收

- 前端全量 455 项通过；原生全量 82 项通过、2 项忽略；文档检查与差异空白检查通过。
- macOS 调试包构建成功，经用户许可重启；真实选择三参数提示词，修改第一项并聚焦第二项，切到访达确认启动器隐藏，再从客户端入口唤起，值与第二项焦点保持。Esc 后再次打开为空搜索；测试草稿已清理，未修改已保存提示词。
- 全局快捷键与客户端入口使用同一原生唤起路径；自动化按键未可靠触发系统快捷键，真实物理按键仍待用户复验，不计为已完成的原生快捷键验收。
