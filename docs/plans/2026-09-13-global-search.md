# 全局搜索与页面筛选分工

- 日期：2026-09-13

## 范围

右上角唯一全局搜索入口，Cmd/Ctrl+K 打开临时面板；移除左上角重复入口。页面内搜索及 Cmd/Ctrl+F 继续筛选当前列表。默认查询全部本地提示词和合集，可显式切到广场；独立查询不继承页面分类、模型、收藏或文字。空输入不查询，250ms 防抖、输入法组字保护，最多呈现 48 条并在截断时提示细化关键词。广场复用有界分页及关闭访问开关。结果打开前沿用未保存与忙碌保护，关闭面板保持底层上下文。
