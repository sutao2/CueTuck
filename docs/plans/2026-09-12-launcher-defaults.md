# 启动器缺省偏好修复

## 原因与范围

本机设置存在 `launcher_shortcut`，但没有 `launcher_preferences`。原生窗口唤起和调整大小直接使用必须存在的设置读取函数，缺少该行时提前返回错误；前端显示的默认偏好不能补偿原生读取。仅修复缺省读取，不重置用户设置或库，不改变快捷键、尺寸及窗口样式。

## 实施与验收

1. 增加可选设置读取，保留原必填读取语义；原生启动器对缺省偏好返回空值，沿用既有默认尺寸。
2. GIVEN 新安装/旧库没有偏好行 WHEN 原生读取 THEN 成功使用默认值且不写入设置。
3. GIVEN 已保存偏好 WHEN 读取 THEN 保留值；无效内部 JSON 使用默认；数据库错误仍返回错误，不掩盖损坏。
4. 用真实临时 SQLite 做回归，运行桌面与原生测试，构建本地 App，再实测按钮及当前快捷键。

## 进度

- 已修复可选设置读取；必填读取仍对缺省记录报错，数据库故障不会被默认值掩盖。
- 真实临时 SQLite 覆盖缺省、无写入、已有配置、非法内部 JSON 和数据库错误。原生测试 78 通过、1 个性能测试忽略；桌面前端 435 通过；docs-check 通过。
- `npm run build:local` 完成；用户确认后重启本机调试 App。现有库仍无 `launcher_preferences`，按钮已能打开独立 `tauri://localhost/launcher.html`，搜索框聚焦；搜索“电商”出现既有本地结果，Esc 关闭正常。
- 全局快捷键保留 `Shift+Super+P`，未修改用户设置。自动化按键受窗口切换干扰，真实键盘复验待用户确认，不标称已通过。
