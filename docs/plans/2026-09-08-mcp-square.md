# P2 MCP 广场与接入配置

状态：已验收（2026-09-08）。依赖 [ADR 0021](../architecture/decisions/0021-mcp-square-opt-in.md)。

## 步骤

1. 保持现有三个本地工具与只读 SQLite 行为。仅环境变量 PROMPTARK_MCP_SQUARE=1 时增加 search_square_prompts、get_square_prompt、list_square_catalog；环境固定于进程启动，工具参数不能开启网络或改地址。
2. 新增独立 GET /v1/square/search 分页合同，按标题/id 排序，标题/摘要字面关键词、分类（含一级子分类）、模型筛选，limit 默认 20 最大 100，offset 0–100000。数据库直接 LIMIT/OFFSET，返回 next_offset，不改变既有工作台列表响应。在线可见性及匿名策略在 API 校验；不记下载统计。
3. MCP 仅请求指定站点的固定只读广场路径，不带账号/本地文件/令牌；默认地址 http://127.0.0.1:8787。启动配置仅允许 HTTPS 或 loopback HTTP origin，无凭据/查询/片段。禁止重定向与自动代理；连接 3 秒、总请求 8 秒、响应最多 2 MiB。离线/下架/禁匿名返回有界工具错误，不回退本地或编造空结果。返回内容明确为不可信数据，不执行正文/附件。
4. 设置「网络与代理」增加独立接入区：填写已构建 MCP 可执行文件绝对路径，读取真实库目录；原生只检查文件存在/可执行，不运行程序。显式选择是否给此配置启用广场，生成可复制 mcpServers JSON，说明可信宿主和重启生效；不安装宿主配置、不嵌入 MCP 进桌面包，不复制登录令牌。浏览器无法获取原生路径时诚实提示。
5. 单元及真实 stdio 子进程：默认网络关闭、工具发现、参数校验、分页和筛选、404/401/离线/重定向/超大/超时、后续 ping 可用；新 API 用隔离数据验证下架与分类；本机后端真实联调仅只读。前端配置/复制失败测试，原生路径检查测试；构建与文档通过后独立提交。

## Given / When / Then

- GIVEN 未显式启用或只设置站点地址；WHEN 列工具或调用本地搜索；THEN 只有三个本地工具且无网络，强行调用广场工具返回错误。
- GIVEN 已启用；WHEN 本地搜索或读取；THEN 仍只读 SQLite；广场工具不会读取或上传本机正文。
- GIVEN 多页公开条目与下架条目；WHEN 广场分页并筛选父分类、模型或字面 %；THEN 稳定有界、无重复/下架项，末页 next_offset 为 null。
- GIVEN 广场禁匿名、目标下架或接口离线；WHEN 智能体读取；THEN 明确错误，不使用桌面会话，不缓存旧正文；后续本地工具/ping 可继续。
- GIVEN 远端重定向、超时或超量响应；WHEN 请求；THEN 拒绝/超时错误，不继续访问新地址或无限读取。
- GIVEN 原生库目录和有效独立程序路径；WHEN 生成配置；THEN JSON 转义正确、绝对路径、默认显式关闭广场以覆盖宿主继承环境；不执行程序或写宿主配置，复制失败保留配置。

## 不包含

远程 HTTP MCP、认证广场、附件字节下载、向量搜索、自动安装宿主配置和 MCP 随桌面打包。合集与云端回收仍在 P1 后续，不被本片标成完成。

## 验收记录

- MCP 15 项测试通过，含真实 stdio 进程、仅本地隔离、 opt-in 工具发现及错误/超时后仍可 ping。
- 后端 146 项通过、2 项显式忽略；桌面 378 项通过；原生 72 项通过、1 项显式忽略。API、MCP release 和 macOS debug app 构建成功。
- 真实本机后端只读联调：发现 6 工具、两页 limit=1 无重复、40 项分类目录、正文读取；未访问用户本地 SQLite、未修改广场数据。
- 原生应用实际填写已构建程序路径，生成真实库目录及默认关闭的配置；切换广场清除旧配置，重生成含指定 API origin；测试后恢复默认关闭，未修改任何宿主配置。
