# CueTuck · 唤词

**Your prompts, a shortcut away.**

[简体中文](../../README.md) · [English](README.en.md) · **日本語** · [한국어](README.ko.md) · [Español](README.es.md) · [Français](README.fr.md) · [Deutsch](README.de.md)

よく使うプロンプト、参考画像、エージェントの Skills をまとめる、ローカル優先のデスクトップアプリ。検索して変数を入力し、結果を普段の AI ツールにコピーできます。

[プレビュー版をダウンロード](https://github.com/sutao2/CueTuck/releases) · [ドキュメント](../../docs/INDEX.md) · [問題を報告](https://github.com/sutao2/CueTuck/issues)

![プロンプト広場：カテゴリ、画像、検索とフィルター](../../docs/assets/readme/square.png)

## 主な機能

| 機能 | できること |
|---|---|
| プロンプト広場 | カテゴリ・モデル・キーワードで検索。画像、出典、作者を確認してダウンロードやお気に入り登録。 |
| ローカルライブラリ | 分類、検索、お気に入り、本文と参考資料の編集。カードとリスト表示の切り替え。 |
| 独立ランチャー | 設定可能なグローバルショートカットで起動。検索、変数入力、コピー、新規作成、AI 最適化、広場検索。 |
| 翻訳と AI | 広場の中国語・原文・英語を切り替え。ローカルの翻訳と最適化には自分のモデルを使用し、取得したモデル一覧から選択。 |
| Skills 管理 | 公開ソースの閲覧、本機の Skills 検出、エージェント別のインストール、バックアップ復元、手動更新確認。 |
| MCP | 対応エージェントからローカルプロンプトを検索・取得・展開。広場の公開ツールは任意で有効化。 |

## 整理して、すぐ使う

### テンプレートはローカルに

デスクトップ版は SQLite に保存します。`{{変数}}` と参考資料を使い、同じテンプレートを繰り返し利用できます。広場のお気に入り・公開・個人ライブラリ同期にはログインを使います。

![サンプルプロンプトを整理したローカルライブラリ](../../docs/assets/readme/library.png)

### 入力結果を確認してコピー

今回の目的や対象読者を入力し、完成した本文を確認してからコピーします。

![変数入力後のプロンプトのプレビュー](../../docs/assets/readme/variables.png)

### ショートカットで呼び出す

ランチャーは独立したウィンドウです。キーボードで検索と変数入力を行い、Enter でコピー。新しい入力からプロンプトを作成したり、AI 最適化を実行したりできます。

![独立ランチャーでの変数入力](../../docs/assets/readme/launcher.png)

> スクリーンショットは現行ソースのブラウザプレビューです。広場は公開コンテンツ、ローカルとランチャーはサンプルを使用しています。ネイティブ SQLite、システムショートカット、ファイルのインストールにはデスクトップ版が必要です。配布版はソースより古い場合があります。

## インストールと更新

[GitHub Releases](https://github.com/sutao2/CueTuck/releases) からダウンロードしてください。

| 環境 | パッケージ | 対応状況 |
|---|---|---|
| macOS · Apple Silicon | `.dmg` | arm64、実機確認済み |
| Windows | `.exe` | x64、CI でインストール・起動・アンインストールを確認 |
| Linux | — | 未検証 |

**設定 → 更新** で確認、ダウンロード進捗の表示、インストールの承認ができます。現在はプレビュー版です。macOS はアドホック署名で Apple の公証は未取得です。システムの警告については[インストール説明](../../deploy/README.md)を参照してください。

## はじめに

1. ローカルで新規作成するか、広場からテンプレートをダウンロード。
2. **使用** を選び、変数を入力して AI ツールにコピー。
3. 設定でショートカット、言語、外観を変更。
4. **AI とモデル** でサービス URL と API キーを設定し、モデル一覧を取得して選択。
5. 同期や広場への公開を使う場合はログインし、公開ニックネームを設定。

AI 設定をローカルに保存しても、推論がオフラインになるわけではありません。デスクトップ版のキーは OS の資格情報ストアに保存され、翻訳・最適化時には対象テキストを選択したサービスへ送ります。公開前に本文と添付を確認してください。

## Skills と MCP

Codex、Claude Code、Cursor、Pi、OpenCode などの Skill フォルダーを、グローバルまたはプロジェクト単位で管理できます。インストールと置換には確認・バックアップの手順があります。依存 MCP の自動インストールやスクリプト実行は行いません。[Skills 仕様](../../docs/specs/skills/spec.md)。

MCP は別途ビルドする **Rust stdio サービス** で、実行に Node.js や uv は不要です。既定はローカルの読み取り専用ツールです。**設定 → ネットワークとプロキシ → エージェント MCP 接続** で設定を生成し、[接続ガイド](../../docs/how-to/mcp-clients.md)に沿って導入します。

## 開発

Node.js 22+ を用意してください。デスクトップ版には Rust と各 OS の Tauri ビルド依存関係も必要です。

```bash
git clone https://github.com/sutao2/CueTuck.git
cd CueTuck/desktop
npm ci
npm test
npm run dev
```

ブラウザプレビューが起動します。ネイティブ版はプレビューを停止してから `npm run tauri dev` を実行します。
