- Given 本地或广场的卡片/列表 When 右键 Then 不打开应用操作菜单，也不改变条目或导航状态。

- Given 编辑或搜索输入框 When 右键 Then 应用不拦截系统复制、粘贴菜单。
- Given 工作台底栏或收藏空态 When 查看指引 Then 不再提示使用右键。
