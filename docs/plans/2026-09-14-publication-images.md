## 上线后列表错位修复

API 已于 2026-09-14 部署，元数据已返回。用户截图暴露 PublishedImage 的多根组件未把调用方封面 class 传递到图片按钮，导致列表列宽、位置和高度规则失效。

1. 先用传入封面 class/style 的挂载回归复现；显式绑定到图片按钮，不能落到大图查看器。
2. 加载/失败占位服从封面盒子，不以最小高度挤压列表。检查列表与网格、成功与失败、大图打开与关闭。
3. 运行回归、构建安装，实际搜索“鹈鹕”验证封面位于文字左侧且图片可加载，提交。

- Given 已发布的条目有图片 When 切到列表并等待图片 Then 封面固定在左侧，加载前后不挤到摘要或计数下方。
- Given 图片加载失败 When 点击重试或打开大图 Then 保持封面尺寸与操作可用，弹窗不继承封面样式。
