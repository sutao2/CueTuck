# beta.13 双平台发行

状态：已发布并验收。

1. 将桌面版本统一至 0.1.0-beta.13，覆盖已安装 beta.12 与公开 beta.10 的升级路径；不加入无关功能。
2. 推送发行提交，用同一提交构建 macOS arm64 与 Windows x64；沿用现有更新签名公钥与生产 API。
3. 检查 CI、安装包、签名与哈希；准备发行说明及双平台更新清单后发布 GitHub prerelease，匿名核验附件和更新发现。

- Given 两平台构建 When 发布 Then 源提交、版本、生产地址一致，更新资产签名可验证。
- Given beta.10 或 beta.12 客户端 When 检查预览更新 Then 可发现 beta.13 及匹配平台下载。
- Given 构建或验证失败 When 准备发行 Then 不公开不完整的更新清单。

本版包含登录后昵称设置、广场发布者信息、会话恢复、分类统计与下拉样式、发布图片及列表封面修复；对应实施记录见 INDEX。

初次 CI 中浏览器旧模拟账号未提供公开资料，被新增昵称弹窗正常拦截。补齐隔离资料传输并让浏览器实际填写昵称后续接，不跳过该步骤；重新验证并统一最终发行源提交。
