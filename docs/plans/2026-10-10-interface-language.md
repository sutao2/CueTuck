# 完整界面语言切换

## 方案

当前词表只覆盖导航。扩展已有本机 `ui_language` 偏好，统一响应式语言状态；逐页接入明确的界面文案，不扫描或替换 DOM，不翻译用户内容。范围为客户端设置十页、工作台、编辑/详情/使用/登录等弹窗、Skills、独立启动器，以及共用控件的可访问名称。提示词内容语言仍由内容语言开关独立管理。

1. 建立共享语言状态与中英文词表，保留现有导航键；先完成设置与共用控件。
2. 按组件接入界面文字、占位符、提示及 UI 状态；数据标识、用户命名、提示词正文、路径和模型 ID 保持原值。
3. 检查静态中文遗漏；验证中文默认、切换后立即更新、持久化恢复、英文长文案布局及现有行为回归。

## 场景

- Given 中文界面 When 保存 English Then 当前设置正文、导航、按钮和下拉选项立即切换，已打开的子组件也更新。
- Given 已保存 English When 重启或唤起启动器 Then 使用英文界面；切回中文后恢复中文。
- Given 保存失败 When 切换语言 Then 保持已生效语言，显示失败，不假装成功。
- Given 用户中文提示词、分类或文件名 When 切换 English Then 原始内容与内部标识不变；内容翻译仍须独立选择。
- Given 英文浅深色和窄窗口 When 打开设置、工作台和弹窗 Then 文字可换行、按钮可操作、无横向溢出。

## 验收

已实现，客户端未发版。

- 共用响应式语言状态与明确的 UI 翻译入口覆盖工作台、十个设置页、编辑/详情/使用/登录/举报/发布/Skills 页面、共用选择器及独立启动器；启动器初次加载及再次唤起读取已保存偏好。
- 原始标题、正文、自定义分类、模型 ID、路径与公开作者资料不翻译；仅系统预置分类显示英文标签，标识与持久化数据不变。服务端自由文本、审核理由和未知技术诊断保留原文。
- 全量 690 项前端测试通过；最终调整后 12 项语言、共享身份表单及同步状态回归通过；生产构建与 docs-check 通过。新增静态文案漏接检查、译文插值完整性、保存失败、重开恢复、用户内容隔离和启动器语言测试。
- 浏览器真实选择 English 后，十页设置 × 1440/820/600px 的 30 组检查均无中文界面残留或横向溢出；英文工作台、新建页、系统分类菜单、注册页已验。浅色全宽与深色窄窗截图分别为 `output/playwright/settings-english.png`、`settings-english-dark-narrow.png`，长选项菜单宽 220px 且位于视口内。
- 未重新打包或安装客户端；本机原生窗口与发行包在下次发行验收。
